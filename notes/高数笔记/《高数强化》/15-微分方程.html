第15讲 微分方程

1. 总体判断流程

遇到微分方程，先判断类型，再套对应方法：

识别类型 → 化成标准形式 → 求通解 → 代初值/边界条件定常数

考研中重点识别：

  1. 一阶微分方程；
  2. 二阶可降阶微分方程；
  3. 高阶常系数线性微分方程；
  4. 欧拉方程等可通过换元化简的方程。

一、一阶微分方程

1. 可分离变量型

若能写成

y ′ = f ⁡ ( x ) ⁢ g ⁡ ( y ) ,

则

d ⁢ y g ⁡ ( y ) = f ⁡ ( x ) ⁢ d ⁢ x .

两边积分：

∫ d y g ⁡ ( y ) = ∫ f ⁡ ( x ) d x + C .
易错点

分离变量时若除以 g ⁡ ( y ) ，可能漏掉

g ⁡ ( y ) = 0

对应的常值解，应单独检查。

2. 可化为可分离变量型

2.1 y ′ = f ⁡ ( a ⁢ x + b ⁢ y + c )

令

u = a ⁢ x + b ⁢ y + c .

则

d ⁢ u d ⁢ x = a + b ⁢ y ′ = a + b ⁢ f ⁡ ( u ) .

于是化成

d ⁢ u a + b ⁢ f ⁡ ( u ) = d ⁢ x .

2.2 y ′ = f ⁡ ( y x )

令

u = y x , y = u ⁢ x .

则

y ′ = u + x ⁢ u ′ .

代回原方程：

u + x ⁢ u ′ = f ⁡ ( u ) ,

所以

d ⁢ u f ⁡ ( u ) − u = d ⁢ x x .

2.3 y ′ = f ⁡ ( x y )

可令

u = x y ,

通常把 x 看成 y 的函数，利用

d ⁢ x d ⁢ y = 1 y ′

化成齐次型处理。

2.4 线性分式形式

若出现

y ′ = f ⁡ ( a 1 ⁢ x + b 1 ⁢ y + c 1 a 2 ⁢ x + b 2 ⁢ y + c 2 ) ,

先看分子、分母对应的两条直线。

  • 若常数项可通过平移消掉，令
x = X + x 0 , y = Y + y 0

化成

y ′ = f ⁡ ( a ⁢ X + b ⁢ Y c ⁢ X + d ⁢ Y ) ,

再按齐次型处理；

  • 若结构可直接化成 y / x 或 x / y ，直接使用齐次换元。 核心目标：
把复杂组合变成一个新变量

3. 一阶线性微分方程

标准形式：

y ′ + P ⁡ ( x ) ⁢ y = Q ⁡ ( x )

通解：

y = e − ∫ P ⁡ ( x ) d x ⁢ [ ∫ Q ⁡ ( x ) ⁢ e ∫ P ⁡ ( x ) d x d x + C ]

考试中建议先认出标准形式，不要每次重新推导公式。

4. 伯努利方程

标准形式：

y ′ + P ⁡ ( x ) ⁢ y = Q ⁡ ( x ) ⁢ y n , n ≠ 0 , 1.

两边乘

y − n

得

y − n ⁢ y ′ + P ⁡ ( x ) ⁢ y 1 − n = Q ⁡ ( x ) .

令

z = y 1 − n ,

则

z ′ = ( 1 − n ) ⁢ y − n ⁢ y ′ .

于是化成关于 z 的一阶线性方程。

判断

看到

y ′ + P ⁡ ( x ) ⁢ y = Q ⁡ ( x ) ⁢ y n

第一反应就是

z = y 1 − n .

二、二阶可降阶微分方程

1. 不含 y ：令 p = y ′

若

y ″ = f ⁡ ( x , y ′ ) ,

令

p = y ′ ,

则

y ″ = p ′ .

原二阶方程降为

p ′ = f ⁡ ( x , p ) .

先求

p = φ ⁡ ( x , C 1 ) ,

再由

y ′ = p

积分得到

y = ∫ φ ⁡ ( x , C 1 ) d x + C 2 .

2. 不显含 x ：令 p = p ⁡ ( y ) = y ′

若

y ″ = f ⁡ ( y , y ′ ) ,

令

p ⁡ ( y ) = y ′ .

由链式法则：

y ″ = d ⁢ p d ⁢ x = d ⁢ p d ⁢ y ⁢ d ⁢ y d ⁢ x = p ⁢ d ⁢ p d ⁢ y .

于是原方程变为

p ⁢ d ⁢ p d ⁢ y = f ⁡ ( y , p )

先求 p ⁡ ( y ) ，再由

d ⁢ y d ⁢ x = p ⁡ ( y )

分离变量：

d ⁢ y p ⁡ ( y ) = d ⁢ x .
易错点

如果处理中除以 p ，一定检查

p = 0

是否对应原方程的解，否则可能漏解。

3. 只含 y ″ 与 x

若

y ″ = f ⁡ ( x ) ,

直接连续积分两次：

y ′ = ∫ f ⁡ ( x ) d x + C 1 ,
y = ∫ ( ∫ f ⁡ ( x ) d x ) d x + C 1 ⁢ x + C 2 .

三、高阶常系数线性微分方程

1. 齐次方程

二阶标准形式：

y ″ + p ⁢ y ′ + q ⁢ y = 0.

写特征方程：

r 2 + p ⁢ r + q = 0

根据特征根写通解。

两个不同实根

若

r 1 ≠ r 2 ,

则

y = C 1 ⁢ e r 1 ⁢ x + C 2 ⁢ e r 2 ⁢ x

二重实根

若

r 1 = r 2 = r ,

则

y = ( C 1 + C 2 ⁢ x ) ⁢ e r ⁢ x

共轭复根

若

r = α ± i ⁢ β ,

则

y = e α ⁢ x ⁢ ( C 1 ⁢ cos ⁡ β ⁢ x + C 2 ⁢ sin ⁡ β ⁢ x )

2. 高阶齐次方程

若

a n ⁢ y ( n ) + ⋯ + a 1 ⁢ y ′ + a 0 ⁢ y = 0 ,

写特征方程

a n ⁢ r n + ⋯ + a 1 ⁢ r + a 0 = 0.

若 r 是 k 重实根，则对应部分为

e r ⁢ x ⁢ ( C 1 + C 2 ⁢ x + ⋯ + C k ⁢ x k − 1 )

若

α ± i ⁢ β

是 k 重共轭复根，则对应部分为

e α ⁢ x ⁢ [ P k − 1 ⁡ ( x ) ⁢ cos ⁡ β ⁢ x + Q k − 1 ⁡ ( x ) ⁢ sin ⁡ β ⁢ x ] .

3. 已知一个齐次特解：降阶法

对二阶齐次线性方程

y ″ + P ⁡ ( x ) ⁢ y ′ + Q ⁡ ( x ) ⁢ y = 0 ,

若已知一个非零特解 y 1 ⁡ ( x ) ，求另一个线性无关特解时，核心方法是设

y = y 1 ⁢ v ⁡ ( x ) .

代入原方程后，由于 y 1 本身满足

y 1 ″ + P ⁢ y 1 ′ + Q ⁢ y 1 = 0 ,

所有含 v 的项会消掉，只剩 v ′ , v ″ ，从而把二阶方程降为一阶方程。 最终可得到另一特解

y 2 = y 1 ⁢ ∫ e − ∫ P ⁡ ( x ) d x y 1 2 d x .

且

y 2 y 1

不是常数，因此 y 1 , y 2 线性无关，原方程通解为

y = C 1 ⁢ y 1 + C 2 ⁢ y 2 .
考研掌握程度

必须理解并会用 y = y 1 ⁢ v 的降阶思想；上面的 y 2 公式建议认识、会用，但完整证明不必死背。若考证明题，只需掌握“设 y = y 1 ⁢ v → 利用 y 1 是解消去 v 项 → 降阶”的主线。

四、二阶常系数非齐次线性微分方程

1. 概念

方程

y ″ + p ⁢ y ′ + q ⁢ y = f ⁡ ( x ) ( f ⁡ ( x ) ≠ 0 )

称为二阶常系数非齐次线性微分方程，其中 p , q 为常数， f ⁡ ( x ) 为已知连续函数，称为自由项。 对应的导出方程（齐次方程）为

y ″ + p ⁢ y ′ + q ⁢ y = 0.

2. 解的结构

（1）叠加性

若

y 1 ∗ ⁡ ( x )  是  y ″ + p ⁢ y ′ + q ⁢ y = f 1 ⁡ ( x )  的一个特解 ,
y 2 ∗ ⁡ ( x )  是  y ″ + p ⁢ y ′ + q ⁢ y = f 2 ⁡ ( x )  的一个特解 ,

则

y 1 ∗ ⁡ ( x ) + y 2 ∗ ⁡ ( x )

是

y ″ + p ⁢ y ′ + q ⁢ y = f 1 ⁡ ( x ) + f 2 ⁡ ( x )

的一个特解。

（2）同一非齐次方程的两个特解之差

若

y 1 ∗ ,   y 2 ∗

都是

y ″ + p ⁢ y ′ + q ⁢ y = f ⁡ ( x )

的特解，则

y 1 ∗ − y 2 ∗

是对应齐次方程

y ″ + p ⁢ y ′ + q ⁢ y = 0

的解。

（3）通解结构

非齐次方程的通解为

y = y h + y p

其中：

  • y h ：导出方程（齐次方程）的通解；
  • y p ：原非齐次方程的一个特解。

3. 特解的设定（重点）

总原则

先按自由项 f ⁡ ( x ) 的形式“照抄”特解基本形式； 再看是否与齐次解重复； 若重复，则乘以 x k ，其中 k 由对应特征根重数决定。

设

P n ⁡ ( x ) ,   Q n ⁡ ( x )

分别为 n 次多项式。

情形1：自由项为 f ⁡ ( x ) = P n ⁡ ( x ) ⁢ e α ⁢ x

特解设为

y p ∗ = e α ⁢ x ⁢ x k ⁢ Q n ⁡ ( x )

其中：

  • e α ⁢ x ：照抄；
  • Q n ⁡ ( x ) ：与 P n ⁡ ( x ) 同次数的一般多项式；
  • k 的取值由 α 是否为特征根决定：
{ k = 0 , α  不是特征根 ; k = 1 , α  是单特征根 ; k = 2 , α  是二重特征根 .

情形2：自由项为 f ⁡ ( x ) = e α ⁢ x ⁢ [ P n ⁡ ( x ) ⁢ cos ⁡ β ⁢ x + Q n ⁡ ( x ) ⁢ sin ⁡ β ⁢ x ]

特解设为

y p ∗ = e α ⁢ x ⁢ x k ⁢ [ R n ⁡ ( x ) ⁢ cos ⁡ β ⁢ x + S n ⁡ ( x ) ⁢ sin ⁡ β ⁢ x ]

其中：

  • R n ⁡ ( x ) , S n ⁡ ( x ) ：一般 n 次多项式；
  • e α ⁢ x , cos ⁡ β ⁢ x , sin ⁡ β ⁢ x ：按自由项照抄；
  • k 的取值由
α ± i ⁢ β

是否为特征根决定：

{ k = 0 , α ± i ⁢ β  不是特征根 ; k = 1 , α ± i ⁢ β  是单特征根 ; k = 2 , α ± i ⁢ β  是二重特征根 .

4. 常见特解设法对照表

（1）多项式型

若

f ⁡ ( x ) = P n ⁡ ( x ) ,

可看作

P n ⁡ ( x ) ⁢ e 0 ⁢ x .

故特解设为

y p ∗ = x k ⁢ Q n ⁡ ( x ) ,

其中

{ k = 0 , 0  不是特征根 ; k = 1 , 0  是单特征根 ; k = 2 , 0  是二重特征根 .

（2）指数型

若

f ⁡ ( x ) = e α ⁢ x ,

则设

y p ∗ = A ⁢ x k ⁢ e α ⁢ x ,

其中

{ k = 0 , α  不是特征根 ; k = 1 , α  是单特征根 ; k = 2 , α  是二重特征根 .

（3）三角函数型

若

f ⁡ ( x ) = sin ⁡ β ⁢ x 或 f ⁡ ( x ) = cos ⁡ β ⁢ x ,

则设

y p ∗ = x k ⁢ ( A ⁢ cos ⁡ β ⁢ x + B ⁢ sin ⁡ β ⁢ x ) ,

其中

{ k = 0 , ± i ⁢ β  不是特征根 ; k = 1 , ± i ⁢ β  是单特征根 ; k = 2 , ± i ⁢ β  是二重特征根 .
易错点

右端只有 sin ⁡ β ⁢ x 或只有 cos ⁡ β ⁢ x 时，特解也要同时设

A ⁢ cos ⁡ β ⁢ x + B ⁢ sin ⁡ β ⁢ x ,

不能只设一项。

（4）指数乘三角型

若

f ⁡ ( x ) = e α ⁢ x ⁢ sin ⁡ β ⁢ x 或 f ⁡ ( x ) = e α ⁢ x ⁢ cos ⁡ β ⁢ x ,

则设

y p ∗ = x k ⁢ e α ⁢ x ⁢ ( A ⁢ cos ⁡ β ⁢ x + B ⁢ sin ⁡ β ⁢ x ) ,

其中

{ k = 0 , α ± i ⁢ β  不是特征根 ; k = 1 , α ± i ⁢ β  是单特征根 ; k = 2 , α ± i ⁢ β  是二重特征根 .

5. 为什么要乘 x k

若你“照抄”出的特解形式已经包含在齐次解 y h 中，那么代回去无法解出待定系数，因此必须乘上 x 把它“挪开”，直到与齐次解线性无关为止。 所以：

自由项决定基本形式，特征根重数决定乘  x k

6. 解题固定流程

对于

y ″ + p ⁢ y ′ + q ⁢ y = f ⁡ ( x )

按下面顺序做：

  1. 写导出方程
y ″ + p ⁢ y ′ + q ⁢ y = 0 ;
  1. 写特征方程
r 2 + p ⁢ r + q = 0 ;
  1. 求齐次通解 y h ；
  2. 根据自由项 f ⁡ ( x ) 设特解 y p ；
  3. 若与齐次解重复，则乘 x k ；
  4. 将 y p 代回原方程求待定系数；
  5. 写出通解
y = y h + y p .

7. 一句话总结

先看右端像什么，再看特征根重几次；像什么就照抄什么，重几次就乘  x k

欧拉方程

典型形式：

x 2 ⁢ y ″ + p ⁢ x ⁢ y ′ + q ⁢ y = f ⁡ ( x ) , x > 0.

令

x = e t

即

t = ln ⁡ x .

有

d ⁢ y d ⁢ x = 1 x ⁢ d ⁢ y d ⁢ t ,
d 2 ⁢ y d ⁢ x 2 = 1 x 2 ⁢ ( d 2 ⁢ y d ⁢ t 2 − d ⁢ y d ⁢ t ) .

代入后可以把欧拉方程化成常系数线性微分方程。

识别

出现

x 2 ⁢ y ″ , x ⁢ y ′ , y

的组合时，优先想到

x = e t .

全微分方程

若

M ⁡ ( x , y ) ⁢ d ⁢ x + N ⁡ ( x , y ) ⁢ d ⁢ y = 0 ,

先判断

M y = N x

若成立，则存在函数 F ⁡ ( x , y ) 使

d ⁢ F = M ⁢ d ⁢ x + N ⁢ d ⁢ y .

因此通解为

F ⁡ ( x , y ) = C

求 F 时可先积分：

F = ∫ M d x + φ ⁡ ( y ) ,

再对 y 求偏导，与 N 比较确定 φ ⁡ ( y ) 。

→ 分离变量。 看到

y ′ + P ⁡ ( x ) ⁢ y = Q ⁡ ( x )

→ 一阶线性。 看到

y ′ + P ⁡ ( x ) ⁢ y = Q ⁡ ( x ) ⁢ y n

→ 伯努利。 看到

y ′ = f ⁡ ( y x )

→ 令 y = u ⁢ x 。 看到

y ′ = f ⁡ ( a ⁢ x + b ⁢ y + c )

→ 令 u = a ⁢ x + b ⁢ y + c 。

二阶可降阶

看到不含 y ：

y ″ = f ⁡ ( x , y ′ )

→ 令

p = y ′ .

看到不含 x ：

y ″ = f ⁡ ( y , y ′ )

→ 令

p ⁡ ( y ) = y ′ , y ″ = p ⁡ d ⁢ p d ⁢ y .

常系数线性

固定顺序：

特征方程 → y h → 判断右端形式 → 设  ⁢ y p → 代回求系数 → y = y h + y p

常见易错点

1. 分离变量可能漏常值解

除以 g ⁡ ( y ) 前检查 g ⁡ ( y ) = 0 。

2. 降阶时可能漏 p = 0

如果除以 p = y ′ ，必须检查 p = 0 是否为解。

3. 非齐次特解不是直接照抄右端

先照右端写形式，再检查是否与齐次解重复；若重复，要乘 x k 。

4. 多项式要设完整

例如右端为二次多项式，通常应设

A ⁢ x 2 + B ⁢ x + C ,

不能只挑看起来会用到的项。

5. 三角函数必须成对设

右端即使只有 sin ⁡ β ⁢ x ，一般也要设

A ⁢ cos ⁡ β ⁢ x + B ⁢ sin ⁡ β ⁢ x .
6. 求特解时不要带任意常数

y p 只需找一个特解；任意常数已经包含在齐次通解 y h 中。

7. 求特解、通解、满足初值的解要区分
  • 特解：满足非齐次方程的某一个解；
  • 通解：包含足够任意常数的全部解；
  • 初值问题的解：把初值代入通解后确定常数得到的唯一解。

强化阶段最重要的判断

微分方程这一章不要把主要精力放在积分运算上，而是练到看到方程就能判断：

它是什么类型 → 应该换什么元 → 特解应该设成什么形式

尤其必须熟练：

y ″ + p ⁢ y ′ + q ⁢ y = 0 ⇒ 特征根决定齐次通解

以及

y ″ + p ⁢ y ′ + q ⁢ y = f ⁡ ( x ) ⇒ 右端决定特解基本形式，特征根决定是否乘  ⁢ x k
