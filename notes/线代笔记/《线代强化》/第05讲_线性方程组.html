第5讲 线性方程组

使用说明单位矩阵统一写 I ，伴随矩阵写 adj ⁡ ( A ) 。

1. 解的情形

设 A 有 n 列，增广矩阵为 [ A , b ] 。

方程 判据 结论
A ⁢ x = 0 r ⁡ ( A ) = n 只有零解
A ⁢ x = 0 r ⁡ ( A ) < n 有非零解，解空间维数 n − r ⁡ ( A )
A ⁢ x = b r ⁡ ( A ) < r ⁡ ( [ A , b ] ) 无解
A ⁢ x = b r ⁡ ( A ) = r ⁡ ( [ A , b ] ) = n 唯一解
A ⁢ x = b r ⁡ ( A ) = r ⁡ ( [ A , b ] ) < n 无穷多解

自由变量个数看的是未知量数减秩，不是方程数减秩。

2. 基础解系与通解

若 r ⁡ ( A ) = r < n ，一组 n − r 个线性无关的齐次解 ξ 1 , … , ξ n − r 构成基础解系：

x = k 1 ⁢ ξ 1 + ⋯ + k n − r ⁢ ξ n − r .

非齐次方程有特解 η 时：

x = η + k 1 ⁢ ξ 1 + ⋯ + k n − r ⁢ ξ n − r .

基础解系不唯一，但所含向量个数固定。证明某些向量构成基础解系必须核实：都是解、线性无关、数量为 n − r ⁡ ( A ) 。

3. 解的组合规律

  • 齐次解的任意线性组合还是齐次解。
  • 两个非齐次解之差是对应齐次方程的解。
  • 若 A ⁢ η i = b ，则
A ⁡ ( ∑ i k i ⁢ η i ) = ( ∑ i k i ) ⁢ b .

因此当 b ≠ 0 时，组合仍为原非齐次方程的解，当且仅当 ∑ i k i = 1 。

非齐次解集是平移后的齐次解空间，通常不是向量空间；若 b ≠ 0 ，其所有解的线性张成空间维数为 n − r ⁡ ( A ) + 1 。

4. 标准求解流程

  1. 对 [ A , b ] 作初等行变换。
  2. 出现“左边全零、右边非零”的行则无解。
  3. 找主元变量与自由变量。
  4. 先写坐标形式，再拆成特解与齐次基础解系。
  5. 含参数时，按主元因子为零与非零分别讨论。

5. 从 A ⁢ B = 0 识别基础解系

若 A ⁢ B = 0 ，则 B 的列均属于 ker ⁡ A 。若另外

r ⁡ ( B ) = n − r ⁡ ( A ) ,

则 B 的一个列极大无关组就是 A ⁢ x = 0 的基础解系，并且 Col ⁡ ( B ) = ker ⁡ A 。

若 B 的列本身线性无关，则任一齐次解在这些列下的表示唯一。

6. 公共解问题

6.1 两个齐次方程组

联立：

A ⁢ x = 0 ,   B ⁢ x = 0 ⟺ ( A B ) ⁢ x = 0.

公共非零解存在当且仅当

r ⁢ ( A B ) < n .

充分条件 r ⁡ ( A ) + r ⁡ ( B ) < n 很好用，但不是必要条件。

6.1 补充：齐次方程组公共解的统一判断

设两个齐次方程组

M ⁢ x = 0 , N ⁢ x = 0 ,

未知量有 n 个。

1. 给系数矩阵：竖拼

两组方程有公共非零解

⟺ ( M N ) ⁢ x = 0

有非零解，因此

有公共非零解 ⟺ r ⁢ ( M N ) < n
只有公共零解 ⟺ r ⁢ ( M N ) = n
快速充分条件

因为

r ⁡ ( M N ) ≤ r ⁡ ( M ) + r ⁡ ( N ) ,

所以

r ⁡ ( M ) + r ⁡ ( N ) < n ⇒ 一定有公共非零解

但反过来不成立，因此 r ⁡ ( M ) + r ⁡ ( N ) < n 只是充分条件，不是充要条件。

2. 给两个方程组的基础解系：横拼

若

ker ⁡ M = span ⁡ { α 1 , … , α p } ,
ker ⁡ N = span ⁡ { β 1 , … , β q } ,

则无非零公共解

⟺ ker ⁡ M ∩ ker ⁡ N = { 0 }
⟺ r ⁡ [ α 1 , … , α p , β 1 , … , β q ] = p + q .

特别地，若 p + q = n ，则可直接判断拼成的 n 个向量是否满秩。

记忆
给系数矩阵看公共解：竖拼；给基础解向量：横拼

3. 抽象矩阵题的快捷思路

若不能直接算竖拼秩，优先利用

r ⁡ ( M ⁢ N ) ≤ min ⁡ { r ⁡ ( M ) , r ⁡ ( N ) }

压低秩；若最终能证明

r ⁡ ( M ) + r ⁡ ( N ) < n ,

即可直接推出 M ⁢ x = 0 , N ⁢ x = 0 有公共非零解。 出现

A T ⁢ A

时可直接用

ker ⁡ ( A T ⁢ A ) = ker ⁡ A ,

因为

A T ⁢ A ⁢ x = 0 ⇒ x T ⁢ A T ⁢ A ⁢ x = ‖ A ⁢ x ‖ 2 = 0 ⇒ A ⁢ x = 0.

出现块矩阵方程时先按块拆开：

( M N P Q ) ⁢ ( x y ) = 0 ⟺ { M ⁢ x + N ⁢ y = 0 , P ⁢ x + Q ⁢ y = 0.

若题目给矩阵多项式关系，如

A 2 − A = 3 ⁢ I ,

优先改写为

A ⁢ ( A − I ) = 3 ⁢ I ,

从而得到 A 、 A − I 可逆，再用于化简各方程组。

4. 公共解与同解不要混淆

公共解只要求两个解空间有交集：

ker ⁡ M ∩ ker ⁡ N .

同解要求两个解空间完全相同：

ker ⁡ M = ker ⁡ N .

齐次方程组同解的判据为

r ⁡ ( M ) = r ⁡ ( N ) = r ⁡ ( M N ) .
易错点
r ⁢ ( M N ) < n

与

r ⁡ ( M ) + r ⁡ ( N ) < n

不等价。前者是公共非零解的充要条件，后者只是方便使用的充分条件。

6.2 两个非齐次方程组

A ⁢ x = b ,   B ⁢ x = c ⟺ ( A B ) ⁢ x = ( b c ) .

仍然比较联立系数矩阵与联立增广矩阵的秩。分别有解不保证有公共解。

7. 同解问题

齐次情形：

A ⁢ x = 0  与  B ⁢ x = 0 ⁢  同解 ⟺ Row ⁡ ( A ) = Row ⁡ ( B ) .

也可用第4讲的竖拼三秩相等判据。

两组均有解的非齐次方程组同解，当且仅当：

  1. 对应齐次方程组同解。
  2. 有一个公共特解。

等价地，两组增广矩阵的行向量组等价。若两组都无解，它们的解集也相同，但不能套用“公共特解”判据。

补充理解：对于方阵， A ⁢ x = 0 与 A 2 ⁢ x = 0 同解当且仅当 r ⁡ ( A ) = r ⁡ ( A 2 ) ；仅有 det ⁡ A = 0 不能判定二者是否同解。

8. 几何意义

三元线性方程可表示平面，前提是每条方程的法向量非零。

秩情况 三张平面的公共点集
r ⁡ ( A ) = r ⁡ ( [ A , b ] ) = 3 一个点
r ⁡ ( A ) = r ⁡ ( [ A , b ] ) = 2 一条直线
r ⁡ ( A ) = r ⁡ ( [ A , b ] ) = 1 一个平面；三平面重合
r ⁡ ( A ) < r ⁡ ( [ A , b ] ) 三平面没有公共点
区分“两平面重合”“平行不重合”等细节时，还要检查法向量是否成比例，以及包含常数项的增广行是否成比例。

齐次解集经过原点； b ≠ 0 的非齐次解集不经过原点。

9. 补全：解向量与行向量的正交关系

若 A 的各行转成列向量后为 a 1 , … , a m ，则

A ⁢ x = 0 ⟺ a i T ⁢ x = 0 ( i = 1 , … , m ) .

因此解空间是行空间的正交补：

ker ⁡ A = Row ⁡ ( A ) ⟂ .

这解释了“齐次同解等价于行向量组等价”。若 A ⁢ x = b ，则每个内积应等于对应的 b i ，不能继续说非齐次解与所有行向量正交。

10. 补全：由已知解反推通解

10.1 非齐次解的差能否构成基础解系

若 η 0 , η 1 , … , η s 都是 A ⁢ x = b 的解，则

η 1 − η 0 , … , η s − η 0

都是 A ⁢ x = 0 的解。若这些差向量线性无关，且 s = n − r ⁡ ( A ) ，它们就是基础解系，通解为

x = η 0 + ∑ i = 1 s k i ⁢ ( η i − η 0 ) .

单凭“给了 s + 1 个非齐次解”不能保证差向量无关。

10.2 利用列之间的关系求齐次解

若 A = [ α 1 , … , α n ] ，且

c 1 ⁢ α 1 + ⋯ + c n ⁢ α n = 0 ,

则 ( c 1 , … , c n ) T 是齐次解。若右端也显然是某些列的组合，则组合系数立即给出一个特解；再补齐基础解系即可。

10.3 构造满足 A ⁢ C = 0 的矩阵

若 H 的列为 A ⁢ x = 0 的基础解系，则满足 A ⁢ C = 0 的全部矩阵可以写成

C = H ⁡ K .

因此

r ⁡ ( C ) ≤ n − r ⁡ ( A ) .

例如三阶 A 的秩为 2 ，零空间只有一维，只能构造秩不超过 1 的 C ；非零零空间向量 ξ 与任意非零行向量 v T 可给出秩一解 C = ξ ⁢ v T 。

11. 公共解与同解的实用流程

目标 最直接的做法
求公共解 联立两组方程后消元
判有无公共非零解 看联立系数矩阵秩是否小于未知量数
证所有第一组解都是第二组解 把第一组通解代入第二组，要求对所有自由参数成立
证两组同解 双向包含；或比较基础解系张成空间，并检查公共特解

如果第一组通解为 x = η + H ⁡ k ，则它的所有解都满足 B ⁢ x = c ，当且仅当

B ⁢ η = c , B ⁢ H = 0.

对每个自由参数成立，才能说明整组解的包含关系；代入一个特解只说明存在公共解。

在两组均有解的前提下，非齐次同解还等价于

r ⁡ ( A b B c ) = r ⁡ ( A B ) = r ⁡ ( A ) = r ⁡ ( B ) .

12. A ⁢ x = 0 与 A 2 ⁢ x = 0 ：逆否思路的边界

恒有 ker ⁡ A ⊆ ker ⁡ A 2 。

  • A 可逆时二者必同解，因此不同解必推出 det ⁡ A = 0 。
  • det ⁡ A = 0 不足以反推不同解。

**补充例：** A = diag ⁡ ( 1 , 0 ) 不可逆，但 A 2 = A ，两组同解；而

N = ( 0 1 0 0 ) , N 2 = 0 ,

有 ker ⁡ N ≠ ker ⁡ N 2 。

原书例5.7用“不同解推出不可逆”求必要参数关系，是有效的逆否思路；若目标是完整求出所有允许参数，还须继续检查秩是否下降。

13. 三平面位置关系细分

记法向量 a i = ( a i , b i , c i ) T ，增广向量 u i = ( a i , b i , c i , d i ) T 。每个法向量均非零。

公共点与秩 进一步条件 几何关系
r ⁡ ( A ) = r ⁡ ( [ A , b ] ) = 3 无需额外条件 三平面交于一点
两秩均为 2 增广向量任意两者无关 三个不同平面交于同一直线
两秩均为 2 有两个增广向量成比例 两平面重合，第三个与之相交
两秩均为 1 增广向量全成比例 三平面重合
r ⁡ ( A ) = 2 , r ⁡ ( [ A , b ] ) = 3 法向量任意两者无关 两两相交，三条交线互相平行，无公共点
r ⁡ ( A ) = 2 , r ⁡ ( [ A , b ] ) = 3 有两个法向量成比例 两平面平行不重合，第三个分别与它们相交
r ⁡ ( A ) = 1 , r ⁡ ( [ A , b ] ) = 2 增广向量任意两者无关 三平面互相平行，均不重合
r ⁡ ( A ) = 1 , r ⁡ ( [ A , b ] ) = 2 有两个增广向量成比例 两平面重合，第三个与它们平行不重合

注意“平行不重合”由法向量成比例但增广向量不成比例判定；只看法向量会漏掉重合情形。

14. 本讲复习检查

  • 先判断解的情形，再写通解。
  • 自由变量数量等于未知量数减秩。
  • 由已知解作差后，另外检查无关性与数量。
  • 证通解代入另一组成立时，要求对所有参数成立。
  • 公共解与同解使用不同的判断目标。
  • 三平面关系同时检查法向量与增广向量。
