使用说明单位矩阵统一写 I ，伴随矩阵写 adj ⁡ ( A ) 。

1. 矩阵乘法先看形状

A m × n ⁢ B n × s = C m × s , c i ⁢ j = ∑ k = 1 n a i ⁢ k ⁢ b k ⁢ j .

对于列向量 α , β ∈ R n ：

表达式 结果与含义
α T ⁢ β 数；内积
α ⁢ β T n × n 矩阵；外积
A ⁢ e 每行元素之和构成的列向量
e T ⁢ A 每列元素之和构成的行向量
α T ⁢ A ⁢ α 数；二次型
A ⁡ [ β 1 , … , β s ] [ A ⁢ β 1 , … , A ⁢ β s ]

一般 A ⁢ B ≠ B ⁢ A ； A ⁢ B = 0 不推出 A = 0 或 B = 0 。消去因子必须具备可逆或合适的满秩条件。

2. 基本运算公式

( A ⁢ B ) T = B T ⁢ A T , ( A ⁢ B ) − 1 = B − 1 ⁢ A − 1 .
( A T ) − 1 = ( A − 1 ) T , tr ⁡ ( A ⁢ B ) = tr ⁡ ( B ⁢ A ) .

逆公式要求有关矩阵可逆；迹公式要求 A ⁢ B , B ⁢ A 都能定义。转置、求逆都要倒转乘积次序。

若 A ⁢ B = B ⁢ A ，才可以使用通常的二项式展开：

( A + B ) m = ∑ k = 0 m ( m k ) ⁢ A m − k ⁢ B k .

3. 矩阵幂的六类入口

3.1 秩一方阵

非零秩一方阵可以写成 A = α ⁢ β T ，于是

A 2 = ( β T ⁢ α ) ⁢ A = tr ⁡ ( A ) ⁢ A .
A m = [ tr ⁡ ( A ) ] m − 1 ⁢ A ( m ≥ 2 ) .

若 tr ⁡ ( A ) = 0 ，则 A 2 = 0 ，但 A 可以非零。

3.2 试算低次幂找规律

先算 A 2 , A 3 ，观察是否出现 A 2 = k ⁢ A 、 A q = k ⁢ I 、周期性或零矩阵，再给出递推证明。

3.3 分解为容易计算的和

若 A = I + N 且 N q = 0 ，则

A m = ∑ k = 0 min ⁡ ( m , q − 1 ) ( m k ) ⁢ N k .

若 A = B + C 且 B ⁢ C = C ⁢ B = 0 ，则对于正整数 m ：

A m = B m + C m .

3.4 初等矩阵的幂

把乘法翻译成反复行变换或列变换。交换矩阵 S 满足 S 2 = I ，故偶次幂为 I ，奇次幂为 S 。

3.5 相似化简

A = P ⁢ B ⁢ P − 1 ⟹ A m = P ⁢ B m ⁢ P − 1 .

若 B 为对角矩阵，直接对对角元素取幂。

3.6 满秩分解降维

若 A = B ⁢ C ，其中 B 列满秩、 C 行满秩，则

A m = B ⁢ ( C ⁢ B ) m − 1 ⁢ C ( m ≥ 1 ) .

用低阶的 C ⁢ B 代替高阶的 A 计算。 m = 1 时中间矩阵取单位矩阵。

4. 格拉姆矩阵 A T ⁢ A

对于实矩阵 A ：

x T ⁢ A T ⁢ A ⁢ x = ‖ A ⁢ x ‖ 2 ≥ 0.

因此

ker ⁡ ( A T ⁢ A ) = ker ⁡ A , r ⁡ ( A T ⁢ A ) = r ⁡ ( A ⁢ A T ) = r ⁡ ( A T ) = r ⁡ ( A ) .
tr ⁡ ( A T ⁢ A ) = ∑ i , j a i ⁢ j 2 .

所以 tr ⁡ ( A T ⁢ A ) = 0 ⟺ A = 0 ； A T ⁢ A 正定当且仅当 A 列满秩。

条件与唯一性

复矩阵应改用共轭转置 A H 。若要求 A T ⁢ A = B ，分解通常不唯一：找到一个解 D 后， Q ⁢ D 对任意正交 Q 也满足同一等式。

5. 伴随矩阵

以下 A 为 n ≥ 2 阶方阵：

A ⁢ adj ⁡ ( A ) = adj ⁡ ( A ) ⁢ A = det ⁡ A I .
det ⁡ ( adj ⁡ ( A ) ) = ( det ⁡ A ) n − 1 .
adj ⁡ ( k ⁢ A ) = k n − 1 ⁢ adj ⁡ ( A ) , adj ⁡ ( A ⁢ B ) = adj ⁡ ( B ) ⁢ adj ⁡ ( A ) .
adj ⁡ ( A T ) = adj ⁡ ( A ) T .

若 A 可逆：

adj ⁡ ( A ) = det ⁡ A A − 1 , adj ⁡ ( A − 1 ) = 1 det ⁡ A ⁢ A .

对于 n ≥ 3 ：

adj ⁡ ( adj ⁡ ( A ) ) = ( det ⁡ A ) n − 2 ⁢ A .

二阶情形直接为 adj ⁡ ( adj ⁡ ( A ) ) = A ，避免在奇异情形出现 0 0 写法。

r ⁡ ( adj ⁡ ( A ) ) = { n , r ⁡ ( A ) = n , 1 , r ⁡ ( A ) = n − 1 , 0 , r ⁡ ( A ) ≤ n − 2.

6. 可逆矩阵与求逆方法

主要方法：

  1. 行变换： [ A ∣ I ] → [ I ∣ A − 1 ] 。
  2. 定义法：构造 A ⁢ B = I 或 B ⁢ A = I ；同阶方阵的一侧逆即可推出可逆。
  3. 多项式恒等式：把条件整理成 A ⁢ g ⁡ ( A ) = c ⁢ I ，其中 c ≠ 0 。
  4. 分块求逆或利用相似结构。

例如 N q = 0 ：

( I − N ) − 1 = I + N + ⋯ + N q − 1 .

若 p ⁡ ( A ) = 0 且要算 ( A − a ⁢ I ) − 1 ，把多项式作带余除法：

p ⁡ ( t ) = ( t − a ) ⁢ q ⁡ ( t ) + p ⁡ ( a ) .

若 p ⁡ ( a ) ≠ 0 ，则

( A − a ⁢ I ) − 1 = − q ⁡ ( A ) p ⁡ ( a ) .

7. 初等矩阵与初等变换

左乘初等矩阵对应行变换，右乘对应列变换。

任务 合适操作
算行列式 行、列变换均可；跟踪符号和倍数
求秩、等价标准形 行、列变换均可
解 A ⁢ x = b 对增广矩阵作行变换
求列向量组的极大无关组 作行变换；最终回到原矩阵取列
求 A − 1 对 [ A ∣ I ] 作行变换
二次型合同化简 成对的对应行、列变换

列变换会改变未知量的含义，不能在解方程时随意混用。若明确追踪变量变换，则可以使用，但要恢复原变量。

8. 分块矩阵

分块乘法仍按“行乘列”，保持次序与尺寸相容：

( A B C D ) ⁢ ( X Y Z W ) = ( A ⁢ X + B ⁢ Z A ⁢ Y + B ⁢ W C ⁢ X + D ⁢ Z C ⁢ Y + D ⁢ W ) .

若 A , D 可逆：

( A B 0 D ) − 1 = ( A − 1 − A − 1 ⁢ B ⁢ D − 1 0 D − 1 ) .

若 A ⁢ B = C ，则 C 的列由 A 的列线性表示， C 的行由 B 的行线性表示。因此

r ⁡ ( [ A , A ⁢ B ] ) = r ⁡ ( A ) , r ⁡ ( B A ⁢ B ) = r ⁡ ( B ) .

若 A ⁢ B = 0 ，则 B 的每一列都是 A ⁢ x = 0 的解，且

r ⁡ ( A ) + r ⁡ ( B ) ≤ n ,

其中 n 是 A 的列数，也就是 B 的行数。

9. 矩阵方程

可逆情形：

A ⁢ X = B ⇒ X = A − 1 ⁢ B ; X ⁢ A = B ⇒ X = B ⁢ A − 1 ; A ⁢ X ⁢ B = C ⇒ X = A − 1 ⁢ C ⁢ B − 1 .

若 A 不可逆，将 A ⁢ X = B 按列拆成 A ⁢ x j = b j 。

A ⁢ X = B ⁢  有解 ⟺ r ⁡ ( A ) = r ⁡ ( [ A , B ] ) .

求得通解后，如果题目要求 X 可逆，还必须加上 det ⁡ X ≠ 0 。对于 A ⁢ X = X ⁢ B 一类方程，可以设 X = ( x i ⁢ j ) 比较元素，或按列解释乘法。

10. 补全：特殊矩阵与标准结构

10.1 对称、反对称和正交

类型 定义 常用结论
实对称 A T = A 实特征值；可正交对角化
实反对称 A T = − A 对角元素为零； x T ⁢ A ⁢ x = 0 ；奇数阶行列式为零
正交 A T ⁢ A = I A − 1 = A T ；行列均为标准正交组

任意实方阵分解为

A = A + A T 2 + A − A T 2 .

两个实对称矩阵的乘积对称，当且仅当它们交换。

10.2 几何结构辅助算幂（补充理解，对应原书试算路线）

平面旋转矩阵

R ⁡ ( θ ) = ( cos ⁡ θ − sin ⁡ θ sin ⁡ θ cos ⁡ θ )

满足 R ⁡ ( θ ) m = R ⁡ ( m ⁢ θ ) 。遇到旋转、反射、投影等结构，可先利用几何含义，避免连续乘法。

10.3 上三角矩阵的通用幂例

A = ( 1 a b 0 1 a 0 0 1 ) = I + N , N 3 = 0.

因此

A m = ( 1 m ⁢ a m ⁢ b + ( m 2 ) ⁢ a 2 0 1 m ⁢ a 0 0 1 ) .

这将原书“试算找规律”与“分解后二项式”统一起来。

10.4 一类常用互逆矩阵（原书第21页）

主对角为 a ≠ 0 、上对角为 − 1 、其余位置为零的上双对角矩阵 T ，其逆为

( T − 1 ) i ⁢ j = { a − ( j − i + 1 ) , j ≥ i , 0 , j < i .

令 a = 1 ，就得到上三角区域全为 1 的逆矩阵。可由有限几何级数证明： T = a ⁢ I − N ，其中 N 为上移矩阵， N n = 0 。

11. 补全：伴随矩阵的关系传递

原书例3.8总结以下正向结论：

  • A ⁢ B = B ⁢ A 推出 adj ⁡ ( A ) ⁢ B = B ⁢ adj ⁡ ( A ) 。
  • A , B 等价推出它们的伴随矩阵等价。
  • A , B 相似推出它们的伴随矩阵相似。
  • A , B 合同推出它们的伴随矩阵合同。

这些是正向推出，不能随意颠倒。例如三阶矩阵秩为 0 或 1 时，伴随矩阵都为零，故伴随矩阵等价并不能保证原矩阵等价。

相似有精确公式：

B = P − 1 ⁢ A ⁢ P ⟹ adj ⁡ ( B ) = P − 1 ⁢ adj ⁡ ( A ) ⁢ P .

合同有精确公式：若 B = C T ⁢ A ⁢ C ，则

adj ⁡ ( B ) = ( det ⁡ C ) 2 ⁢ C − 1 ⁢ adj ⁡ ( A ) ⁢ C − T .

右边是伴随矩阵的合同变换，取变换矩阵 ( det ⁡ C ) ⁢ C − T 即可。该恒等式对奇异 A 也成立。

12. 补全：初等矩阵的具体公式

定义 S i ⁢ j 为互换第 i , j 行的矩阵； T i ⁢ j ⁡ ( k ) 为将第 j 行的 k 倍加到第 i 行的矩阵； D i ⁡ ( k ) 为第 i 行乘 k ≠ 0 的矩阵。均由单位矩阵进行一次对应行变换得到。

矩阵 行列式 逆矩阵 转置
S i ⁢ j − 1 S i ⁢ j S i ⁢ j
T i ⁢ j ⁡ ( k ) 1 T i ⁢ j ⁡ ( − k ) T j ⁢ i ⁡ ( k )
D i ⁡ ( k ) k D i ⁢ ( 1 / k ) D i ⁡ ( k )

右乘时需按定义辨别方向： A ⁢ T i ⁢ j ⁡ ( k ) 对应将第 i 列的 k 倍加到第 j 列，因为 T i ⁢ j ⁡ ( k ) = I + k ⁢ e i ⁢ e j T 。

伴随矩阵可由 adj ⁡ ( E ) = det ⁡ E E − 1 得到，例如

adj ⁡ ( S i ⁢ j ) = − S i ⁢ j , adj ⁡ ( T i ⁢ j ⁡ ( k ) ) = T i ⁢ j ⁡ ( − k ) .

13. 补全：可逆判据的完整联系

对 n 阶实方阵 A ，以下条件等价：

  • det ⁡ A ≠ 0 ，或 r ⁡ ( A ) = n 。
  • A ⁢ x = 0 只有零解。
  • 对每个 b ∈ R n ， A ⁢ x = b 有解；也等价于对每个 b 有唯一解。
  • 行向量组或列向量组线性无关，分别构成 R n 的一个基。
  • 0 不是特征值。
  • 初等行变换可以化为 I ；或初等列变换可以化为 I 。
  • 可以写成有限个初等矩阵的乘积。
  • A T ⁢ A 正定；也等价于 A ⁢ A T 正定。

量词不能删：“对某个 b 有解”不能推出可逆；零矩阵对于 b = 0 就有解。

14. 补全：等价标准形与分块逆

若 A 为 m × n 矩阵且秩为 r ，则存在可逆 P , Q 使

P ⁢ A ⁢ Q = ( I r 0 0 0 ) .

从这个式子可提取 A = B ⁢ C ，其中 B 为 m × r 列满秩矩阵， C 为 r × n 行满秩矩阵。另一做法是选原矩阵的主元列作为 B ，将每列的表示系数拼成 C 。

若 A , D 可逆，原书还列出

( A 0 C D ) − 1 = ( A − 1 0 − D − 1 ⁢ C ⁢ A − 1 D − 1 ) .

副对角块情形：

( 0 A D 0 ) − 1 = ( 0 D − 1 A − 1 0 ) .

块内的因子顺序不能按照普通数的交换规则调换。

15. 矩阵方程的通解写法（补充理解）

若 A ⁢ X = B 有一个特解 X 0 ，且 H 的列构成 A ⁢ x = 0 的基础解系，则

X = X 0 + H ⁡ K ,

其中 K 是尺寸相容的任意矩阵。每列可以使用各自独立的参数，不能强行让不同列共用一组参数。

若要求 P − 1 ⁢ A ⁢ P = J ，先改写为 A ⁢ P = P ⁢ J ，按列求 P ；最后必须检验 det ⁡ P ≠ 0 。若要求 B 2 = A ，可先利用 A ⁢ B = B ⁢ A 缩小待定元素范围，但仅有交换关系不等于已经求出平方根。

16. 本讲复习检查

  • 运算前先看形状，运算后检查结果尺寸。
  • 二项式展开前先检查是否交换。
  • 能分辨秩一、幂零、旋转、相似和满秩分解五类结构。
  • 伴随矩阵关系可使用正向推出，但不随意反推。
  • 能正确解释初等矩阵的左乘和右乘。
  • 解矩阵方程后检查题目要求的可逆、对称或正交条件。
