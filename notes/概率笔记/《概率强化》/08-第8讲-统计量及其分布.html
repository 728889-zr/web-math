第 8 讲　统计量及其分布

1. 定义与直接结论

1.1 总体、样本与统计量【基础补充】

  • 总体：研究对象的数量指标 X 及其分布。
  • 简单随机样本 X 1 , … , X n ：相互独立，且都与总体 X 同分布，即 iid。
  • 统计量 T = g ⁡ ( X 1 , … , X n ) ：只含样本，不含任何未知参数的样本函数。
  • 将观测值代入统计量后得到的具体数称为统计量的观察值。

1.2 常用统计量

样本均值：

X ¯ = 1 n ⁢ ∑ i = 1 n X i .

样本方差与样本标准差：

S 2 = 1 n − 1 ⁢ ∑ i = 1 n ( X i − X ¯ ) 2 = 1 n − 1 ⁢ ( ∑ X i 2 − n ⁢ X ¯ 2 ) ,
S = S 2 .

样本 k 阶原点矩、 k 阶中心矩：

A k = 1 n ⁢ ∑ X i k , B k = 1 n ⁢ ∑ ( X i − X ¯ ) k .

顺序统计量：把样本从小到大排列为

X ( 1 ) ≤ ⋯ ≤ X ( n ) .

其中 X ( 1 ) 为最小值， X ( n ) 为最大值。

若总体 E ⁢ X = μ , D ⁢ X = σ 2 ，则

E ⁡ X ¯ = μ , D ⁢ X ¯ = σ 2 n , E ⁡ ( S 2 ) = σ 2 .

1.3 χ 2 、 t 、 F 分布

  • 若 Z 1 , … , Z n ∼ i ⁢ i ⁢ d N ⁡ ( 0 , 1 ) ，则 ∑ Z i 2 ∼ χ 2 ⁡ ( n ) 。
  • 若 Z ∼ N ⁡ ( 0 , 1 ) 、 V ∼ χ 2 ⁡ ( n ) 且独立，则
    Z V / n ∼ t ⁡ ( n ) .
  • 若 U ∼ χ 2 ⁡ ( n 1 ) 、 V ∼ χ 2 ⁡ ( n 2 ) 且独立，则
    U / n 1 V / n 2 ∼ F ⁡ ( n 1 , n 2 ) .

可加性：独立时

χ 2 ⁡ ( n 1 ) + χ 2 ⁡ ( n 2 ) ∼ χ 2 ⁡ ( n 1 + n 2 ) .

倒数性质：

F ∼ F ⁡ ( n 1 , n 2 ) ⇒ 1 F ∼ F ⁡ ( n 2 , n 1 ) .

1.4 正态总体下的核心抽样结论

若 X 1 , … , X n ∼ i ⁢ i ⁢ d N ⁡ ( μ , σ 2 ) ，则

  1. X ¯ ∼ N ⁡ ( μ , σ 2 n ) .
  2. 标准化得到
    ∑ i = 1 n ( X i − μ σ ) 2 ∼ χ 2 ⁡ ( n ) .
  3. ( n − 1 ) ⁢ S 2 σ 2 ∼ χ 2 ⁢ ( n − 1 ) .
  4. == X ¯ 与 S 2 相互独立。==
  5. n ⁢ ( X ¯ − μ ) S ∼ t ⁢ ( n − 1 ) .
  6. n ⁢ ( X ¯ − μ ) 2 S 2 ∼ F ⁡ ( 1 , n − 1 ) .

1.5 两个正态总体的常用结论

两独立样本分别来自 N ⁡ ( μ 1 , σ 1 2 ) 、 N ⁡ ( μ 2 , σ 2 2 ) ：

X ¯ − Y ¯ ∼ N ⁡ ( μ 1 − μ 2 , σ 1 2 n + σ 2 2 m ) .
S X 2 / σ 1 2 S Y 2 / σ 2 2 ∼ F ⁡ ( n − 1 , m − 1 ) .

若 σ 1 2 = σ 2 2 = σ 2 未知，令

S p 2 = ( n − 1 ) ⁢ S X 2 + ( m − 1 ) ⁢ S Y 2 n + m − 2 ,

则

X ¯ − Y ¯ − ( μ 1 − μ 2 ) S p ⁢ 1 / n + 1 / m ∼ t ⁢ ( n + m − 2 ) .

1.6 上侧分位点

本笔记采用教材常用记号：

P ⁡ ( Z > z α ) = α ,
P ⁡ ( χ 2 ⁡ ( n ) > χ α 2 ⁡ ( n ) ) = α ,
P ⁡ ( t ⁡ ( n ) > t α ⁡ ( n ) ) = α ,
P ⁡ ( F ⁡ ( n 1 , n 2 ) > F α ⁡ ( n 1 , n 2 ) ) = α .

其中

t 1 − α ⁡ ( n ) = − t α ⁡ ( n ) ,
F 1 − α ⁡ ( n 1 , n 2 ) = 1 F α ⁡ ( n 2 , n 1 ) .

2. 考研做题固定流程

第一步：确认总体是否正态

正态总体是 X ¯ 与 S 2 独立、卡方结论和 t / F 枢轴量成立的关键条件。题目没给正态时，不能无条件套这些精确分布。

第二步：把统计量配成标准结构

看到平方和：

  • 围绕已知 μ 的平方和 → 自由度通常为 n ；
  • 围绕样本均值 X ¯ 的离差平方和 → 自由度为 n − 1 。

看到正态量除以独立卡方量平方根 → t ；看到两个独立卡方量按自由度相除 → F 。

第三步：处理多个样本

  1. 先确认两组样本相互独立。
  2. 均值差先算均值和方差。
  3. 方差比配成 F 。
  4. 同方差未知时使用合并方差 S p 2 。

第四步：核对自由度

自由度是选择题最常见陷阱。每估计一个独立线性约束，通常损失一个自由度；样本离差满足 ∑ ( X i − X ¯ ) = 0 ，所以只剩 n − 1 个自由度。

3. 补充 / 易错点

高频错误
  • 样本方差分母是 n − 1 ，不是 n ；除非题目另行定义。
  • “统计量不含未知参数”是定义要求。
  • X ¯ 与 S 2 独立是正态总体的特殊结论，不是任意总体都成立。
  • 构造 t 时，分母是 S / n 。
  • F 分布交换分子分母后，自由度也必须交换。
  • X 2 与一个 χ 2 变量同分布，不表示二者是同一个随机变量。

做题口诀：先正态、再标准化；平方和找卡方，正态除根号卡方找 t ，卡方比找 F 。
