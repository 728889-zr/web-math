第6讲 向量组

本页定位

使用说明单位矩阵统一写 I ，伴随矩阵写 adj ⁡ ( A ) 。

1. 线性表示就是解方程

令 A = [ α 1 , … , α s ] ，则

β = x 1 ⁢ α 1 + ⋯ + x s ⁢ α s ⟺ A ⁢ x = β .
秩判据 线性表示结论
r ⁡ ( A ) < r ⁡ ( [ A , β ] ) 不能表示
r ⁡ ( A ) = r ⁡ ( [ A , β ] ) = s 唯一表示
r ⁡ ( A ) = r ⁡ ( [ A , β ] ) < s 无穷多种表示

这里 s 是向量个数，也就是系数未知量个数。

若 β 同时由两组向量表示，写成

A ⁢ u = B ⁢ v ⟺ [ A , − B ] ⁢ ( u v ) = 0.

求出 u , v 后，代回 β = A ⁢ u ；求到的系数向量与最终所求的 β 不是同一个对象。

2. 线性相关与无关

α 1 , … , α s ⁢  无关 ⟺ ∑ i = 1 s k i ⁢ α i = 0 ⁢  只有全零系数 ⟺ r ⁡ ( A ) = s .

相关则存在不全为零的系数使组合为零。

重要结论：

  • n 维向量超过 n 个，必相关。
  • n 个 n 维向量可用行列式判定；少于 n 个一般用秩。
  • 无关组的任意部分仍无关；相关部分包含在更大组内，使更大组相关。
  • 无关组对应增加分量后仍无关；相关组对应删除分量后仍相关。
  • 若一组 s 个向量能表示另一组 t > s 个向量，则后者相关。
  • 被表示向量组的秩不大于表示向量组的秩。

若 α 1 , … , α s 无关，则增加 β 后相关，当且仅当 β 可由原组表示。

补充：左乘矩阵后，线性相关性如何变化

设

B = [ α 1 , … , α s ] ,

则

A ⁢ B = [ A ⁢ α 1 , … , A ⁢ α s ] .

恒有

r ⁡ ( A ⁢ B ) ≤ r ⁡ ( B ) .

因此：

A ⁢ α 1 , … , A ⁢ α s ⁢  线性无关 ⇒ α 1 , … , α s  线性无关

等价地，取逆否命题：

α 1 , … , α s ⁢  线性相关 ⇒ A ⁢ α 1 , … , A ⁢ α s  线性相关

证明很直接：若

k 1 ⁢ α 1 + ⋯ + k s ⁢ α s = 0

存在不全为零的系数，则左乘 A ：

k 1 ⁢ A ⁢ α 1 + ⋯ + k s ⁢ A ⁢ α s = 0 ,

所以变换后的向量组也相关。

易错点

原向量组无关，左乘 A 后不一定仍无关，因为 A 可能把某些方向压成零。

只有当 A 列满秩时，才有

r ⁡ ( A ⁢ B ) = r ⁡ ( B ) ,

此时线性相关性完全保持。

3. 极大线性无关组

极大无关组：本身无关，且原组所有向量均能由它表示。成员数等于原向量组的秩。

求解流程：

  1. 把向量按列组成 A 。
  2. 仅作初等行变换，化为阶梯形。
  3. 找主元列的编号。
  4. 回到原矩阵取相同编号的列。
  5. 需要表示关系时，从变换后的矩阵读取并还原系数。
主元列的含义

阶梯形的主元列帮助选择原向量；不能把变换后的列当成原向量组的极大无关组直接提交。

若选出的原列组成 C ，其余各列按这些列表示，就得到满秩分解 A = C ⁢ D 。

4. 抽象向量关系

优先将关系转为矩阵方程，如 A ⁢ α = 0 、 A ⁢ α = λ ⁢ α 、 A ⁢ B = 0 。

原书典型结论：若

A k − 1 ⁢ α ≠ 0 , A k ⁢ α = 0 ,

则 α , A ⁢ α , … , A k − 1 ⁢ α 线性无关。

证明方法：设组合为零，左乘 A k − 1 得第一个系数为零；再左乘 A k − 2 ，依次消去所有系数。

对于 n 阶矩阵，还可推出 ker ⁡ A n = ker ⁡ A n + 1 ，即零空间在至多 n 次幂后稳定。

5. 向量组等价

两组向量等价，是指能够互相线性表示，即张成空间相同：

span ⁡ ( α 1 , … , α s ) = span ⁡ ( β 1 , … , β t ) .

矩阵判据：

r ⁡ ( A ) = r ⁡ ( B ) = r ⁡ ( [ A , B ] ) .

**只有 r ⁡ ( A ) = r ⁡ ( B ) 不够。**相同维数的两个不同子空间可以有相同的秩。

若已知一组能表示另一组，再加两组秩相等，就能推出等价。

6. 向量空间、基、坐标

基既要无关，又要张成整个空间。维数等于基所含向量个数。

在基 E = [ e 1 , … , e r ] 下，每个向量唯一表示为 α = E ⁢ x ， x 为坐标。

若旧基为 E 、新基为 F ，约定

F = E ⁢ C ,

则 C 的第 j 列为新基第 j 个向量在旧基下的坐标。对同一向量：

α = E ⁢ x = F ⁡ y = E ⁢ C ⁢ y ⟹ x = C ⁢ y , y = C − 1 ⁢ x .
不死记方向

先写出“新基 = 旧基 × 过渡矩阵”，再由同一向量的两种表示推导坐标公式。

规范正交基

规范正交基 = 一组基 + 两两正交 + 每个向量长度为 1：

α i T ⁢ α j = { 1 , i = j , 0 , i ≠ j .

求法： 先求普通基 → Schmidt 正交化 → 单位化

其中“正交”负责彼此垂直，“单位化”只负责把每个向量长度变成 1 。

7. 补全：线性关系与系数矩阵

7.1 线性组合形成新向量组

若 B = A ⁢ C ，则 B 的每一列是 A 的列的线性组合，所以

r ⁡ ( B ) ≤ r ⁡ ( A ) .

如果 A 的列线性无关，则进一步有 r ⁡ ( B ) = r ⁡ ( C ) 。此时新向量组是否无关，只需要看系数矩阵 C 是否列满秩。

若 C 为可逆方阵，则 A , B 等价，线性无关性也同时保持。

7.2 相关组中的某向量能否被其他向量表示

相关意味着至少存在一个向量可由其他向量表示，不意味着每一个都能。

给定关系 ∑ i k i ⁢ α i = 0 ，只有 k j ≠ 0 时，才可据此解出

α j = − ∑ i ≠ j k i k j ⁢ α i .

补充例： e 1 , e 1 , e 2 相关，但 e 2 不能由前两个表示。

7.3 两两无关不代表全组无关

在 R 2 中， e 1 , e 2 , e 1 + e 2 任意两者无关，但三个向量相关。题目强调“任意两个无关”时，要与“全组无关”分开处理。

8. 原书极大无关组例的系数读取

经行化简后出现

( 1 0 2 1 1 0 1 − 1 1 2 0 0 0 0 0 ) .

主元列为第1、2列，取原矩阵对应列 α 1 , α 2 ，可读出

α 3 = 2 ⁢ α 1 − α 2 , α 4 = α 1 + α 2 , α 5 = α 1 + 2 ⁢ α 2 .

因此

A = [ α 1 , α 2 ] ⁢ ( 1 0 2 1 1 0 1 − 1 1 2 ) .

原因是行变换等于左乘同一个可逆矩阵 P ； P ⁢ α j 之间的线性关系，左乘 P − 1 就还原为原列的同一关系。

9. 抽象无关性证明的完整步骤

对原书条件 A k − 1 ⁢ α ≠ 0 、 A k ⁢ α = 0 ，设

c 0 ⁢ α + c 1 ⁢ A ⁢ α + ⋯ + c k − 1 ⁢ A k − 1 ⁢ α = 0.

左乘 A k − 1 ，高次项均消失，得 c 0 ⁢ A k − 1 ⁢ α = 0 ，故 c 0 = 0 。再左乘 A k − 2 得 c 1 = 0 ；依次得到全部系数为零。

这同时说明 k ≤ n ，因为 n 维空间不能有超过 n 个无关向量。

若存在 A n + 1 ⁢ x = 0 而 A n ⁢ x ≠ 0 ，上述结论将产生 n + 1 个无关向量，矛盾。因此

ker ⁡ A n = ker ⁡ A n + 1 , r ⁡ ( A n ) = r ⁡ ( A n + 1 ) .

这里没有假设 A 本身幂零。

10. 向量组等价的方向检查

原书包含“第一组可由第二组表示，但第二组不能由第一组表示”的题型。先记张成空间为 U , V ：

U ⊆ V , V ⊈ U .

于是必有 dim ⁡ U < dim ⁡ V 。这可先排除一部分参数，但还应检查单向表示是否真的成立。

**补充反例：** span ⁡ ( e 1 ) 和 span ⁡ ( e 2 , e 3 ) 维数不同，却互不包含。所以“秩小于另一组”单独不能保证可表示。

11. 求基与坐标的操作归纳

  • 列空间的基：取原矩阵主元列。
  • 行空间的基：可取行阶梯形的非零行。
  • 零空间的基：求 A ⁢ x = 0 的基础解系。
  • 判断候选向量是否是某空间的基：属于该空间、无关、数量等于空间维数。

“基”总是相对于某个空间；极大无关组则相对于某个给定向量组。给定向量组的极大无关组是其张成空间的一个基。

12. 公共张成空间的维数

若 U = Col ⁡ ( A ) 、 V = Col ⁡ ( B ) ，则

dim ⁡ ( U ∩ V ) = r ⁡ ( A ) + r ⁡ ( B ) − r ⁡ ( [ A , B ] ) .

它来自 dim ⁡ ( U + V ) = dim ⁡ U + dim ⁡ V − dim ⁡ ( U ∩ V ) 。求公共向量时仍可解 A ⁢ u = B ⁢ v ；若两组内部各有相关向量，参数解的数量不直接等于交空间维数，需去除系数表示的冗余。

13. 本讲复习检查

  • 将线性表示翻译为非齐次方程，将无关性翻译为齐次方程只有零解。
  • 区分两两无关与全组无关。
  • 会从主元列编号返回原向量。
  • 判等价时检查空间包含，不能只比秩。
  • 会写“新基 = 旧基 × 过渡矩阵”，再推导坐标方向。
