条件概率、条件分布与“固定一个随机变量”的统一理解

1. 定义与直接结论

（1）三个最基本的概率对象

设事件 A , B 。

条件概率：已经知道 B 发生

P ⁡ ( A | B )

联合概率： A , B 同时发生

P ⁡ ( A ⁢ B ) = P ⁡ ( B ) ⁢ P ⁡ ( A | B )

总体概率：把不同条件情况重新合并 若 B 1 , B 2 , ⋯ 构成完备事件组：

P ⁡ ( A ) = ∑ i P ⁡ ( B i ) ⁢ P ⁡ ( A | B i )

三者关系可记为：

条件内部不乘权重；回到总体要把权重乘回来

（2）独立性到底起什么作用

若 A , B 独立：

P ⁡ ( A | B ) = P ⁡ ( A )

所以：

P ⁡ ( A ⁢ B ) = P ⁡ ( B ) ⁢ P ⁡ ( A )

注意：

独立性只负责把条件概率  P ⁡ ( A | B )  化成  P ⁡ ( A )

它不会把总体计算中的 P ⁡ ( B ) 消掉。

（3）条件分布

例如题目直接给：

Y | X = 1 ∼ U ⁡ ( 0 , 1 )

表示在“ X = 1 已经发生”的条件世界里， Y 已经服从新的分布 U ⁡ ( 0 , 1 ) 。

所以：

P ⁡ ( Y ≤ y | X = 1 ) = y , 0 ≤ y ≤ 1

这里不需要再乘 P ⁡ ( X = 1 ) 。

但若要求联合概率：

P ⁡ ( Y ≤ y , X = 1 )

则：

P ⁡ ( Y ≤ y , X = 1 ) = P ⁡ ( X = 1 ) ⁢ P ⁡ ( Y ≤ y | X = 1 )

2. 考研做题固定流程

类型一：题目真的问条件概率

例如：

P ⁡ ( X > 1 | Y = 1 )

此时已经进入 Y = 1 的条件世界。

若 X , Y 独立：

P ⁡ ( X > 1 | Y = 1 ) = P ⁡ ( X > 1 )

不乘 P ⁡ ( Y = 1 ) 。

类型二：问两个事件同时发生

例如：

P ⁡ ( X > 1 , Y = 1 )

永远先写：

P ⁡ ( X > 1 , Y = 1 ) = P ⁡ ( Y = 1 ) ⁢ P ⁡ ( X > 1 | Y = 1 )

若独立：

P ⁡ ( X > 1 , Y = 1 ) = P ⁡ ( Y = 1 ) ⁢ P ⁡ ( X > 1 )

类型三：题目问总体，但需要“固定一个变量”分类

例如：

P ⁡ ( X ⁢ Y > 2 )

若 Y 离散，取值为 y 1 , y 2 , ⋯ ，则先固定：

Y = y i

事件变成只关于 X 的条件事件：

P ⁡ ( X ⁢ Y > 2 | Y = y i )

最后必须加权回总体：

P ⁡ ( X ⁢ Y > 2 ) = ∑ i P ⁡ ( Y = y i ) ⁢ P ⁡ ( X ⁢ Y > 2 | Y = y i )

若 X , Y 独立，则：

P ⁡ ( X ⁢ Y > 2 | Y = y i )

可直接用 X 的边缘分布计算。

固定 Y = y i 只是为了分类，不代表最终题目变成条件概率。

类型四： P ⁡ ( X > Y )

本质是二维事件：

{ X > Y }

离散型：

P ⁡ ( X > Y ) = ∑ y P ⁡ ( Y = y ) ⁢ P ⁡ ( X > y | Y = y )

若独立：

P ⁡ ( X > Y ) = ∑ y P ⁡ ( Y = y ) ⁢ P ⁡ ( X > y )

连续型：

P ⁡ ( X > Y ) = ∫ P ⁡ ( X > y | Y = y ) ⁢ f Y ⁡ ( y ) d y

若独立：

P ⁡ ( X > Y ) = ∫ P ⁡ ( X > y ) ⁢ f Y ⁡ ( y ) d y

也可直接利用联合密度：

P ⁡ ( X > Y ) = ∬ x > y f X , Y ⁡ ( x , y ) d x ⁢ d ⁢ y

类型五： P ⁡ ( F ⁡ ( X ) > F ⁡ ( Y ) )

先处理函数关系，再算概率。

若 F 严格递增：

F ⁡ ( X ) > F ⁡ ( Y ) ⟺ X > Y

若 F 严格递减：

F ⁡ ( X ) > F ⁡ ( Y ) ⟺ X < Y

若 F 不单调，则要真正解：

F ⁡ ( x ) > F ⁡ ( y )

确定二维区域后再求概率。

类型六：题目直接给条件分布

例如：

Y | X = i ∼ U ⁡ ( 0 , i )

先直接按条件分布算：

P ⁡ ( Y ≤ y | X = i )

若最后要求 Y 的总体分布：

F Y ⁡ ( y ) = ∑ i P ⁡ ( X = i ) ⁢ P ⁡ ( Y ≤ y | X = i )

例如：

P ⁡ ( X = 1 ) = a , P ⁡ ( X = 2 ) = 1 − a

且：

Y ⁢ | X = 1 ∼ U ⁡ ( 0 , 1 ) , Y | ⁢ X = 2 ∼ U ⁡ ( 0 , 2 )

则对 0 ≤ y < 1 ：

P ⁡ ( Y ≤ y | X = 1 ) = y
P ⁡ ( Y ≤ y | X = 2 ) = y 2

最终：

F Y ⁡ ( y ) = a ⁢ y + ( 1 − a ) ⁢ y 2

3. 补充 / 易错点

（1）“固定 X = i ”有两种完全不同的含义

题目本身给条件：

P ⁡ ( A | X = i )

此时停留在条件世界，不乘 P ⁡ ( X = i ) 。

为了求总体自己分类：

P ⁡ ( A )

先讨论 X = i ，最后必须乘：

P ⁡ ( X = i ) ⁢ P ⁡ ( A | X = i )

（2）判断口诀

每次看到“ X = i ”先问：

最终求的是条件概率，还是总体概率？
  • 求 P ⁡ ( A | X = i ) ：不乘 P ⁡ ( X = i )
  • 求 P ⁡ ( A , X = i ) ：乘 P ⁡ ( X = i )
  • 求总体 P ⁡ ( A ) ：各条件分支乘权重后相加

（3）条件分布已经完成了“重新归一化”

例如：

Y | X = 1 ∼ U ⁡ ( 0 , 1 )

说明在 X = 1 条件下已经形成新的概率分布。

所以：

题目已给条件分布 ⇒ 直接按新分布计算

不需要再除或乘一次条件概率。

（4）连续型随机变量的 Y = y

若 Y 连续，则：

P ⁡ ( Y = y ) = 0

因此不能直接用：

P ⁡ ( A | Y = y ) = P ⁡ ( A , Y = y ) P ⁡ ( Y = y )

此时使用条件密度：

f X | Y ⁡ ( x | y ) = f X , Y ⁡ ( x , y ) f Y ⁡ ( y )

（5）最重要的统一关系

P ⁡ ( A ⁢ B ) = P ⁡ ( B ) ⁢ P ⁡ ( A | B )
A , B ⁢ 独立 ⇒ P ⁡ ( A | B ) = P ⁡ ( A )
P ⁡ ( A ) = ∑ i P ⁡ ( B i ) ⁢ P ⁡ ( A | B i )

一句记忆：

条件内部只算“这一支”；回到总体，再乘“进入这一支”的概率。

做题时先问一句：

我是“真的已知  X = i ”，还是“为了分类暂时令  X = i ⁢ ”？

**出处口径：**张宇/Kria 概率论中“条件概率、全概率公式、随机变量独立性、条件分布及二维随机变量”相关内容。这里将“固定一个随机变量再计算”的多种题型统一为“条件世界 → 加权回总体”的思路。
