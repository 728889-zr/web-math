1.反常积分 + 有界导数综合判断

题设核心：

f ⁡ ( x ) ≥ 0 , f ′ ⁡ ( x )  有界

即存在 M > 0 ：

| f ′ ⁡ ( x ) | ≤ M

① ∫ 0 ∞ f 2 ⁡ ( x ) d x 收敛 ⇒ ∫ 0 ∞ f ⁡ ( x ) d x 收敛？

错误

反例可取：

f ⁡ ( x ) = 1 ( 1 + x ) 3 / 4

则 f ≥ 0 、 f ′ 有界，且：

∫ 0 ∞ f 2 ⁡ ( x ) d x = ∫ 0 ∞ d x ( 1 + x ) 3 / 2 收敛

但：

∫ 0 ∞ f ⁡ ( x ) d x = ∫ 0 ∞ d x ( 1 + x ) 3 / 4 发散

本质：充分大时若 0 < f < 1 ，则 f 2 < f ，已知“小的收敛”不能推出“大的收敛”。

② ∫ 0 ∞ f ⁡ ( x ) d x 收敛 ⇒ ∫ 0 ∞ f 2 ⁡ ( x ) d x 收敛？

正确

关键先证：

∫ 0 ∞ f ⁡ ( x ) d x ⁢  收敛 + f ≥ 0 + f ′ ⁡  有界 ⇒ f ⁡ ( x ) → 0

反设 f ⁡ ( x ) ↛ 0 。由极限定义的否定，存在固定

ε 0 > 0

及 x n → ∞ ，使：

f ⁡ ( x n ) ≥ ε 0

由 | f ′ | ≤ M 和中值定理：

| f ⁡ ( x ) − f ⁡ ( x n ) | ≤ M ⁢ | x − x n |

故当：

| x − x n | < ε 0 2 ⁢ M

有：

f ⁡ ( x ) ≥ ε 0 2

即每次达到固定高度 ε 0 ，附近都会形成固定高度、固定宽度的一块正面积；若无穷多次出现，则与：

∫ 0 ∞ f ⁡ ( x ) d x < ∞

矛盾。因此：

f ⁡ ( x ) → 0

充分大时：

0 ≤ f ⁡ ( x ) < 1

所以：

0 ≤ f 2 ⁡ ( x ) ≤ f ⁡ ( x )

由“大收敛推小收敛”：

∫ 0 ∞ f 2 ⁡ ( x ) d x  收敛

③ lim x → ∞ ⁡ x 2 ⁢ f ⁡ ( x ) 存在 ⇒ ∫ 0 ∞ f ⁡ ( x ) d x 收敛

若该极限为有限值 A ≥ 0 ，则充分大时 x 2 ⁢ f ⁡ ( x ) 有界：

0 ≤ x 2 ⁢ f ⁡ ( x ) ≤ C

所以：

0 ≤ f ⁡ ( x ) ≤ C x 2

而：

∫ 1 ∞ 1 x 2 d x

收敛，因此：

∫ 1 ∞ f ⁡ ( x ) d x

收敛。

[ 0 , 1 ] 上因为 f 可导 ⇒ f 连续，所以：

∫ 0 1 f ⁡ ( x ) d x

是普通定积分，必为有限值。因此整体收敛。

我的易错点

1. f ′ 有界不代表 f ′ 有极限：

| f ′ ⁡ ( x ) | ≤ M ⇏ lim x → ∞ ⁡ f ′ ⁡ ( x )  存在

“有界导数”只表示函数变化速度受限，不表示最终朝固定方向变化。

2. 反常积分收敛本身不能推出 f ⁡ ( x ) → 0 ：

∫ 0 ∞ f ⁡ ( x ) d x ⁢  收敛 ⇏ f ⁡ ( x ) → 0

本题能推出，是因为额外有：

f ≥ 0 , f ′  有界

它们排除了“越来越窄的尖峰”。

3. f ⁡ ( x ) ↛ 0 的关键不是 f ⁡ ( x n ) > 0 ，而是存在固定门槛：

∃ ε 0 > 0 , x n → ∞ , | f ⁡ ( x n ) | ≥ ε 0

例如 1 / x 2 虽始终 > 0 ，但对任意固定 ε 0 > 0 ，最终都会小于它，所以仍然趋于 0 。

本题核心链：积分收敛 + 非负 + 导数有界 ⇒ f → 0 ；再用 f 2 ≤ f 做比较判敛。
