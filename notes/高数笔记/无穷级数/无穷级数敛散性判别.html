无穷级数敛散性判别

一、做题总流程

判断

∑ n = 1 ∞ a n

的敛散性，优先按下面顺序：

  1. 先算
lim n → ∞ ⁡ a n .

若

lim ⁡ a n ≠ 0

则级数一定发散。 2. 若 a n ≥ 0 ，按正项级数处理：比较、极限比较、比值、根值、积分判别等。 3. 若含 ( − 1 ) n ，先考虑绝对收敛；绝对值级数发散时，再考虑莱布尼茨或其他方法判断条件收敛。 4. 若通项结构复杂，不急着套判别法，先化简、等价、泰勒展开或构造望远镜结构。

必要条件
∑ a n ⁢  收敛 ⇒ a n → 0 ,

但

a n → 0

不能推出级数收敛。

二、几个必须熟记的标准级数

1. p 级数

∑ 1 n p ⁢ { 收敛 , p > 1 , 发散 , p ≤ 1.

其中

∑ 1 n

为调和级数，发散。

2. 等比级数

∑ q n

满足

| q | < 1 ⇒ 收敛

否则发散。

3. 对数型常用结论

∑ 1 n ⁢ ( ln ⁡ n ) p ⁢ { 收敛 , p > 1 , 发散 , p ≤ 1.

三、正项级数基本判别法

1. 比较判别法

设

0 ≤ a n ≤ b n .

则：

  • 若 ∑ b n 收敛，则 ∑ a n 收敛；
  • 若 ∑ a n 发散，则 ∑ b n 发散。 口诀：
小于收敛的 → 收敛；大于发散的 → 发散
比较方向不能反

已知“大级数收敛”才能推出小级数收敛；已知“小级数发散”才能推出大级数发散。

2. 极限比较判别法

若 a n , b n > 0 ，且

lim n → ∞ ⁡ a n b n = L , 0 < L < + ∞ ,

则

∑ a n  与  ∑ b n  同敛散

特别地：

a n ∼ b n ⟺ a n b n → 1 ,

此时两级数同敛散。

极限比较中 L = 1 完全有效
a n b n → 1

正是最好用的情况之一。

3. 比值判别法

若

lim n → ∞ ⁡ | a n + 1 a n | = q ,

则

{ q < 1 , 绝对收敛 , q > 1 , 发散 , q = 1 , 失效 .

因此一定区分：

a n b n → 1 ⇒ 极限比较法有效

而

a n + 1 a n → 1 ⇒ 比值判别法失效

4. 根值判别法

若

lim n → ∞ ⁡ | a n | n = q ,

则

{ q < 1 , 绝对收敛 , q > 1 , 发散 , q = 1 , 失效 .

指数、幂、阶乘混合时优先考虑比值法或根值法。

5. 积分判别法

若 f ⁡ ( x ) 在 [ 1 , + ∞ ) 上非负、连续且单调递减，则

∑ n = 1 ∞ f ⁡ ( n )  与  ∫ 1 + ∞ f ⁡ ( x ) d x  同敛散

适合通项本身就是容易积分的函数形式。

四、见到 f ⁡ ( n ) ：先化简通项

1. 幂与指数

见到

a n − b n

优先提出较大的指数因子，例如

a n − b n = a n ⁢ [ 1 − ( b a ) n ] .

见到复杂幂：

A n B n

优先写成

A n B n = e B n ⁢ ln ⁡ A n .

目的是把通项化成

1 n p , q n

等熟悉形式。

2. 见到 ln

优先使用

ln ⁡ a − ln ⁡ b = ln ⁡ a b ,
ln ⁡ a + ln ⁡ b = ln ⁡ ( a ⁢ b ) ,
ln ⁡ a b = b ⁢ ln ⁡ a .

常用估计：

ln ⁡ ( 1 + x ) ∼ x ( x → 0 ) .

例如

ln ⁡ ( 1 + 1 n 2 ) ∼ 1 n 2 .

3. 基本等价无穷小

当 x → 0 ：

sin ⁡ x ∼ x ,
tan ⁡ x ∼ x ,
ln ⁡ ( 1 + x ) ∼ x ,
e x − 1 ∼ x ,
1 − cos ⁡ x ∼ x 2 2 ,
( 1 + x ) α − 1 ∼ α ⁢ x .

因此看到

sin ⁡ 1 n , 1 − cos ⁡ a n , ln ⁡ ( 1 + 1 n p )

应迅速化成 p 级数比较。

4. 出现高阶相消：泰勒展开

若一阶等价后发生抵消，就继续展开：

ln ⁡ ( 1 + x ) = x − x 2 2 + x 3 3 + o ⁡ ( x 3 ) ,
e x = 1 + x + x 2 2 + o ⁡ ( x 2 ) ,
( 1 + x ) α = 1 + α ⁢ x + α ⁢ ( α − 1 ) 2 ⁢ x 2 + o ⁡ ( x 2 ) .

核心目标是找到

a n ∼ C n p

再直接用 p 级数判断。

五、见到 f ⁡ ( n ) 与 f ′ ⁡ ( n )

若通项中同时出现函数值和导数，优先考虑拉格朗日中值定理：

f ⁡ ( n + 1 ) − f ⁡ ( n ) = f ′ ⁡ ( ξ n ) , ξ n ∈ ( n , n + 1 ) .

若能比较

f ′ ⁡ ( ξ n )

与

f ⁡ ( n + 1 ) − f ⁡ ( n ) ,

则级数

∑ [ f ⁡ ( n + 1 ) − f ⁡ ( n ) ]

可以直接望远镜：

∑ k = 1 n [ f ⁡ ( k + 1 ) − f ⁡ ( k ) ] = f ⁡ ( n + 1 ) − f ⁡ ( 1 ) .
识别

看到 f ⁡ ( n ) , f ′ ⁡ ( n ) 同时出现：

优先想到中值定理 + 望远镜

六、见到 f ⁡ ( n ) − f ⁡ ( n − 1 )

优先考虑：

  1. 因式分解；
  2. 有理化；
  3. 中值定理；
  4. 直接望远镜。 例如
n + 1 − n = 1 n + 1 + n ∼ 1 2 ⁢ n .

又如

1 n p − 1 ( n + 1 ) p

本身具有望远镜结构。 口诀：

相邻两项之差 → 因式分解/有理化/望远镜

七、见到 f ⁡ ( a n )

1. 已知 a n → a > 0

则 a n 最终既有上界又远离 0 。 即存在 N ，当 n > N 时，

a 2 < a n < M .

因此可以把复杂的 f ⁡ ( a n ) 夹在常数倍之间，再使用比较判别法。

2. 已知 n p ⁢ a n → A

若

0 < A < + ∞ ,

则

a n ∼ A n p .

因此直接与

∑ 1 n p

比较。 若

n p ⁢ a n → 0 ,

则通常可得到

| a n | ≤ C n p

从而在 p > 1 时推出绝对收敛。

3. 常用缩放

当 x > 0 且足够小时：

x 1 + x ∼ x , x 1 − x ∼ x .

例如 0 < x < 1 / 2 时：

x 2 < x 1 + x < x ,
x < x 1 − x < 2 ⁢ x .

因此遇到

a n 1 ± a n

通常与 a n 同阶。

4. 指数为变数

若

a n → p ,

判断

∑ 1 n a n

时：

{ p > 1 , 收敛 , p < 1 , 发散 , p = 1 , 不能仅由极限判断 .

八、见到 f ⁡ ( a n , a n + 1 )

优先研究 a n 与 a n + 1 的关系。 常见处理：

  1. 用递推关系判断 a n 的单调性、有界性和极限；
  2. 有根号时有理化；
  3. 尝试化成
φ ⁡ ( a n + 1 ) − φ ⁡ ( a n ) ;
  1. 若关系复杂，可适当放缩后构造望远镜级数。 例如若能得到
0 ≤ u n ≤ C ⁢ ( a n + 1 − a n ) ,

则

∑ u n

可由右边望远镜控制。 口诀：

相邻两项同时出现 → 找差、找递推、造望远镜

九、见到 f ⁡ ( a n , b n )

1. 已知两级数关系

若能把

a n ⁢ b n

改写为

( n ⁢ a n ) ⁢ b n n ,

且已知

∑ n ⁢ | a n |

收敛，而

b n n

有界，则

∑ | a n ⁢ b n |

收敛。 本质：

把双通项拆成“可求和部分 × 有界部分”

2. 常用不等式

2 ⁢ | a ⁢ b | ≤ a 2 + b 2 .

因此看到乘积、平方根乘幂时，可将复杂乘积拆成两个已知正项级数。

十、见到 f ⁡ ( a n , n p )

若出现

a n n p ,

可用

2 ⁢ a ⁢ b ≤ a 2 + b 2 .

取

a = a n , b = 1 n p ,

则

a n n p ≤ 1 2 ⁢ ( a n + 1 n 2 ⁢ p ) .

若

∑ a n

收敛且

2 ⁢ p > 1 ,

则原级数收敛。

十一、见到 f ⁡ ( a n , S n )

设

S n = ∑ k = 1 n a k .

立即想到

a n = S n − S n − 1

再尝试把通项改写成关于 S n 的相邻差。 例如

a n S n 2 = S n − S n − 1 S n 2

常与

1 S n − 1 − 1 S n = S n − S n − 1 S n − 1 ⁢ S n

比较，从而构造望远镜。 若 a n > 0 ，则 S n 单调递增，并且

∑ a n ⁢  收敛 ⟺ S n  有上界

注意这个“有界判据”只可直接用于正项级数。

十二、含 ( − 1 ) n 的级数

1. 先判断绝对收敛

先研究

∑ | a n | .

若收敛，则原级数绝对收敛。 若绝对值级数发散，再研究是否条件收敛。

2. 莱布尼茨判别法

若

a n = ( − 1 ) n − 1 ⁢ b n , b n > 0 ,

且

b n ↓ 0 ,

则

∑ ( − 1 ) n − 1 ⁢ b n  收敛

若同时

∑ b n

发散，则原级数条件收敛。

3. 条件收敛的定义

∑ a n ⁢  条件收敛 ⟺ ∑ a n  收敛且  ∑ | a n |  发散

所以题目明确说“条件收敛”，就一定意味着“不绝对收敛”。

4. 含 ( − 1 ) n 但不能直接用莱布尼茨

若绝对值部分

| a n |

不单调，不能硬套莱布尼茨。 可考虑：

  • 把奇偶项两两合并；
  • 研究偶数部分和 S 2 ⁢ n ；
  • 泰勒展开；
  • 将通项拆成若干熟悉级数。

5. ( − 1 ) n 藏在函数内部

例如

ln ⁡ ( 1 + ( − 1 ) n n p ) .

应先泰勒展开：

ln ⁡ ( 1 + x ) = x − x 2 2 + O ⁡ ( x 3 ) .

得到

ln ⁡ ( 1 + ( − 1 ) n n p ) = ( − 1 ) n n p − 1 2 ⁢ n 2 ⁢ p + O ⁡ ( 1 n 3 ⁢ p ) .

再分别判断：

  • 交错部分；
  • 正项修正部分。 这类题不能只看到 ( − 1 ) n 就直接套莱布尼茨。

十三、拆项法

若通项能写成

a n = b n + c n ,

可分别研究

∑ b n , ∑ c n .

若一个收敛、一个发散，则原级数发散。 但：

发散 + 发散不能直接判断

因为可能发生抵消。 见到

h ⁡ ( n ) f ⁡ ( n ) ⁢ g ⁡ ( n )

也可考虑部分分式：

h ⁡ ( n ) f ⁡ ( n ) ⁢ g ⁡ ( n ) = A ⁡ ( n ) f ⁡ ( n ) + B ⁡ ( n ) g ⁡ ( n ) .

十四、绝对值判别

若

∑ | a n |

收敛，则

∑ a n  一定收敛

常用基本不等式：

| a + b | ≤ | a | + | b | ,
2 ⁢ | a ⁢ b | ≤ a 2 + b 2 .

遇到复杂符号级数，若能直接把绝对值压到两个已知收敛正项级数之和上，通常最省事。

十六、最容易混淆的结论

1. a n → 0 不能推出级数收敛

它只是级数收敛的必要条件。

2. 极限比较法中极限为 1 不失效
a n b n → 1 ⇒ ∑ a n , ∑ b n  同敛散 .
3. 比值/根值判别中极限为 1 才失效
a n + 1 a n → 1

或

a n n → 1

均不能直接判断。

4. 条件收敛一定不是绝对收敛
条件收敛 = 原级数收敛 + 绝对值级数发散 .
5. 莱布尼茨必须检查单调趋零

只有出现 ( − 1 ) n 还不够。

6. 正项级数优先比较，不要一上来硬算

强化题大量复杂通项最终只是为了化成

1 n p

或几何级数。

十七、考试中的核心目标

无穷级数题的本质通常不是“把级数求和”，而是把复杂通项化成一个熟悉的比较对象：
