记忆规律

  • e x ：所有次幂都有，系数为 1 / n !
  • sin ⁡ x ：只有奇次，正负交替
  • cos ⁡ x ：只有偶次，正负交替
  • ln ⁡ ( 1 + x ) ：所有次幂都有，分母就是次数，正负交替
  • 1 1 − x ：全部为正
  • 1 1 + x ：正负交替

做极限时不要默认展开越多越好：先判断最低需要保留到哪一阶，尤其加减出现主项抵消时再继续展开。

三角函数常见化简

1. 根号型：优先看能否配平方

1 − cos ⁡ x = 2 ⁢ sin 2 ⁡ x 2 , 1 + cos ⁡ x = 2 ⁢ cos 2 ⁡ x 2

所以

1 − cos ⁡ x = 2 ⁢ | sin ⁡ x 2 |
1 + cos ⁡ x = 2 ⁢ | cos ⁡ x 2 |

以及

1 + sin ⁡ x = ( sin ⁡ x 2 + cos ⁡ x 2 ) 2
1 − sin ⁡ x = ( cos ⁡ x 2 − sin ⁡ x 2 ) 2

因此

1 + sin ⁡ x = | sin ⁡ x 2 + cos ⁡ x 2 |
1 − sin ⁡ x = | cos ⁡ x 2 − sin ⁡ x 2 |

易错： u 2 = | u | ，根号化简注意绝对值。

2. 半角分式

sin ⁡ x 1 + cos ⁡ x = tan ⁡ x 2
sin ⁡ x 1 − cos ⁡ x = cot ⁡ x 2
1 − cos ⁡ x sin ⁡ x = tan ⁡ x 2
1 + cos ⁡ x sin ⁡ x = cot ⁡ x 2

以及

1 − cos ⁡ x 1 + cos ⁡ x = | tan ⁡ x 2 |
1 + cos ⁡ x 1 − cos ⁡ x = | cot ⁡ x 2 |

3. 弧长/根号常见形式

1 + tan 2 ⁡ x = sec 2 ⁡ x

所以

1 + tan 2 ⁡ x = | sec ⁡ x |

同理

1 + cot 2 ⁡ x = | csc ⁡ x |

4. 合并与降幂

a ⁢ sin ⁡ x + b ⁢ cos ⁡ x = a 2 + b 2 ⁢ sin ⁡ ( x + φ )

因此

| a ⁢ sin ⁡ x + b ⁢ cos ⁡ x | ≤ a 2 + b 2

以及

sin 2 ⁡ x = 1 − cos ⁡ 2 ⁢ x 2
cos 2 ⁡ x = 1 + cos ⁡ 2 ⁢ x 2
sin ⁡ x ⁢ cos ⁡ x = 1 2 ⁢ sin ⁡ 2 ⁢ x

5. 做题识别顺序

1 ± sin ⁡ x ,   1 ± cos ⁡ x ⇒ 半角 / 配平方
根号 ⇒ 找平方 + 判断绝对值
sin ⁡ x 1 ± cos ⁡ x ⇒ tan ⁡ x 2 ,   cot ⁡ x 2
偶次幂 ⇒ 降幂

一句记忆：根号先找平方， 1 ± cos ⁡ x 先半角， sin ⁡ x / ( 1 ± cos ⁡ x ) 先想半角正切。
