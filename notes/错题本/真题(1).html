2005-8--F(x) 可以由f(x)表示

题目

设 F ⁡ ( x ) 是连续函数 f ⁡ ( x ) 的一个原函数，“ M ⇔ N ”表示“ M 的充分必要条件是 N ”，则必有（　）。

  • A. F ⁡ ( x ) 是偶函数 ⇔ f ⁡ ( x ) 是奇函数
  • B. F ⁡ ( x ) 是奇函数 ⇔ f ⁡ ( x ) 是偶函数
  • C. F ⁡ ( x ) 是周期函数 ⇔ f ⁡ ( x ) 是周期函数
  • D. F ⁡ ( x ) 是单调函数 ⇔ f ⁡ ( x ) 是单调函数

错因： 对于偶函数的定义

解答与答疑

设 f ⁡ ( − x ) = − f ⁡ ( x ) ，令 F ⁡ ( x ) = ∫ a x f ⁡ ( t ) d t

则 F ⁡ ( − x ) = ∫ a − x f ⁡ ( t ) d t = t = − u ∫ − a x f ⁡ ( − u ) ⁢ ( − d ⁢ u ) = ∫ − a x f ⁡ ( u ) d u = ∫ − a a f ⁡ ( u ) d u + ∫ a x f ⁡ ( u ) d u = ∫ a x f ⁡ ( u ) d u = F ⁡ ( x ) ,

于是 F ⁡ ( x ) 为偶函数； 反之，设 F ⁡ ( − x ) = F ⁡ ( x ) ，两边求导得 − F ′ ⁡ ( − x ) = F ′ ⁡ ( x ) ，或 f ⁡ ( − x ) = − f ⁡ ( x ) ，即 f ⁡ ( x ) 为奇函数，应选(A).

*==🔴2008-19--傅里叶级数==

题目

将函数

f ⁡ ( x ) = 1 − x 2 , 0 ≤ x ≤ π ,

展开成余弦级数，并求

∑ n = 1 ∞ ( − 1 ) n − 1 n 2

的和。

关联笔记： 傅里叶系数、延拓及特殊点代入 错因： 非周期函数傅里叶级数的应用。

复盘提示

余弦展开对应偶延拓；特殊点应按实际系数选择，不能机械地把“交错级数”对应到端点。

解答与答疑

余弦级数及所求和为

1 − x 2 = 1 − π 2 3 + 4 ⁢ ∑ n = 1 ∞ ( − 1 ) n − 1 n 2 ⁢ cos ⁡ n ⁢ x , 0 ≤ x ≤ π ,
∑ n = 1 ∞ ( − 1 ) n − 1 n 2 = π 2 12 .

① 非周期函数也能作傅里叶展开吗？

能。题目只给出 [ 0 , π ] 上的函数，并没有要求原来的多项式 1 − x 2 在整个实轴上是周期函数。

“展开成余弦级数”表示：先把它偶延拓到 [ − π , π ] ，再作 2 ⁢ π 周期延拓。由于本题的多项式本来就是偶函数，偶延拓在 [ − π , π ] 上仍为 1 − x 2 。

最终的级数代表一个周期函数；它在原区间 [ 0 , π ] 上等于题目给定的 f ⁡ ( x ) 。原区间外，一般不再等于未作周期延拓的多项式 1 − x 2 。

只写余弦项，是因为偶延拓后的正弦系数为 0 。

② 计算系数，注意常数项是 a 0 / 2 。

写成

f ⁡ ( x ) = a 0 2 + ∑ n = 1 ∞ a n ⁢ cos ⁡ n ⁢ x ,

其中

a 0 = 2 π ⁢ ∫ 0 π ( 1 − x 2 ) d x = 2 − 2 ⁢ π 2 3 .

对 n ≥ 1 ，

a n = 2 π ⁢ ∫ 0 π ( 1 − x 2 ) ⁢ cos ⁡ n ⁢ x d ⁢ x .

因为 ∫ 0 π cos ⁡ n ⁢ x d ⁢ x = 0 ，只需求 ∫ 0 π x 2 ⁢ cos ⁡ n ⁢ x d ⁢ x 。两次分部积分可得

∫ 0 π x 2 ⁢ cos ⁡ n ⁢ x d ⁢ x = − 2 n ⁢ ∫ 0 π x ⁢ sin ⁡ n ⁢ x d ⁢ x , ∫ 0 π x ⁢ sin ⁡ n ⁢ x d ⁢ x = [ − x ⁢ cos ⁡ n ⁢ x n ] 0 π + 1 n ⁢ ∫ 0 π cos ⁡ n ⁢ x d ⁢ x = − π ⁢ ( − 1 ) n n .

因此

∫ 0 π x 2 ⁢ cos ⁡ n ⁢ x d ⁢ x = 2 ⁢ π ⁢ ( − 1 ) n n 2 ,
a n = − 2 π ⋅ 2 ⁢ π ⁢ ( − 1 ) n n 2 = 4 ⁢ ( − 1 ) n − 1 n 2 .

代回即得到上述展开式。偶周期延拓在 0 , π 两端也连续，所以这里端点处同样等于原函数值。

③ 为什么代 x = 0 ，而不是看到交错符号就代 x = π ？

要看展开式中已经有什么系数。本题的 a n 自带 ( − 1 ) n − 1 / n 2 ；目标正是这些系数去掉因子 4 后的和。因此取 x = 0 ，使 cos ⁡ n ⁢ x = 1 ：

1 = 1 − π 2 3 + 4 ⁢ ∑ n = 1 ∞ ( − 1 ) n − 1 n 2 ,

便得所求结果。若代 x = π ，反而会把系数中的交错符号消掉。

**使用顺序：**确定要作哪种延拓 → 算系数 → 核对代入点的连续性 → 让三角因子变成目标所需的系数。

2008-23--估计值和估计量

题目

（本题满分 11 分）设 X 1 , X 2 , … , X n 是总体 N ⁡ ( μ , σ 2 ) 的简单随机样本，记

X ¯ = 1 n ⁢ ∑ i = 1 n X i , S 2 = 1 n − 1 ⁢ ∑ i = 1 n ( X i − X ¯ ) 2 ,
T = X ¯ 2 − 1 n ⁢ S 2 .

（Ⅰ）证明 T 是 μ 2 的无偏估计量；

（Ⅱ）当 μ = 0 , σ = 1 时，求 D ⁡ ( T ) 。

关联笔记： 估计量与估计值 · 正态总体的抽样分布 · 独立性与卡方分布 错因： μ 是估计值吗？估计值的分布应该怎么理解，再怎么去求呢？T 呢，也是估计值吗，还是什么？

解答与答疑

结论： E ⁡ ( T ) = μ 2 ；当 μ = 0 , σ = 1 时， D ⁡ ( T ) = 2 / [ n ⁢ ( n − 1 ) ] 。以下 n ≥ 2 。

① 先回答概念： μ 不是估计值， T 是估计量。

这里的字母是希腊字母 μ 。在本题的经典参数估计框架下，它表示固定但未知的总体均值，不是随机变量。

对象 本题中的身份 是否随重复抽样变化
μ 、 σ 2 总体参数 否
μ 2 待估计的参数函数 否
X 1 , … , X n 随机样本 是
X ¯ 样本均值，也是 μ 的估计量 是
S 2 样本方差，也是 σ 2 的估计量 是
T = X ¯ 2 − S 2 / n 统计量，也是本题用于估计 μ 2 的估计量 是
t = x ¯ 2 − s 2 / n 把一组具体样本值代入后得到的估计值 样本一旦固定，就是一个数

所以，通常讨论的是估计量 T 的抽样分布。想象反复抽取 n 个样本，每次算出一个 T ；这些可能结果及其概率构成 T 的分布。

已经算出的某一次估计值 t 是具体数字，不再需要给这个数字另求抽样分布。已知样本值也不等于知道了真实参数。

② 第Ⅰ问：无偏性只需证明 E ⁡ ( T ) = μ 2 。

由简单随机样本的基本性质，

E ⁡ ( X ¯ ) = μ , D ⁡ ( X ¯ ) = σ 2 n , E ⁡ ( S 2 ) = σ 2 .

注意 E ⁡ ( X ¯ 2 ) 不能直接写成 [ E ⁡ ( X ¯ ) ] 2 ，应使用

E ⁡ ( X ¯ 2 ) = D ⁡ ( X ¯ ) + [ E ⁡ ( X ¯ ) ] 2 = σ 2 n + μ 2 .

于是

E ⁡ ( T ) = E ⁡ ( X ¯ 2 ) − 1 n ⁢ E ⁡ ( S 2 ) = μ 2 + σ 2 n − σ 2 n = μ 2 .

因此 T 是 μ 2 的无偏估计量。这里减去 S 2 / n ，正是用来抵消 X ¯ 2 的 σ 2 / n 偏差。

③ 第Ⅱ问：先分别识别 X ¯ 2 与 S 2 的分布。

当 μ = 0 , σ = 1 时，

X ¯ ∼ N ⁡ ( 0 , 1 n ) .

标准化后 n X ¯ ∼ N ⁡ ( 0 , 1 ) ，所以

U = n ⁢ X ¯ 2 ∼ χ 2 ⁡ ( 1 ) .

另一方面，正态样本有

V = ( n − 1 ) ⁢ S 2 ∼ χ 2 ⁢ ( n − 1 ) .

正态总体下 X ¯ 与 S 2 独立，因此它们的函数 X ¯ 2 与 S 2 也独立，进而 U , V 独立。

把 T 写成

T = 1 n ⁢ ( U − V n − 1 ) .

这已经说明 T 的抽样分布可表示为两个独立卡方变量的加权差；它不是这里可直接套用的一个普通卡方、 t 或 F 分布。本题只问方差，不必推完整密度。

④ 利用独立性计算方差，减号不会使方差相减。

由 D ⁡ ( χ 2 ⁡ ( k ) ) = 2 ⁢ k ，得到

D ⁡ ( T ) = 1 n 2 ⁢ [ D ⁡ ( U ) + D ⁡ ( V ) ( n − 1 ) 2 ] = 1 n 2 ⁢ [ 2 + 2 ⁢ ( n − 1 ) ( n − 1 ) 2 ] = 2 n ⁢ ( n − 1 ) .

关键公式是

题目

过点 P 1 = ( 1 , 0 , 0 ) 、 P 2 = ( 0 , 1 , 0 ) ，且与曲面 z = x 2 + y 2 相切的平面为（ ）。

  • A. z = 0 与 x + y − z = 1
  • B. z = 0 与 2 ⁢ x + 2 ⁢ y − z = 2
  • C. x = y 与 x + y − z = 1
  • D. x = y 与 2 ⁢ x + 2 ⁢ y − z = 2

解答与答疑

结论： 选 B。两个切平面分别是

z = 0 , 2 ⁢ x + 2 ⁢ y − z = 2 .

① 用不同字母区分“切点”与“平面上的一般点”。

设未知切点为

M = ( u , v , u 2 + v 2 ) .

将曲面写成 F ⁡ ( x , y , z ) = x 2 + y 2 − z = 0 ，其在 M 点的法向量为

n = ∇ F ⁡ ( M ) = ( 2 ⁢ u , 2 ⁢ v , − 1 ) .

因而切平面方程为

2 ⁢ u ⁢ ( x − u ) + 2 ⁢ v ⁢ ( y − v ) − ( z − u 2 − v 2 ) = 0 ,

即

z = 2 ⁢ u ⁢ x + 2 ⁢ v ⁢ y − u 2 − v 2 .

这里 u , v 是确定切点的参数； x , y , z 是平面上一般点的坐标。

② 你的点积条件没有错，它给出的是 u = v 。

因为切平面经过 P 1 , P 2 ，方向向量

d = P 1 − P 2 = ( 1 , − 1 , 0 )

平行于切平面，必须垂直于其法向量。所以

d ⋅ n = ( 1 , − 1 , 0 ) ⋅ ( 2 ⁢ u , 2 ⁢ v , − 1 ) = 2 ⁢ u − 2 ⁢ v = 0 ,

得到

u = v .

这说明切点的横、纵坐标相等，不说明切平面上每个点都满足 x = y 。 事实上，给定点 ( 1 , 0 , 0 ) 连平面 x = y 都不在，因此 x = y 不可能是题目所求平面。

③ 再代入一个给定点，确定切点。

将 P 1 = ( 1 , 0 , 0 ) 代入切平面方程：

0 = 2 ⁢ u − u 2 − v 2 .

结合 u = v ，得到

2 ⁢ u − 2 ⁢ u 2 = 0 ⁢ ⟹ ⁢ u = 0   或   u = 1.
  • u = v = 0 ：切点为 ( 0 , 0 , 0 ) ，切平面为 z = 0 。
  • u = v = 1 ：切点为 ( 1 , 1 , 2 ) ，切平面为 z = 2 ⁢ x + 2 ⁢ y − 2 。

2018-5--横向分块矩阵的秩

题目

设 A , B 为 n 阶矩阵， r ⁡ ( X ) 表示矩阵 X 的秩， ( X , Y ) 表示横向拼接的分块矩阵，则恒成立的是（ ）。

  • A. r ⁡ ( A , A ⁢ B ) = r ⁡ ( A )
  • B. r ⁡ ( A , B ⁢ A ) = r ⁡ ( A )
  • C. r ⁡ ( A , B ) = max ⁡ { r ⁡ ( A ) , r ⁡ ( B ) }
  • D. r ⁡ ( A , B ) = r ⁡ ( A T ⁢ B T )

我的疑问： 我选了 C。 ( A , B ) 是 n × 2 ⁢ n 矩阵，为什么 C 不成立？

关联笔记： 拼接矩阵的秩与乘积秩 · 从列向量的无关组判断秩 错因： 将矩阵的行列规模所给出的“秩的上界”，误当成具体的秩；没有考虑拼接后是否增加了新的线性无关列向量。

解答与答疑

结论： 选 A。一般只有

max ⁡ { r ⁡ ( A ) , r ⁡ ( B ) } ≤ r ⁡ ( A , B ) ≤ min ⁡ { n , r ⁡ ( A ) + r ⁡ ( B ) } .

① n × 2 ⁢ n 只说明秩不超过 n 。

矩阵的秩是其中线性无关列向量的最大个数，并非行数、列数本身。横向拼接后，要把 A 和 B 的所有列向量放在一起，重新判断线性无关性。

例如，取

A = ( 1 0 0 0 ) , B = ( 0 0 0 1 ) .

两者分别只有一个非零独立列，因此 r ⁡ ( A ) = r ⁡ ( B ) = 1 。但

( A , B ) = ( 1 0 0 0 0 0 0 1 )

包含 ( 1 , 0 ) T 与 ( 0 , 1 ) T 两个线性无关的列，所以

r ⁡ ( A , B ) = 2 > 1 = max ⁡ { r ⁡ ( A ) , r ⁡ ( B ) } .

这就是 C 的反例。矩阵确实是 2 × 4 ，秩也确实不超过 2 ，但不能因此认定它等于两个单独秩的最大值。

② 为什么 A 恒成立？

将 B 按列写成 B = ( b 1 , … , b n ) ，则

A ⁢ B = ( A ⁢ b 1 , … , A ⁢ b n ) .

每个 A ⁢ b j 都是 A 的列向量的线性组合。因此在 A 后面增加 A ⁢ B 的列，不会增加新的独立方向：

Col ⁡ ( A ⁢ B ) ⊆ Col ⁡ ( A ) ,

从而

r ⁡ ( A , A ⁢ B ) = r ⁡ ( A ) .

Col ⁡ ( A ) 表示 A 的所有列向量张成的空间，称为列空间。

也可以用可逆分块矩阵作证明：

( A , A ⁢ B ) ⁢ ( E − B 0 E ) = ( A , 0 ) .

右侧乘的分块矩阵可逆，所以两边秩相等。

③ 另外两个选项为什么不恒成立？

对 B，左乘 B 可能把 A 的列向量移到新的方向。例如

A = ( 1 0 0 0 ) , B = ( 0 0 1 0 ) ,

有 B ⁢ A = B ，故 r ⁡ ( A , B ⁢ A ) = 2 ，而 r ⁡ ( A ) = 1 。

对 D，题图右侧是乘积 A T ⁢ B T 的秩。使用①中的两个对角矩阵，有 A T ⁢ B T = 0 ，但 r ⁡ ( A , B ) = 2 ，所以也不成立。

正确的转置关系是

r ⁡ ( A , B ) = r ⁡ ( A T B T ) .

横向拼接矩阵整体转置后，要变成纵向拼接，不能变成矩阵乘积。

④ C 在什么情况下成立？

当两个列空间中，一个包含在另一个之内时成立。一般地，令 U = Col ⁡ ( A ) 、 V = Col ⁡ ( B ) ，则

r ⁡ ( A , B ) = dim ⁡ ( U + V ) = r ⁡ ( A ) + r ⁡ ( B ) − dim ⁡ ( U ∩ V ) .

两个矩阵各自的秩，只给出各自独立方向的数量；拼接后的秩还取决于这些方向有多少重合。

  • H 1 : μ ≠ μ 0 ：总体真实均值偏离标准，是备择假设；偏大、偏小都属于备择，因此是双侧检验。

例如，以 100 g 为包装平均重量标准时， H 0 表示真实平均重量为 100 g 。样本均值不必刚好等于 100 g ，因为抽样本身有波动。

检验要判断的是：如果 H 0 成立，当前观察到的偏离是否大到难以用抽样波动解释？

② 拒绝域是什么？

拒绝域是“检验统计量一旦落进去，就按规则拒绝 H 0 ”的取值范围。

在方差未知、 n ≥ 2 时，正态总体均值的常用检验统计量为

T = X ¯ − μ 0 S / n , S 2 = 1 n − 1 ⁢ ∑ i = 1 n ( X i − X ¯ ) 2 .

在 H 0 成立时， T ∼ t ⁢ ( n − 1 ) 。 T 衡量的是“样本均值离标准值相差了多少个标准误差”。

双侧检验在水平 α 下的拒绝域为

W α = { | T | > t 1 − α / 2 , n − 1 } ,

其中 t q , n − 1 表示自由度为 n − 1 的 t 分布的下侧累积概率为 q 的分位数。双侧检验将概率 α 分到左右两端，各占 α / 2 。

α 越小，临界值越大，要求偏离越极端才能拒绝。因此

W 0.01 ⊂ W 0.05 .

若总体方差已知，则使用 Z = ( X ¯ − μ 0 ) / ( σ / n ) ； 0.05 、 0.01 对应的双侧临界值分别约为 1.960 、 2.576 ，也能直观看出拒绝条件变严格。

③ 为什么一定是 D？

如果样本结果连较大的拒绝域 W 0.05 都没有落入，就更不可能落入其中较小的 W 0.01 。所以

0.05  下不拒绝  H 0 ⁡   ⟹   ⁢ 0.01  下不拒绝  H 0 .

反过来，若结果落入 W 0.05 ，它可能落入 W 0.01 ，也可能只在两者之间，因此 A、B 都不能保证；C 的方向相反。

④ 用 p 值核对。

p 值是在 H 0 成立时，得到“至少像当前样本结果这么极端”的结果的概率。对这里的双侧 t 检验，

p = 2 ⁢ [ 1 − F t ⁢ ( n − 1 ) ⁡ ( | t obs | ) ] .

按 p < α 时拒绝的约定：

  • 若 p = 0.03 ，在 0.05 下拒绝，在 0.01 下不拒绝，所以 A 不成立。
  • 若 p = 0.005 ，在两个水平下都拒绝，所以 B 不成立。
  • 若 p = 0.08 ，在两个水平下都不拒绝，与 D 一致。

⑤ 两个概念不能混淆。

显著性水平 α 控制的是：在 H 0 真实成立的前提下，错误拒绝它的概率，也就是第一类错误概率。它不是“ H 0 成立的概率”，也不是“这次拒绝后有多大概率判错”。

题目中的“接受 H 0 ”，在这里应理解为“未拒绝 H 0 ”：现有样本证据不足以否定它，并不等于已经证明 μ = μ 0 。

2019-16--方向导数：为什么必须把方向向量单位化？最大值与梯度有什么关系？

题目

设 a , b 为实数，函数

z = f ⁡ ( x , y ) = 2 + a ⁢ x 2 + b ⁢ y 2

在点 ( 3 , 4 ) 处，沿方向 l = − 3 ⁢ i − 4 ⁢ j 的方向导数最大，最大值为 10 。 （1）求 a , b 。

关联笔记： 单位方向与最大方向导数 错因： 直接把非单位向量 ( − 3 , − 4 ) 代入了方向导数公式；同时，比例相等只能说明平行，最大方向导数还要求梯度与给定方向同向。

解答与答疑

结论：

a = b = − 1 .

方向导数表示沿给定方向每移动单位距离时的瞬时变化率。对于非单位方向向量 l ，本题应使用

D l ⁢ f ⁡ ( P ) = ∇ f ⁡ ( P ) ⋅ l | l | .

这里 D l 表示“沿 l 所指方向”的方向导数。

① 先把方向向量单位化。

题目给出的向量为 l = ( − 3 , − 4 ) ，长度是

| l | = ( − 3 ) 2 + ( − 4 ) 2 = 5.

对应的单位方向向量为

e = ( − 3 5 , − 4 5 ) .

方向相同的 ( − 3 , − 4 ) 、 ( − 6 , − 8 ) 应对应相同的方向导数。先单位化，就能去掉向量长度的影响，只保留方向。

② 梯度与方向导数的关系。

对本题的可微函数，梯度由两个偏导数组成：

∇ f = ( f x , f y ) = ( 2 ⁢ a ⁢ x , 2 ⁢ b ⁢ y ) .

在 P = ( 3 , 4 ) 处，有

∇ f ⁡ ( 3 , 4 ) = ( 6 ⁢ a , 8 ⁢ b ) .

沿任意单位向量 e 的方向导数为

D e ⁢ f = ∇ f ⋅ e = | ∇ f | ⁢ cos ⁡ θ ,

其中 θ 是梯度与该方向的夹角。于是：

  • 与梯度同向时， cos ⁡ θ = 1 ，方向导数最大，为 | ∇ f | 。
  • 与梯度反向时， cos ⁡ θ = − 1 ，方向导数最小，为 − | ∇ f | 。
  • 与梯度垂直时，方向导数为 0 。

本题最大值为 10 ，所以梯度非零，且给定方向必须与梯度同向。

③ 最直接的方法：梯度等于“最大值乘单位方向”。

梯度的长度为 10 ，方向是 e = ( − 3 / 5 , − 4 / 5 ) ，故

∇ f ⁡ ( 3 , 4 ) = 10 ⁢ e = 10 ⁢ ( − 3 5 , − 4 5 ) = ( − 6 , − 8 ) .

与 ( 6 ⁢ a , 8 ⁢ b ) 比较各分量：

6 ⁢ a = − 6 , 8 ⁢ b = − 8 ,

得到

a = b = − 1 .

④ 沿用你的方法，具体应改哪一步？

由平行条件

6 ⁢ a − 3 = 8 ⁢ b − 4

得到 a = b ，这一步没错。但比例式没有区分同向和反向：如果只靠它配合梯度长度求参数，还必须检查比例为正。

接着计算方向导数时，要将方向向量除以长度 5 ：

( 6 ⁢ a , 8 ⁢ b ) ⋅ ( − 3 5 , − 4 5 ) = 10 ,

即

− 18 ⁢ a − 32 ⁢ b 5 = 10 .

代入 a = b ，有

− 10 ⁢ a = 10 ⁢ ⟹ ⁢ a = b = − 1.

此时 ∇ f = ( − 6 , − 8 ) = 2 ⁢ ( − 3 , − 4 ) ，比例为正，确实同向；梯度长度也确实为 10 ，满足最大值条件。

⑤ 你原来的点积有什么意义？为什么它比方向导数大了 5 倍？

沿参数路径

x ⁡ ( t ) = 3 − 3 ⁢ t , y ⁡ ( t ) = 4 − 4 ⁢ t

运动，链式法则给出

d d ⁢ t ⁢ f ⁡ ( x ⁡ ( t ) , y ⁡ ( t ) ) | t = 0 = 6 ⁢ a ⁡ ( − 3 ) + 8 ⁢ b ⁡ ( − 4 ) .

这表示“每单位参数 t 的变化率”。但这条路径的运动速度为 5 ，即每单位 t 走过 5 单位距离。因此换成每单位距离的变化率，还要除以 5 。

如果忘记除以 5 ，会得到 a = b = − 1 / 5 ，此时梯度长度只有

( 6 ⁢ a ) 2 + ( 8 ⁢ b ) 2 = 2 ,

与题目所说的“最大值为 10 ”矛盾。这可以作为计算后的快速检查。

本题可记住的关系： 已知方向 l 是方向导数的最大方向、最大值为 M > 0 时，

∇ f ⁡ ( P ) = M ⁢ l | l | .
