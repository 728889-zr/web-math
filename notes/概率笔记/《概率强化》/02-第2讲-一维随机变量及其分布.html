第 2 讲　一维随机变量及其分布

1. 定义与直接结论

1.1 随机变量与分布函数【基础补充】

随机变量 X 本质上是把每个样本点 ω 映射为实数 X ⁡ ( ω ) 的函数。

分布函数：

F X ⁡ ( x ) = P ⁡ ( X ≤ x ) .

任何分布函数都满足：

  1. 0 ≤ F X ⁡ ( x ) ≤ 1 ；
  2. 单调不减；
  3. 右连续；
  4. F X ⁡ ( − ∞ ) = 0 , F X ⁡ ( + ∞ ) = 1 。

区间概率统一由 F 求：

P ⁡ ( a < X ≤ b ) = F ⁡ ( b ) − F ⁡ ( a ) ,
P ⁡ ( a ≤ X ≤ b ) = F ⁡ ( b ) − F ⁡ ( a − ) , q ⁢ q ⁢ u ⁢ a ⁢ d ⁢ P ⁡ ( X = a ) = F ⁡ ( a ) − F ⁡ ( a − ) .

1.2 离散型与连续型

离散型分布律 p i = P ⁡ ( X = x i ) 必须满足

p i ≥ 0 , q ⁢ q ⁢ u ⁢ a ⁢ d ⁢ ∑ i p i = 1.

连续型概率密度 f ⁡ ( x ) 必须满足

f ⁡ ( x ) ≥ 0 , q ⁢ q ⁢ u ⁢ a ⁢ d ⁢ ∫ − ∞ + ∞ f ⁡ ( x ) d x = 1.
F ⁡ ( x ) = ∫ − ∞ x f ⁡ ( t ) d t , q ⁢ q ⁢ u ⁢ a ⁢ d ⁢ f ⁡ ( x ) = F ′ ⁡ ( x ) （可导点） .

连续型变量在单点处概率为零： P ⁡ ( X = a ) = 0 。因此连续型题中端点是否取到通常不影响概率。

二项分布众数：令 r = ( n + 1 ) ⁢ p 。

  • r 不是整数时，唯一众数为 ⌊ r ⌋ ；
  • r 是整数时， r − 1 与 r 同为众数。

( n k ) ⁢ p k ⁢ ( 1 − p ) n − k ≈ e − λ ⁢ λ k k ! .

强化版给出的实用判断：通常 n ≥ 20 , p ≤ 0.05 , n ⁢ p ≤ 10 时可考虑； n ≥ 100 时近似更稳。

指数分布无记忆性：

P ⁡ ( X > s + t ∣ X > s ) = P ⁡ ( X > t ) .

正态标准化：

Z = X − μ σ ∼ N ⁡ ( 0 , 1 ) , q ⁢ q ⁢ u ⁢ a ⁢ d ⁢ P ⁡ ( a < X ≤ b ) = Φ ⁡ ( b − μ σ ) − Φ ⁡ ( a − μ σ ) .

对称性： Φ ⁡ ( − x ) = 1 − Φ ⁡ ( x ) 。

1.5 用分布求概率与反问题

  • 已知 F ：按区间端点直接作差。
  • 已知 f ：先定有效区间，再积分。
  • 已知含参数的 p i 或 f ⁡ ( x ) ：先用总概率为 1 求参数，再做其他计算。
  • 若给出的函数声称是分布函数，先查“单调不减、右连续、两端极限”；声称是密度，先查“非负、积分为 1 ”。

1.6 两个尾和公式

若 X 为非负整数型随机变量，则

E ⁢ X = ∑ k = 1 ∞ P ⁡ ( X ≥ k ) .

若 X ≥ 0 为连续型随机变量，则

E ⁢ X = ∫ 0 ∞ [ 1 − F X ⁡ ( x ) ] d x .

2. 考研做题固定流程

流程 A：判断一个函数能否成为 F 、 p 或 f

  1. 先看非负性/单调性。
  2. 再看归一化或两端极限。
  3. 最后查连续性要求： F 右连续，密度不要求连续。
  4. 几个候选函数作算术平均或凸组合时，利用线性保持性质；几何平均不能想当然。

流程 B：识别常见分布

  1. 一次成败 → 0 - 1 。
  2. 固定 n 次独立成败、数成功次数 → 二项。
  3. 稀有事件计数或“单位时间内个数” → 泊松。
  4. 等到第一次成功 → 几何。
  5. 不放回抽取、数次品 → 超几何。
  6. 区间等可能 → 均匀；等待时间且无记忆 → 指数；许多小扰动叠加 → 正态。

流程 C：由条件构造分布

  1. 先按条件变量的所有可能值分层。
  2. 写全概率：
    F Y ⁡ ( y ) = ∑ i P ⁡ ( X = x i ) ⁢ P ⁡ ( Y ≤ y ∣ X = x i ) .
  3. 每一层分别确定 y 的有效范围。
  4. 合并成分段 F Y ⁡ ( y ) ，最后求导得到连续部分密度。

流程 D：几何背景题

  1. 先把随机点的位置参数化成随机变量。
  2. 由几何关系写目标量与位置变量的函数关系。
  3. 求 CDF： F Y ⁡ ( y ) = P ⁡ ( g ⁡ ( X ) ≤ y ) 。
  4. 若要求密度，再对分段 CDF 求导。

3. 补充 / 易错点

高频错误
  • 分布函数是 P ⁡ ( X ≤ x ) ，不是 P ⁡ ( X = x ) 。
  • F 可以跳跃；跳跃高度就是该点的概率。
  • 连续型只表示 F 连续，不表示密度 f 必须连续。
  • “同分布”不等于“相等”，也不等于“独立”。
  • 柯西分布的期望、方差不存在，不能因图形对称就写 E ⁢ X = 0 。
  • 超几何对应不放回，二项对应独立重复；二者不要混用。

最常见端点统一法：

P ⁡ ( X < x ) = F ⁡ ( x − ) , P ⁡ ( X ≥ x ) = 1 − F ⁡ ( x − ) ,
P ⁡ ( X > x ) = 1 − F ⁡ ( x ) , P ⁡ ( X = x ) = F ⁡ ( x ) − F ⁡ ( x − ) .

若题目同时含离散点质量和连续密度，它是混合型分布：总概率应为“所有跳跃概率之和 + 密度积分”。
