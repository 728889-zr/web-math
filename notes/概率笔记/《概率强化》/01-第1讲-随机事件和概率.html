第 1 讲　随机事件和概率

1. 定义与直接结论

1.1 随机试验、样本空间与事件【基础补充】

  • 随机试验：相同条件下可重复；所有可能结果可预先描述；每次出现哪个结果事先不能确定。
  • 样本空间 Ω ：所有基本结果（样本点）的集合。
  • 随机事件 A ： Ω 的子集。事件发生，就是试验结果落入 A 。
  • 必然事件为 Ω ，不可能事件为 ∅ 。

事件语言与集合语言：

题目语言 集合表示
A 与 B 同时发生 A ⁢ B = A ∩ B
至少一个发生 A ∪ B
A 发生而 B 不发生 A ⁢ B ¯
A 不发生 A ¯
恰有一个发生 A ⁢ B ¯ ∪ A ¯ ⁢ B
至少一个不发生 A ⁢ B ― = A ¯ ∪ B ¯
两者同时发生或同时不发生 A ⁢ B ∪ A ¯ ⁢ B ¯

德·摩根律：

A ∪ B ― = A ¯ ⁢ B ¯ , A ⁢ B ― = A ¯ ∪ B ¯ .

1.2 概率的基本性质

P ⁡ ( Ω ) = 1 , P ⁡ ( ∅ ) = 0 , 0 ≤ P ⁡ ( A ) ≤ 1.
P ⁡ ( A ¯ ) = 1 − P ⁡ ( A ) , A ⊆ B ⇒ P ⁡ ( A ) ≤ P ⁡ ( B ) .
P ⁡ ( A ∪ B ) = P ⁡ ( A ) + P ⁡ ( B ) − P ⁡ ( A ⁢ B ) .

三个事件：

P ⁡ ( A ∪ B ∪ C ) = P ⁡ ( A ) + P ⁡ ( B ) + P ⁡ ( C ) − P ⁡ ( A ⁢ B ) − P ⁡ ( A ⁢ C ) − P ⁡ ( B ⁢ C ) + P ⁡ ( A ⁢ B ⁢ C ) .

若 A 1 , … , A n 两两互斥，则

P ⁡ ( ⋃ i = 1 n A i ) = ∑ i = 1 n P ⁡ ( A i ) .

1.3 古典概型与几何概型【基础补充】

  • 古典概型：样本点有限且等可能，
    P ⁡ ( A ) = A  中样本点数 Ω  中样本点数 .
  • 几何概型：在区域内“均匀”取点，
    P ⁡ ( A ) = A  对应区域的长度/面积/体积 Ω  的长度/面积/体积 .

只有确认“等可能”或“均匀”后，才能直接作比值。

1.4 条件概率、乘法公式、全概率与贝叶斯

当 P ⁡ ( B ) > 0 时，

P ⁡ ( A ∣ B ) = P ⁡ ( A ⁢ B ) P ⁡ ( B ) .

乘法公式：

P ⁡ ( A ⁢ B ) = P ⁡ ( B ) ⁢ P ⁡ ( A ∣ B ) = P ⁡ ( A ) ⁢ P ⁡ ( B ∣ A ) .

一般乘法公式：

P ⁡ ( A 1 ⋯ A n ) = P ⁡ ( A 1 ) ⁢ P ⁡ ( A 2 ∣ A 1 ) ⋯ P ⁡ ( A n ∣ A 1 ⋯ A n − 1 ) .

若 B 1 , … , B n 为完备事件组，则

P ⁡ ( A ) = ∑ i = 1 n P ⁡ ( B i ) ⁢ P ⁡ ( A ∣ B i ) .

贝叶斯公式：

P ⁡ ( B j ∣ A ) = P ⁡ ( B j ) ⁢ P ⁡ ( A ∣ B j ) ∑ i = 1 n P ⁡ ( B i ) ⁢ P ⁡ ( A ∣ B i ) .

理解：全概率是“由原因推结果”，贝叶斯是“看到结果反推原因”。

1.5 独立、互斥与相容

  • A , B 独立： P ⁡ ( A ⁢ B ) = P ⁡ ( A ) ⁢ P ⁡ ( B ) 。
  • A , B 互斥： A ⁢ B = ∅ 。
  • A , B 相容： A ⁢ B ≠ ∅ 。

当 P ⁡ ( A ) ⁢ P ⁡ ( B ) > 0 时：

A , B ⁢  独立 ⟺ P ⁡ ( A ∣ B ) = P ⁡ ( A ) ⟺ P ⁡ ( B ∣ A ) = P ⁡ ( B ) .

若 A , B 独立，则 A , B ¯ 、 A ¯ , B 、 A ¯ , B ¯ 也独立。

n 个事件相互独立，必须满足任取 k ≥ 2 个事件，其交事件概率都等于各概率之积；只有“两两独立”一般不够。

1.6 强化版六类直接方法

  1. 对立思想： P ⁡ ( A ) = 1 − P ⁡ ( A ¯ ) 。
  2. 互斥拆分：把目标拆成若干互斥小事件再相加。
  3. 条件思想：出现“已知、在……条件下”，优先写条件概率或全概率。
  4. 单调性：由事件包含关系直接比较概率。
  5. 最值关系：
    { max ⁡ ( X , Y ) ≤ a } = { X ≤ a , Y ≤ a } ,
    { min ⁡ ( X , Y ) > a } = { X > a , Y > a } .
  6. 独立/有利/抑制：比较 P ⁡ ( A ⁢ B ) 与 P ⁡ ( A ) ⁢ P ⁡ ( B ) ：大于为相互有利，小于为相互抑制，等于为独立。

2. 考研做题固定流程

流程 A：复杂事件概率

  1. 设事件：一句话只设一个基本事件。
  2. 先翻译，不急算：把“至少、恰有、都不、只有”改写成并、交、补。
  3. 优先找补集：目标若是“至少一个”，通常先算“一个都没有”。
  4. 检查能否互斥拆分：拆分后各项必须互斥，才可直接相加。
  5. 最后代公式：容斥、条件概率或独立性。

流程 B：全概率与贝叶斯

  1. 找“原因层” B 1 , … , B n ，确认它们互斥且覆盖全集。
  2. 写树状关系：先发生 B i ，再发生结果 A 。
  3. 求结果概率用全概率： ∑ P ⁡ ( B i ) ⁢ P ⁡ ( A ∣ B i ) 。
  4. 题目问“已知结果来自哪一类”时，再除以 P ⁡ ( A ) 用贝叶斯。

流程 C：独立重复试验

若每次只有成功/失败、各次独立且成功概率固定为 p ，成功次数

X ∼ B ⁡ ( n , p ) , P ⁡ ( X = k ) = ( n k ) ⁢ p k ⁢ ( 1 − p ) n − k .

题干中“放回抽取”“每次条件不变”“重复 n 次且相互独立”是典型信号。

流程 D：放球、抽样、排列类题目

  1. 先定样本点：球是否可区分？盒子是否可区分？是否允许空盒？
  2. 再判等可能：等可能的是“投放方案”还是“盒中个数结果”？两者通常不是一回事。
  3. 无放回抽样优先组合数；有放回且逐次独立优先乘法或二项分布。
  4. “至少一个空盒/至少一个命中”优先补集。

3. 补充 / 易错点

高频错误
  • P ⁡ ( A ∣ B ) 的分母是 P ⁡ ( B ) ，不是 P ⁡ ( A ) ；必须有 P ⁡ ( B ) > 0 。
  • 互斥不等于独立。若 A , B 互斥且概率都大于零，则它们一定不独立。
  • “两两独立”不推出“相互独立”。
  • 若 P ⁡ ( A ) = 0 或 P ⁡ ( A ) = 1 ，则 A 与任意事件独立；但它未必分别等于 ∅ 或 Ω 。
  • 连续型随机变量出现 P ⁡ ( Y = y 0 ) = 0 时，不能把 P ⁡ ( X ≤ x ∣ Y = y 0 ) 生硬写成概率之比；应使用条件密度，见 04-第4讲-多维随机变量及其分布。

复杂事件翻译口诀：

  • 看见“既……又……”写交集。
  • 看见“至少一个”先写补集。
  • 看见“已知……发生”把已知事件放到条件竖线右边。
  • 看见“不等号或不等关系”先判断能否利用包含关系。
  • 看见“最大/最小”先把最值事件改写成每个变量的事件。
