2020-4 --幂级数的偶数项级数与收敛半径

题目

（4）设 R 为幂级数 ∑ n = 1 ∞ a n ⁢ x n 的收敛半径， r 为实数，则下列结论中正确的是：

A. 当 ∑ n = 1 ∞ a 2 ⁢ n ⁢ r 2 ⁢ n 发散时， | r | ≥ R 。

B. 当 ∑ n = 1 ∞ a 2 ⁢ n ⁢ r 2 ⁢ n 发散时， | r | ≤ R 。

C. 当 | r | ≥ R 时， ∑ n = 1 ∞ a 2 ⁢ n ⁢ r 2 ⁢ n 发散。

D. 当 | r | ≤ R 时， ∑ n = 1 ∞ a 2 ⁢ n ⁢ r 2 ⁢ n 收敛。

我的疑问： 我想用收敛半径求法及比较判别法，把 a 2 ⁢ n ⁢ r 2 ⁢ n a n ⁢ x n 中的系数比值处理成 1 / R ，再利用“大收敛推小收敛”选 D。具体错在哪一步？

关联笔记： 半径内绝对收敛及半径判据 · 偶次项与缺项的处理

错因： 把“收敛半径存在”当成“相邻系数比值极限存在”；把 a 2 ⁢ n / a n 与 a n + 1 / a n 混同；还把只能保证 | r | < R 的结论扩大到了 | r | ≤ R 。

解答与答疑

结论：选 A。你的比较思路可以保留，但应从绝对收敛出发；即使证明了半径内部收敛，也不能据此选包含端点的 D。

一、先沿你的原思路，找出具体错误

1. 有收敛半径，不代表相邻系数比值极限一定存在。

只有在相应极限存在等条件下，才可以使用

lim n → ∞ ⁡ | a n + 1 a n | = 1 R

这样的公式。题目只告诉我们收敛半径为 R ，没有额外保证这个比值极限存在；系数还可能为零，使比值无法定义。

因此，不能把比值法当成所有幂级数都能直接套用的公式。使用比值判别法时，也要注意绝对值。

2. 即使相邻系数比值有极限，也不能推出 a 2 ⁢ n / a n → 1 / R 。

因为在相关系数非零时，

a 2 ⁢ n a n = a n + 1 a n ⁢ a n + 2 a n + 1 ⋯ a 2 ⁢ n a 2 ⁢ n − 1 ,

右边有 n 个因子，不能当成只有一个相邻系数比值。

用一个最简单的例子检查：取 a n = 2 n ，原幂级数的收敛半径为 R = 1 2 。虽然

a n + 1 a n = 2 = 1 R ,

但

a 2 ⁢ n a n = 2 n ⟶ + ∞ ,

并不趋于 2 。

所以，你写的

a 2 ⁢ n ⁢ r 2 ⁢ n a n ⁢ x n ⁢ ⟶ ⁢ 1 R ⁢ ( r 2 x ) n

这一步没有依据。后面再对常数 1 / R 开 n 次方根，也无法补救前面的系数处理错误。

3. “大收敛推小收敛”要比较非负项，不能直接比较任意带符号的项。

本题没有假设 a n ≥ 0 ，因此应考虑

∑ n = 1 ∞ | a n ⁢ r n |

与它的偶数项子级数。这样才可以使用非负项级数的比较关系。

4. 你最后得到的 D 还多包括了边界。

幂级数的基本结论是

| r | < R ⁢ ⇒ 绝对收敛 ,

不是 | r | ≤ R 。即使前面的计算全部正确，也必须单独检查 r = ± R ，不能直接把“ < ”改为“ ≤ ”。

二、怎样保留你的比较思路，正确完成本题？

当 | r | < R 时，由收敛半径的定义，

∑ n = 1 ∞ | a n ⁢ r n | < ∞ .

其偶数项的部分和满足

0 ≤ ∑ n = 1 N | a 2 ⁢ n ⁢ r 2 ⁢ n | ≤ ∑ k = 1 2 ⁢ N | a k ⁢ r k | ≤ ∑ k = 1 ∞ | a k ⁢ r k | .

因而偶数项绝对值级数收敛，进而

| r | < R ⁢   ⇒   ⁢ ∑ n = 1 ∞ a 2 ⁢ n ⁢ r 2 ⁢ n  绝对收敛 .

对这个命题取逆否命题，就得到

∑ n = 1 ∞ a 2 ⁢ n ⁢ r 2 ⁢ n  发散   ⇒   ⁢ | r | ≥ R .

这正是 A。

注意：这里依靠的是原级数在半径内部绝对收敛。一般收敛级数的子级数不一定收敛，例如交错调和级数收敛，但抽取它的偶数项后得到的负项级数发散。

三、为什么其余选项不成立？

选项 反例或原因
B 取 a n = 1 ，则 R = 1 。令 r = 2 ，偶数项级数 ∑ 4 n 发散，但 | r | > R 。
C 偶数项可以衰减得更快，所以偶数项级数的收敛半径可能大于 R 。见下面的例子。
D 取 a n = 1 ，则 R = 1 。令 r = 1 ，满足 | r | ≤ R ，但偶数项级数为 ∑ 1 ，发散。

对 C，具体取

a 2 ⁢ n = 4 − n , a 2 ⁢ n − 1 = 1.

原级数在 | x | < 1 时绝对收敛，在 | x | > 1 时奇数项不趋于零，因此原收敛半径为 R = 1 。但偶数项级数是

∑ n = 1 ∞ ( r 2 4 ) n ,

在 | r | < 2 时仍收敛。例如 r = 3 2 > R 时就收敛，故 C 错误。

记忆：半径内部绝对收敛，可以抽取子级数；子级数可以收敛得更远，端点需要另判。

2020-18 --第二类曲面积分为什么能合并后投影到 x ⁢ O ⁢ y 平面

题目

（18）设 Σ 为曲面

z = x 2 + y 2 , 1 ≤ x 2 + y 2 ≤ 4

的下侧， f 为连续函数，计算

I = ∬ Σ ⁢ [ x ⁢ f ⁡ ( x ⁢ y ) + 2 ⁢ x − y ] ⁢ ⁢ d ⁢ y ⁢ ⁢ d ⁢ z + [ y ⁢ f ⁡ ( x ⁢ y ) + 2 ⁢ y + x ] ⁢ ⁢ d ⁢ z ⁢ ⁢ d ⁢ x + [ z ⁢ f ⁡ ( x ⁢ y ) + z ] ⁢ d ⁢ x d ⁢ y .

我的疑问： 为什么可以把被积式化成 ( P , Q , R ) ⋅ ( z x , z y , − 1 ) 后对 d ⁢ x d ⁢ y 积分？另外两个面的积分投影到 x ⁢ O ⁢ y 平面后不是零吗？我知道 d ⁢ S 和 d ⁢ x d ⁢ y 的转换，但不理解这里三个积分项的变化。

关联笔记： 图形曲面的有向面积向量 错因： 把同一曲面上的三个有向投影面积元，理解成了三块位于坐标平面上的曲面；同时混淆了单位法向量与未单位化的法向量。

解答与答疑

结论：三个积分项都在同一块曲面 Σ 上积分。投影到 x ⁢ O ⁢ y 平面，是统一描述这块曲面的位置及面积，并不会让前两个积分项自动变成零。本题结果为 14 ⁢ π / 3 。

一、先纠正“其他两个面”的理解

在

∬ Σ P d y ⁢ d ⁢ z + Q d ⁢ z d ⁢ x + R d ⁢ x d ⁢ y

中，只有一块积分曲面 Σ 。

d ⁢ y d ⁢ z 、 d ⁢ z d ⁢ x 、 d ⁢ x d ⁢ y 表示这块曲面微元在三个坐标平面上的有向投影面积元，并不表示分别在三个坐标平面上积分。

你的想法中，“一块位于 y ⁢ O ⁢ z 平面的平面区域，投影到 x ⁢ O ⁢ y 平面后面积为零”，这句话本身可以成立。但本题的积分曲面是倾斜的圆锥面，并没有把它换成 y ⁢ O ⁢ z 或 z ⁢ O ⁢ x 平面。

二、为什么会出现 ( z x , z y , − 1 ) ？

先把曲面一般地写成

z = h ⁡ ( x , y ) ,

投影区域记为 D 。下侧的一个法向量是

N = ( h x , h y , − 1 ) .

但它通常不是单位向量。对应的单位法向量为

n = ( h x , h y , − 1 ) 1 + h x 2 + h y 2 ,

曲面面积元为

d ⁢ S = 1 + h x 2 + h y 2 d ⁢ x d ⁢ y .

两者相乘，根号才会抵消：

n ⁢ d ⁢ S = ( h x , h y , − 1 ) ⁢ d ⁢ x d ⁢ y .

第二类曲面积分是通量积分，因此

I = ∬ Σ ( P , Q , R ) ⋅ n d S = ∬ D ( P , Q , R ) ⋅ ( h x , h y , − 1 ) d x ⁢ ⁢ d ⁢ y = ∬ D ( P ⁢ h x + Q ⁢ h y − R ) d x ⁢ d ⁢ y .

这里的 P , Q , R 都要在曲面上取值，即把其中的 z 换成 h ⁡ ( x , y ) 。

所以，公式里出现 − 1 ，是单位法向量与面积元相乘后的结果。仅凭“向下”，只能断定单位法向量的 z 分量小于零，不能断定它等于 − 1 。

三、三个面积元分别发生了什么变化？

记 d ⁢ A = d ⁢ x d ⁢ y 为投影区域 D 上的普通正面积元，则下侧对应：

曲面上的有向面积元 投影到 D 后的表达
d ⁢ y d ⁢ z = n x d ⁢ S h x ⁡ d ⁢ A
d ⁢ z d ⁢ x = n y d ⁢ S h y ⁡ d ⁢ A
d ⁢ x d ⁢ y = n z d ⁢ S − d ⁢ A

因此前两个项通常仍有贡献，分别变成 P ⁢ h x ⁡ d ⁢ A 与 Q ⁢ h y ⁡ d ⁢ A 。只有对应法向分量确实为零时，相应投影面积元才为零。

一个最小例子： 对斜面 z = x 的下侧，有

n = ( 1 , 0 , − 1 ) 2 , d ⁢ S = 2 d ⁢ A .

所以

d ⁢ y d ⁢ z = d ⁢ A , d ⁢ z d ⁢ x = 0 , d ⁢ x d ⁢ y = − d ⁢ A .

即使统一对 x ⁢ O ⁢ y 平面上的 d ⁢ A 积分，原来的 d ⁢ y d ⁢ z 项也没有消失。

四、代入本题

本题

h = x 2 + y 2 = z , h x = x z , h y = y z .

因此下侧单位法向量实际为

n = 1 2 ⁢ ( x z , y z , − 1 ) , n z = − 1 2 .

记

P = x ⁢ f ⁡ ( x ⁢ y ) + 2 ⁢ x − y , Q = y ⁢ f ⁡ ( x ⁢ y ) + 2 ⁢ y + x , R = z ⁢ f ⁡ ( x ⁢ y ) + z .

则投影后的被积函数为

P ⁢ h x + Q ⁢ h y − R = x z ⁢ [ x ⁢ f ⁡ ( x ⁢ y ) + 2 ⁢ x − y ] + y z ⁢ [ y ⁢ f ⁡ ( x ⁢ y ) + 2 ⁢ y + x ] − [ z ⁢ f ⁡ ( x ⁢ y ) + z ] = ( x 2 + y 2 z − z ) ⁢ f ⁡ ( x ⁢ y ) + 2 ⁢ ( x 2 + y 2 ) z − z = z .

最后一步使用了曲面方程 x 2 + y 2 = z 2 ；交叉项 − x ⁢ y / z 与 x ⁢ y / z 也已经抵消。

投影区域为圆环

D = { ( x , y ) : 1 ≤ x 2 + y 2 ≤ 4 } .

改用极坐标 x = ρ ⁢ cos ⁡ θ 、 y = ρ ⁢ sin ⁡ θ ，有 z = ρ 、 d ⁢ x d ⁢ y = ρ d ⁢ ρ d ⁢ θ ，于是

I = ∬ D x 2 + y 2 d x ⁢ ⁢ d ⁢ y = ∫ 0 2 ⁢ π ∫ 1 2 ρ 2 d ρ d θ = 14 ⁢ π 3 .

记忆：先把三个项看成一个通量，再用“单位法向量 × 曲面面积元”统一投影。

2020-19 --中值定理的应用

题目

（19）设函数 f ⁡ ( x ) 在区间 [ 0 , 2 ] 上具有连续导数，

f ⁡ ( 0 ) = f ⁡ ( 2 ) = 0 , M = max x ∈ [ 0 , 2 ] ⁡ | f ⁡ ( x ) | .

证明：

（Ⅰ）存在 ξ ∈ ( 0 , 2 ) ，使得 | f ′ ⁡ ( ξ ) | ≥ M ；

（Ⅱ）若对任意 x ∈ ( 0 , 2 ) ，都有 | f ′ ⁡ ( x ) | ≤ M ，则 M = 0 。

我的疑问： 看答案时觉得简单，但自己做时没有思路，总想编造辅助函数。有没有办法根据题目缩小使用定理的范围？

关联笔记： 从端点与极值点的割线找导数值 错因： 没有先把目标中的“导数下界”翻译成割线斜率；定义了最大值却没有先选取最大值点，导致端点条件无法与目标衔接。第二问还需注意： ≥ M 与 ≤ M 并不矛盾，必须继续排除等号。

解答与答疑

结论：本题先取 | f | 的最大值点，再利用它与两端点形成的割线。第一问用拉格朗日中值定理；第二问检查积分不等式的等号条件，无需先构造辅助函数。

一、做题时如何从条件缩小范围？

本题最值得先识别的是三组信息：

题目信息 应立即尝试的动作 作用
M = max ⁡ | f ⁡ ( x ) | 取 c ，使 | f ⁡ ( c ) | = M 把抽象的最大值变成一个具体函数值
f ⁡ ( 0 ) = f ⁡ ( 2 ) = 0 考虑区间 [ 0 , c ] 、 [ c , 2 ] 形成分子为 ± f ⁡ ( c ) 的差商
要证某点的 | f ′ | 不小于 M 用中值定理把差商变成导数 直接接近结论

若只用端点相等套罗尔定理，只能得到某点 f ′ = 0 ，还没有得到目标要求的导数下界。因此这里应继续利用最大值点与端点之间的函数增量。

二、第一问：为什么选较短的那一段？

若 M = 0 ，则 f ≡ 0 ，结论成立。

以下设 M > 0 。取 c ∈ [ 0 , 2 ] ，使

| f ⁡ ( c ) | = M .

因为两端点的函数值都是零，所以 c ∈ ( 0 , 2 ) 。

在 [ 0 , c ] 上应用拉格朗日中值定理，存在 ξ 1 ∈ ( 0 , c ) ，使

| f ′ ⁡ ( ξ 1 ) | = | f ⁡ ( c ) − f ⁡ ( 0 ) c | = M c .

在 [ c , 2 ] 上同理，存在 ξ 2 ∈ ( c , 2 ) ，使

| f ′ ⁡ ( ξ 2 ) | = | f ⁡ ( 2 ) − f ⁡ ( c ) 2 − c | = M 2 − c .

因为

min ⁡ { c , 2 − c } ≤ 1 ,

所以上述两个导数中至少有一个满足

| f ′ ⁡ ( ξ ) | = M min ⁡ { c , 2 − c } ≥ M .

第一问得证。

几何上： 函数从高度零到达绝对高度 M ，再回到零。左右两段中至少一段长度不超过 1 ，因此这一段的割线斜率绝对值至少为 M ，中值定理保证曲线上某点达到这个斜率。

三、第二问：为什么不能直接引用第一问结束？

第一问只得到某点

| f ′ ⁡ ( ξ ) | ≥ M ,

第二问的假设是所有点

| f ′ ⁡ ( x ) | ≤ M .

它们可以同时成立：某点恰好等于 M 即可。因此还需要证明：当 M > 0 时，这种等号情形也无法实现。

四、第二问的完整证明

反设 M > 0 ，仍取 c ∈ ( 0 , 2 ) ，使 | f ⁡ ( c ) | = M 。

由牛顿—莱布尼茨公式及积分不等式，

2 ⁢ M = | f ⁡ ( c ) − f ⁡ ( 0 ) | + | f ⁡ ( 2 ) − f ⁡ ( c ) | = | ∫ 0 c f ′ ⁡ ( x ) d x | + | ∫ c 2 f ′ ⁡ ( x ) d x | ≤ ∫ 0 2 | f ′ ⁡ ( x ) | d x ≤ ∫ 0 2 M d x = 2 ⁢ M .

  4. 非严格不等式推不出矛盾时，检查等号条件。 本题第二问的突破口就在这里。

C 1 ← C 1 + C 2 + C 3 ,

2022-6 --齐次方程组同解

题目

第6题：

设 A , B 为 n 阶矩阵， E 为单位矩阵， O 为零矩阵。若 A ⁢ x = 0 与 B ⁢ x = 0 同解，则下列说法中哪一个正确？

（A）方程组 ( A O E B ) ⁢ y = 0 只有零解。

（B）方程组 ( E A O A ⁢ B ) ⁢ y = 0 只有零解。

（C）方程组 ( A B O B ) ⁢ y = 0 与 ( B A O A ) ⁢ y = 0 同解。

（D）方程组 ( A ⁢ B B O A ) ⁢ y = 0 与 ( B ⁢ A A O B ) ⁢ y = 0 同解。

疑问： 同解的条件能否写成 r ⁡ ( A ) = r ⁡ ( B ) = r ⁡ ( 合并矩阵 ) ？是否一定存在矩阵 P ，使得 − P ⁢ A = − B ，从而通过行变换消去 B ？

关联笔记： 同解、行空间与纵向拼接 错因： 未区分上下合并矩阵、左右合并矩阵和增广矩阵；没有明确行变换对应左乘可逆矩阵，也容易把同解误理解为乘积 A ⁢ B 与 B ⁢ A 的性质相同。

解答与答疑

结论： 本题选 C。你的行变换思路成立：对于本题的同阶矩阵， A ⁢ x = 0 与 B ⁢ x = 0 同解，确实能推出存在可逆矩阵 P ，使

B = P ⁢ A .

因而 − P ⁢ A = − B 也成立。关键是 P 必须可逆，且“合并矩阵”要指上下合并。

一、先把“同解的秩条件”写准确。

两组齐次方程同解，表示它们对未知向量施加的限制完全相同，即

ker ⁡ A = ker ⁡ B .

其等价的秩条件是

r ⁡ ( A ) = r ⁡ ( B ) = r ⁡ ( A B ) .

这里的 ( A B ) 是把两组方程上下放在一起得到的系数矩阵：增加另一组方程后没有增加独立约束，且两组各自的约束数相同。

这不是通常把常数列添加到系数矩阵右侧形成的增广矩阵 ( A ∣ b ) 。后者的秩条件 r ⁡ ( A ) = r ⁡ ( A ∣ b ) 主要用来判断非齐次方程组是否有解。

仅有 r ⁡ ( A ) = r ⁡ ( B ) 不够；左右合并后的秩相同也不够。 例如

A = ( 1 0 0 0 ) , B = ( 0 1 0 0 ) .

此时 r ⁡ ( A ) = r ⁡ ( B ) = r ⁡ ( A   B ) = 1 ，但 A ⁢ x = 0 要求 x 1 = 0 ， B ⁢ x = 0 要求 x 2 = 0 ，并不同解；上下合并矩阵的秩则是 2 。

二、为什么能推出 B = P ⁢ A ，而且 P 可逆？

同解意味着两者行空间相同，因此它们的行最简形相同，记为 R 。设分别通过初等行变换得到

U ⁢ A = R , V ⁢ B = R ,

其中 U , V 都可逆，于是

B = V − 1 ⁢ U ⁢ A .

令 P = V − 1 ⁢ U ，便有 B = P ⁢ A ，且 P 可逆。这说明 A 可以通过有限次初等行变换变成 B ，即二者行等价。

如果目的是消去上下合并矩阵中的 B ，可以作分块行变换

( E O − P E ) ⁢ ( A B ) = ( A B − P ⁢ A ) = ( A O ) .

左侧的分块矩阵可逆。这正是“下方各行减去上方各行的适当线性组合”。

反过来，若已知 B = P ⁢ A 且 P 可逆，那么 P ⁢ A ⁢ x = 0 ⟺ A ⁢ x = 0 ，所以两组齐次方程同解。若不要求 P 可逆，通常只能得到 A ⁢ x = 0 ⇒ B ⁢ x = 0 ，不能保证反向成立。

三、为什么 C 正确？

令 y = ( u v ) ，其中 u , v 都是 n 维向量。C 左边的方程组为

A ⁢ u + B ⁢ v = 0 , B ⁢ v = 0.

由第二式代入第一式，得到 A ⁢ u = 0 、 B ⁢ v = 0 。设公共零空间为 K = ker ⁡ A = ker ⁡ B ，这就等价于 u ∈ K 、 v ∈ K 。

C 右边的方程组为

B ⁢ u + A ⁢ v = 0 , A ⁢ v = 0 ,

同理等价于 B ⁢ u = 0 、 A ⁢ v = 0 ，也就是 u ∈ K 、 v ∈ K 。因此两者解集完全相同。

四、其他三个选项为什么不能保证成立？

对 A、B，取 A = B = O 即可。这时原来的两组齐次方程显然同解，但两个选项中的分块方程组都会允许 u = 0 、 v ≠ 0 ，所以都有非零解。

解答与答疑

结论： 差级数一定收敛，本题选 A，充分必要条件。

1. 为什么差级数收敛？ 设 A N = ∑ n = 1 N a n → A ， B N = ∑ n = 1 N b n → B 。对每个有限的 N ，都有

∑ n = 1 N ( b n − a n ) = B N − A N .
由收敛数列极限的减法法则，右边趋于 B − A ，所以差级数收敛。此步骤不需要 a n < b n 。

2. 大小条件在何处使用？ 令 c n = b n − a n > 0 。由上一步， ∑ c n 收敛；又因 c n > 0 ，有 ∑ | c n | = ∑ c n < ∞ ，所以差级数绝对收敛。

3. 逐方向检查充分性与必要性。 若 ∑ | a n | < ∞ ，由 b n = a n + c n 和三角不等式，

| b n | ≤ | a n | + c n ,
比较判别法给出 ∑ | b n | < ∞ 。反过来，由 a n = b n − c n ，有
| a n | ≤ | b n | + c n ,
同理可得 ∑ | a n | < ∞ 。两方向均成立。

注意：单由 a n < b n 不能推出 | a n | < | b n | ，例如 − 2 < − 1 。因此不能直接对原来的大小关系套绝对收敛的比较判别法。

4. 哪些运算有保证？

  • 有限线性组合：任意固定实数 α , β ， ∑ ( α ⁢ a n + β ⁢ b n ) 收敛，和为 α ⁢ A + β ⁢ B 。证明同样来自部分和。
  • 逐项相乘：仅有两个级数收敛不够。例如 a n = b n = ( − 1 ) n − 1 / n ，两个级数由交错级数判别法收敛，但 ∑ a n ⁢ b n = ∑ 1 / n 发散。若其中一个级数绝对收敛、另一个收敛，则后者的项有界，利用 | a n ⁢ b n | ≤ M ⁢ | a n | 可证明乘积级数绝对收敛。
  • 柯西乘积：第 n 项为 ∑ k = 1 n a k ⁢ b n + 1 − k ，与逐项相乘不同。两个级数均收敛且至少一个绝对收敛时，柯西乘积收敛于 A ⁢ B （柯西乘积定理）；仅两个条件收敛级数则无一般保证。
  • 逐项取绝对值、相除或任意重排：没有一般的收敛保证；除法还须先检查分母是否为零。

验证说明： 以上结论依据部分和极限、三角不等式及相应收敛定理，属于严格论证。有限项数值计算不能证明无穷级数收敛，因此这里不用数值近似替代证明。

沿 x n = 2 ⁢ n ⁢ π ，导数趋于 2；沿 y n = ( 2 ⁢ n + 1 ) ⁢ π ，导数趋于 − 2 ，故导数没有极限。

B：按有限极限的约定，取 f ⁡ ( x ) = x 即可， f ′ ⁡ ( x ) = 1 ，但 f ⁡ ( x ) 没有有限极限。如果还想排除把无穷也视为极限的歧义，可取 f ⁡ ( x ) = sin ⁡ ( ln ⁡ ( x + 1 ) ) ：导数绝对值不超过 1 / ( x + 1 ) ，故趋于 0，而函数本身持续振荡。

2025 -10 --上侧分位数与右侧检验的拒绝域

题目

X 1 , … , X n 为来自 N ⁡ ( μ , 2 ) 的简单随机样本， X ¯ = 1 n ⁢ ∑ X i 。 Z α 是标准正态分布的上侧 α 分位数。检验 H 0 : μ ≤ 1 ， H 1 : μ > 1 ，求显著性水平为 α 的拒绝域。

关联笔记： 右侧拒绝域与标准化 · 由上尾概率读临界值 错因： 需要建立“上侧 α → 右边面积为 α → 标准化统计量 → 还原到 X ¯ ”的对应关系，并区分方差和标准差。

解答与答疑

结论：拒绝域为

X ¯ > 1 + 2 n Z α .

1. 上侧分位数是一个位置，不是一个概率。

若 U ∼ N ⁡ ( 0 , 1 ) ，则定义

P ⁡ ( U > Z α ) = α .
因正态分布连续，
P ⁡ ( U ≤ Z α ) = 1 − α , Z α = Φ − 1 ⁢ ( 1 − α ) .
α 是右尾面积； Z α 是横轴上切出这块面积的临界值。
右尾概率 α 左侧累计概率 1 − α 临界值 Z α
0.05 0.95 约 1.645
0.025 0.975 约 1.960
0.5 0.5 0

由正态分布关于 0 对称， Z 1 − α = − Z α 。右尾面积越小，临界值越靠右。

2. 标准化前先核对方差。

按本题采用的 N ⁡ ( μ , σ 2 ) 记号， N ⁡ ( μ , 2 ) 中的 2 是方差，因此 $$E(\bar X)=\mu,\qquad \operatorname{Var}(\bar X)=\frac2n,\qquad \operatorname{SD}(\bar X)=\sqrt{\frac2n}.$$ 正态总体的样本均值精确服从 N ⁡ ( μ , 2 / n ) ，这里不需要大样本近似。

3. 为什么拒绝域向右？

备择假设是 μ > 1 ，越大的 X ¯ 越支持备择，所以采用右侧拒绝域。在原假设的边界 μ = 1 处，

T = X ¯ − 1 2 / n ∼ N ⁡ ( 0 , 1 ) .
要让此时误拒概率等于 α ，取 T > Z α 。因 2 / n > 0 ，移项不改变不等号方向： $$\frac{\bar X-1}{\sqrt{2/n}}>Z_\alpha \iff\bar X>1+\sqrt{\frac2n}Z_\alpha.$$

4. 原假设是 μ ≤ 1 ，为什么只在 μ = 1 校准？

记临界值为 c = 1 + 2 / n ⁢ Z α 。对于任意 μ ≤ 1 ， $$P_\mu(\bar X>c) =1-\Phi\left(\frac{c-\mu}{\sqrt{2/n}}\right) \le1-\Phi(Z_\alpha)=\alpha.$$ 因为 c − μ ≥ c − 1 ，且 Φ 单调递增。等号在 μ = 1 成立，所以整个原假设下最大的误拒概率正是 α 。

核验： Python/SciPy 算得 Φ − 1 ⁡ ( 0.95 ) = 1.64485362695 ，对应右尾概率约 0.05 。这只核验数值；拒绝域及水平保证来自上面的分布与不等式推导。

2025 -20 --直线绕斜轴旋转的曲面方程与通量

题目

将 z 轴 x = y = 0 绕直线 x = y = z 旋转一周得到曲面 Σ 。取其介于平面 x + y + z = 0 与 x + y + z = 1 之间部分的外侧 Σ 1 ，求

I = ∬ Σ 1 x d y ⁢ d ⁢ z + ( y + 1 ) ⁢ d ⁢ z d ⁢ x + ( z + 2 ) ⁢ d ⁢ x d ⁢ y .

我的疑惑：我算得 z 轴上一点到旋转轴的距离为 6 / 3 ，想利用这个距离写曲面方程，再补面用高斯公式，但卡在了方程。

关联笔记： 用轴向投影写斜锥面 · 补圆盘后的通量 错因： 你的“先写方程、再补面”的路线正确。距离计算遗漏了点的位置参数；建方程还需要同时记录沿旋转轴的投影位置。只固定到轴的距离会描述圆柱，不能描述本题随高度变化的圆锥。

解答与答疑

结论：曲面方程为

x 2 + y 2 + z 2 = ( x + y + z ) 2 或 x ⁢ y + x ⁢ z + y ⁢ z = 0 ,
**所求通量为**
I = − 2 ⁢ π 3 .

1. 先纠正点到轴的距离。

为避免与旋转后的坐标 z 混淆，将原点记为 P = ( 0 , 0 , a ) 。旋转轴的单位方向向量为

u = 1 3 ⁢ ( 1 , 1 , 1 ) .
P 在轴上的有向投影长度为 P ⋅ u = a / 3 ，所以垂足为
H = ( P ⋅ u ) ⁢ u = ( a / 3 , a / 3 , a / 3 ) .
因而 $$d(P,\text{轴})=\sqrt{|P|^2-(P\cdot\mathbf u)^2} =\sqrt{\frac23}|a|=\frac{\sqrt6}{3}|a|.$$ 你算出的 6 / 3 只在 | a | = 1 时成立。

2. 旋转一个点，哪些量保持不变？

一个点绕轴旋转时，沿轴的投影位置不变，到轴的垂直距离也不变。设旋转后的点为 Q = ( x , y , z ) ，记 s = x + y + z 。第一项不变量给出 $$Q\cdot\mathbf u=P\cdot\mathbf u \iff\frac{s}{\sqrt3}=\frac a{\sqrt3} \iff s=a.$$ 第二项不变量给出

x 2 + y 2 + z 2 − s 2 3 = 2 ⁢ a 2 3 .
用 a = s 消去参数，得到 x 2 + y 2 + z 2 = s 2 。

反过来，满足这个方程的点与 ( 0 , 0 , s ) 有相同的轴向投影和到轴距离，位于同一个旋转圆上。因此所得方程既必要也充分，确实描述整个旋转曲面。

3. 用几何量识别圆锥和截面半径。

轴向高度记为 h = s / 3 ，垂直于轴的距离记为 ρ ，则曲面上 $$\rho^2=x^2+y^2+z^2-\frac{s^2}{3} =\frac{2s^2}{3}=2h^2.$$ 所以这是双圆锥。题目的 0 ≤ s ≤ 1 只取正向这一半，顶点在原点。

顶面 s = 1 垂直于旋转轴，因此截面是圆。其圆心、高、半径分别为 $$H_1=(1/3,1/3,1/3),\quad h_1=\frac1{\sqrt3},\quad R=\sqrt{\frac23}.$$ 平面 s = 0 与该锥面只交于顶点，不需要补一个具有正面积的底面；补上 s = 1 的圆盘 S 即可封闭。

4. 明确高斯公式的区域与方向。

封闭区域为

Ω = { 0 ≤ s ≤ 1 ,   x 2 + y 2 + z 2 ≤ s 2 } .
取 F = ( x , y + 1 , z + 2 ) ，则 ∇ ⋅ F = 3 ，且向量场处处光滑。锥顶这个孤立点不影响分片光滑边界的通量积分。因此
I + ∬ S F ⋅ n d S = 3 ⁢ Vol ⁡ ( Ω ) .
圆锥体积是 $$\operatorname{Vol}(\Omega)=\frac13\pi R^2h_1 =\frac{2\pi}{9\sqrt3},$$ 故封闭面的总通量为 2 ⁢ π / ( 3 ⁢ 3 ) 。

5. 顶盖通量要用单位外法向量。

顶盖朝 s 增大的方向，因此 n = ( 1 , 1 , 1 ) / 3 。顶盖上 $$\mathbf F\cdot\mathbf n =\frac{x+y+z+3}{\sqrt3}=\frac4{\sqrt3}.$$ 它是常数，顶盖面积为 π ⁢ R 2 = 2 ⁢ π / 3 ，所以 $$\iint_S\mathbf F\cdot\mathbf n,dS =\frac{8\pi}{3\sqrt3}.$$ 最后“封闭通量减去补面通量”： $$I=\frac{2\pi}{3\sqrt3}-\frac{8\pi}{3\sqrt3} =-\frac{2\pi}{\sqrt3}.$$ 外侧通量为负并不矛盾：外侧规定法向量方向，向量场仍可能主要朝内穿过侧面。

独立核验： SymPy 用轴向截面积 π ⁢ ( 2 ⁢ h ) 2 = 2 ⁢ π ⁢ h 2 积分得到体积 2 ⁢ π / ( 9 ⁢ 3 ) ，核对了圆锥体积；最终通量化简为 − 2 ⁢ 3 ⁢ π / 3 ，与上式相等。另外，位置向量 ( x , y , z ) 沿圆锥母线，与侧面相切，侧面通量只来自常向量 ( 0 , 1 , 2 ) ；常向量在封闭面上的总通量为零，故侧面通量等于其顶盖通量的负值 − 3 ⁢ ( 2 ⁢ π / 3 ) ，独立得到相同结果。

2025 -20 --全概率求和为何从 n = k 开始？

题目

损失额 X 的密度为

f X ⁡ ( x ) = { 2 ⋅ 100 2 ( 100 + x ) 3 , x > 0 , 0 , x ≤ 0.
赔付额 Y = max ⁡ ( X − 100 , 0 ) 。求 P ⁡ ( Y > 0 ) 、 E ⁡ ( Y ) 。一年事故数 N ∼ Pois ⁡ ( 8 ) ，给定 N = n ≥ 1 时，理赔次数 M ∼ B ⁡ ( n , p ) ，其中 p = P ⁡ ( Y > 0 ) 。求 M 的分布。

我的疑惑：已算出联合概率，求 P ⁡ ( M = k ) 时为什么从 n = k 开始，而不是 n = 1 ？不应该完全消除 N = n 的影响吗？

关联笔记： 条件二项的取值范围与求和下限 错因： 你的联合概率式在 0 ≤ k ≤ n 时是正确的。缺口是没有把适用范围和公式一起写下来。“消去 N ”是对它的所有可能取值求和，不是取消 M ≤ N 的事实约束；另外泊松变量可以取 0。

解答与答疑

结论： $$p=\frac14,\qquad E(Y)=50,\qquad \boxed{P(M=k)=e^{-2}\frac{2^k}{k!},\ k=0,1,2,\ldots.}$$ 即 M ∼ Pois ⁡ ( 2 ) 。

1. 先求单次赔付概率与期望。

Y > 0 等价于 X > 100 ，所以 $$p=\int_{100}^\infty\frac{20000}{(100+x)^3},dx =\left[-\frac{10000}{(100+x)^2}\right]_{100}^\infty=\frac14.$$ 期望直接按 X 积分：

E ⁡ ( Y ) = ∫ 100 ∞ ( x − 100 ) ⁢ 20000 ( 100 + x ) 3 d x .
令 u = x + 100 ，则 x − 100 = u − 200 ，故 $$E(Y)=20000\int_{200}^\infty(u^{-2}-200u^{-3})\,du =20000\left(\frac1{200}-\frac{100}{200^2}\right)=50.$$ 注意 Y 在 0 处有概率 3 / 4 ，不是纯连续型变量；上面的期望公式已正确包含不赔付情况，其贡献为零。

2. 把联合概率连同取值范围写全。

理赔次数不可能大于事故次数，故 $$P(M=k,N=n)= \begin{cases} \displaystyle\binom nk\left(\frac14\right)^k \left(\frac34\right)^{n-k}\frac{8^ne^{-8}}{n!}, &n=0,1,\ldots,\ 0\le k\le n,\ 0,&\text{其余非负整数 }k,n. \end{cases}$$ 虽然题目只在 n ≥ 1 时写条件二项分布，但当 N = 0 ，由事件含义必有 M = 0 ，所以 P ⁡ ( M = 0 ∣ N = 0 ) = 1 。

3. 全概率公式本来从哪里开始？

因为泊松变量 N 的取值是 0 , 1 , 2 , … ，完整公式是

P ⁡ ( M = k ) = ∑ n = 0 ∞ P ⁡ ( M = k ∣ N = n ) ⁢ P ⁡ ( N = n ) .
但对固定的 k ，所有 n < k 的项都是零，所以可以删掉，写成
P ⁡ ( M = k ) = ∑ n = k ∞ P ⁡ ( M = k ∣ N = n ) ⁢ P ⁡ ( N = n ) .
两个式子完全等价，没有遗漏任何可能事件。

4. 那么从 n = 1 开始到底可不可以？

  • 若 k ≥ 1 ，从 n = 1 开始也可以，但必须将 n < k 时的条件概率明确写为 0。删掉这些零项后，仍然从 n = k 开始。
  • 若 k = 0 ，从 n = 1 开始就会漏掉 N = 0 的概率 e − 8 ，不能这样写。
  • 你图中的二项概率公式只适用于 0 ≤ k ≤ n 。若直接把它改写成含 ( n − k ) ! 的式子，再代入 n < k ，就出现负整数阶乘；这是越出了公式适用范围，不是全概率公式失效。

例如要“理赔 3 次”，事故次数可能为 3、4、5……，但不可能为 0、1、2。边缘化是把这些可发生的不同事故次数对应的概率相加，不是让不可能的组合变成可能。

5. 在合法范围内逐步化简级数。

对固定非负整数 k ， $$\begin{aligned} P(M=k) &=\sum_{n=k}^\infty \frac{n!}{k!(n-k)!}\left(\frac14\right)^k \left(\frac34\right)^{n-k}\frac{8^ne^{-8}}{n!}\ &=e^{-8}\frac{2^k}{k!} \sum_{n=k}^\infty\frac{6^{n-k}}{(n-k)!}. \end{aligned}$$ 第二步使用 8 n = 8 k ⁢ 8 n − k ，分别合并为 ( 8 / 4 ) k = 2 k 与 ( 8 ⋅ 3 / 4 ) n − k = 6 n − k 。

再令 j = n − k 。因为原下限是 n = k ，所以新下限恰为 j = 0 ： $$\sum_{n=k}^\infty\frac{6^{n-k}}{(n-k)!} =\sum_{j=0}^\infty\frac{6^j}{j!}=e^6.$$ 因此 P ⁡ ( M = k ) = e − 2 ⁢ 2 k / k ! 。这是使用指数函数幂级数的严格推导，不是由数值拟合猜出的分布。

6. “消除 N 的影响”应怎样理解？

消去的是结果中未固定的变量 n ：最终的概率只依赖 k 。但 N 的分布仍然影响结果，例如其参数 8 与单次赔付概率 1 / 4 一起给出新的参数 8 / 4 = 2 。

一般地，若 N ∼ Pois ⁡ ( λ ) ，且给定 N = n 时 M ∼ B ⁡ ( n , p ) （包括 n = 0 的退化情形），同样推导得到 M ∼ Pois ⁡ ( λ ⁢ p ) 。
