第 4 讲　多维随机变量及其分布

1. 定义与直接结论

1.1 联合分布函数【基础补充】

二维随机变量 ( X , Y ) 的联合分布函数为

F ⁡ ( x , y ) = P ⁡ ( X ≤ x , Y ≤ y ) .

它关于每个变量都单调不减、右连续，并满足二维区间概率非负：

P ⁡ ( x 1 < X ≤ x 2 ,   y 1 < Y ≤ y 2 ) = F ⁡ ( x 2 , y 2 ) − F ⁡ ( x 1 , y 2 ) − F ⁡ ( x 2 , y 1 ) + F ⁡ ( x 1 , y 1 ) ≥ 0.

1.2 离散型联合分布

p i ⁢ j = P ⁡ ( X = x i , Y = y j ) , p i ⁢ j ≥ 0 , q ⁢ q ⁢ u ⁢ a ⁢ d ⁢ ∑ i ∑ j p i ⁢ j = 1.

边缘分布：

p i ⋅ = ∑ j p i ⁢ j , p ⋅ j = ∑ i p i ⁢ j .

1.3 连续型联合分布

联合密度 f ⁡ ( x , y ) 满足

f ⁡ ( x , y ) ≥ 0 , q ⁢ q ⁢ u ⁢ a ⁢ d ⁢ ∬ R 2 f ⁡ ( x , y ) d x ⁢ d ⁢ y = 1.

区域概率：

P ⁢ { ( X , Y ) ∈ D } = ∬ D f ⁡ ( x , y ) d x ⁢ d ⁢ y .

边缘密度：

f X ⁡ ( x ) = ∫ − ∞ + ∞ f ⁡ ( x , y ) d y , q ⁢ q ⁢ u ⁢ a ⁢ d ⁢ f Y ⁡ ( y ) = ∫ − ∞ + ∞ f ⁡ ( x , y ) d x .

边缘分布函数也可由联合 CDF 取极限：

F X ⁡ ( x ) = F ⁡ ( x , + ∞ ) , F Y ⁡ ( y ) = F ⁡ ( + ∞ , y ) .

1.4 条件分布与条件密度

离散型：

P ⁡ ( X = x i ∣ Y = y j ) = p i ⁢ j p ⋅ j , p ⋅ j > 0.

连续型：

f X ∣ Y ⁡ ( x ∣ y ) = f ⁡ ( x , y ) f Y ⁡ ( y ) , f Y ⁡ ( y ) > 0.
F X ∣ Y ⁡ ( x ∣ y ) = ∫ − ∞ x f X ∣ Y ⁡ ( u ∣ y ) d u .

条件密度是“固定 Y = y 后，沿该截面的联合密度重新归一化”。即使 P ⁡ ( Y = y ) = 0 ，只要 f Y ⁡ ( y ) > 0 ，条件密度仍有意义。

1.5 独立性的等价判据

X , Y ⁢  独立 ⟺ F ⁡ ( x , y ) = F X ⁡ ( x ) ⁢ F Y ⁡ ( y ) , ∀ x , y .

离散型：

p i ⁢ j = p i ⋅ ⁢ p ⋅ j , ∀ i , j .

连续型：

f ⁡ ( x , y ) = f X ⁡ ( x ) ⁢ f Y ⁡ ( y ) 几乎处处 .

离散表中，若边缘概率均非零，独立等价于各行成比例（联合概率矩阵秩为 1 ）。

1.6 二维均匀分布与二维正态分布

若 ( X , Y ) 在区域 D 上均匀，则

f ⁡ ( x , y ) = { 1 / S D , ( x , y ) ∈ D , 0 , 其他 .

二维正态密度：

f ⁡ ( x , y ) = 1 2 ⁢ π ⁢ σ X ⁢ σ Y ⁢ 1 − ρ 2 ⁢ exp ⁡ { − 1 2 ⁢ ( 1 − ρ 2 ) ⁢ [ ( x − μ X ) 2 σ X 2 − 2 ⁢ ρ ⁢ ( x − μ X ) ⁢ ( y − μ Y ) σ X ⁢ σ Y + ( y − μ Y ) 2 σ Y 2 ] } .

重要结论：

  • 边缘仍为正态： X ∼ N ⁡ ( μ X , σ X 2 ) ， Y ∼ N ⁡ ( μ Y , σ Y 2 ) 。
  • 任意线性组合 a ⁢ X + b ⁢ Y 为正态。
  • 对二维正态， X , Y 独立 ⟺ ρ = 0 。
  • 条件分布：
    X ∣ Y = y ∼ N ⁡ ( μ X + ρ ⁢ σ X σ Y ⁢ ( y − μ Y ) ,   σ X 2 ⁢ ( 1 − ρ 2 ) ) .

2. 考研做题固定流程

流程 A：连续型联合密度题

  1. 先画或写区域 D ，不要先积分。
  2. 用 ∬ D f = 1 求常数。
  3. 求 f X ⁡ ( x ) 时，固定 x ，从图上读出 y 的上下限；求 f Y ⁡ ( y ) 同理。
  4. 求条件密度：联合密度除以对应边缘密度，并重新写条件取值范围。
  5. 判断独立：优先看支撑区域能否写成直积 D X × D Y ；不是矩形通常直接不独立。

流程 B：离散分布表

  1. 用总和为 1 、题目给出的事件关系求未知格。
  2. 行和得到 X 的边缘，列和得到 Y 的边缘。
  3. 条件概率 = 指定格 / 对应行和或列和。
  4. 独立性不能只查一个格；需验证全部格，或证明各行成比例。

流程 C：二维正态

  1. 先把指数中的二次型配方，读出 μ X , μ Y , σ X , σ Y , ρ 。
  2. 线性组合直接算均值和方差：
    E ⁢ ( a ⁢ X + b ⁢ Y ) = a ⁢ μ X + b ⁢ μ Y ,
    D ⁢ ( a ⁢ X + b ⁢ Y ) = a 2 ⁢ σ X 2 + b 2 ⁢ σ Y 2 + 2 ⁢ a ⁢ b ⁢ ρ ⁢ σ X ⁢ σ Y .
  3. 若要求某个线性组合与另一个变量独立，先令协方差为 0 ；二维正态下即可推出独立。

流程 D：用联合分布算区域概率

  • 离散型：把落在区域内的格点概率相加。
  • 连续型：画出 D ，写二重积分。
  • 混合型：按离散条件分层，再用全概率。

3. 补充 / 易错点

高频错误
  • 边缘分布只能由联合分布推出；只知道两个边缘，通常不能唯一确定联合分布。
  • 边缘独立性不能靠“看起来可分离”判断；支撑区域也必须能分离。
  • Cov ⁡ ( X , Y ) = 0 一般只表示不相关，不推出独立；二维正态是重要例外。
  • 条件密度的分母是被固定变量的边缘密度。
  • 二维正态中的参数是方差 σ 2 还是标准差 σ ，读题时要分清。

若支撑区域是斜三角形、圆盘或其他非直积区域，即使联合密度表达式能写成 g ⁡ ( x ) ⁢ h ⁡ ( y ) ， X , Y 通常仍不独立。
