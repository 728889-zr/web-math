第7讲 特征值与特征向量

使用说明单位矩阵统一写 I ，伴随矩阵写 adj ⁡ ( A ) 。

1. 定义与计算

A ⁢ ξ = λ ⁢ ξ , ξ ≠ 0.

则 λ 为特征值， ξ 为对应特征向量。

λ ⁢  是特征值 ⟺ det ⁡ ( λ ⁢ I − A ) = 0.

计算：先求特征方程的根，再对每个不同根求 ( A − λ ⁢ I ) ⁢ x = 0 的基础解系；对应全部特征向量是该解空间的所有非零向量。

tr ⁡ ( A ) = ∑ i λ i , det ⁡ A = ∏ i λ i .

2. 由 A 推到其他矩阵

若 A ⁢ ξ = λ ⁢ ξ ：

矩阵 对应特征值 对应特征向量及条件
k ⁢ A k ⁢ λ ξ
A m λ m ξ ； m 为正整数
f ⁡ ( A ) f ⁡ ( λ ) ξ ； f 为多项式
A − 1 1 / λ ξ ； A 可逆
adj ⁡ ( A ) det ⁡ A / λ ξ ；此写法要求 λ ≠ 0
P − 1 ⁢ A ⁢ P λ P − 1 ⁢ ξ ； P 可逆

A T 与 A 的特征值相同，但对应特征向量通常不同。

当 A 奇异且 λ = 0 时，伴随矩阵公式不能除以 λ ；可以用

μ i = ∏ j ≠ i λ j

描述伴随矩阵的特征值列表，按代数重数理解，不能直接据此断言任意零特征向量的对应关系。

3. 多项式条件的两条规则

若 p ⁡ ( A ) = 0 ，则 A 的每个特征值满足 p ⁡ ( λ ) = 0 。

例如 A 2 = I 推出特征值只能是 1 或 − 1 ，但不表示两个值必须都出现。

反向一般不成立：所有特征值都满足 p ⁡ ( λ ) = 0 ，未必有 p ⁡ ( A ) = 0 。若 A 可对角化，反向才成立。

**Cayley–Hamilton 定理：**若特征多项式为

p A ⁡ ( t ) = t n + c n − 1 ⁢ t n − 1 + ⋯ + c 1 ⁢ t + c 0 ,

则

p A ⁡ ( A ) = A n + c n − 1 ⁢ A n − 1 + ⋯ + c 1 ⁢ A + c 0 ⁢ I = 0.

常数项必须乘单位矩阵。

4. 特征向量的数量与组合

设 λ 是 m 重特征值，则对应特征子空间维数为

g λ = n − r ⁢ ( A − λ ⁢ I ) , 1 ≤ g λ ≤ m .

这里 m 是代数重数， g λ 是几何重数。单根恰有一个线性无关的特征向量。

  • 不同特征值的特征向量线性无关。
  • 同一特征值的特征向量，其非零线性组合仍为该特征值的特征向量。
  • 不同特征值的两个特征向量，若组合系数都非零，则组合不是 A 的特征向量。
  • 实对称矩阵对应不同特征值的特征向量正交。

零向量可以属于特征子空间，但不是特征向量。

5. 从矩阵方程识别特征信息

A ⁢ B = λ ⁢ B ⟹ A ⁢ β j = λ ⁢ β j .

因此 B 的非零列为对应特征向量；若 r ⁡ ( B ) = k ，则此特征值至少有 k 个无关特征向量，代数重数至少为 k 。

A ⁢ P = P ⁢ Λ , P ⁢  可逆 ⟹ P − 1 ⁢ A ⁢ P = Λ .

如果每行元素之和为 s ，则 A ⁢ e = s ⁢ e ，其中 e = ( 1 , … , 1 ) T 。若 A 可逆，则 s ≠ 0 ，且 A − 1 ⁢ e = ( 1 / s ) ⁢ e 。

若 C ⁢ A = λ ⁢ C ，转置后为 A T ⁢ C T = λ ⁢ C T ，一般得到的是 A T 的特征信息；只有额外满足 A T = A 时才能直接作为 A 的特征信息。

6. 交换矩阵的共同特征向量

若 A ⁢ B = B ⁢ A ，且 A 的某个特征值 λ 的特征子空间为一维，则其中非零向量 ξ 也是 B 的特征向量。

因为 A ⁡ ( B ⁢ ξ ) = λ ⁢ B ⁢ ξ ，所以 B ⁢ ξ 落在同一个一维空间内，必为 μ ⁢ ξ ，其中允许 μ = 0 。

条件不可删

一般交换关系只保证 B 保持 A 的特征子空间，不保证 A 的每个特征向量都是 B 的特征向量。

7. 补全：从奇异表达式直接读出特征值

若 a ≠ 0 ，则

det ⁡ ( a ⁢ A + b ⁢ I ) = 0 ⟺ − b a  是  A  的特征值 .

原书例7.1给出三阶 A 满足 det ⁡ A = 3 ，并有

det ⁡ ( A 2 + 2 ⁢ A ) = 0 , det ⁡ ( 2 ⁢ A 2 + A ) = 0.

因为 A 可逆，先分解并消去非零行列式因子：

det ⁡ ( A + 2 ⁢ I ) = 0 , det ⁡ ( 2 ⁢ A + I ) = 0.

所以特征值中有 − 2 , − 1 / 2 ；乘积为 3 ，第三个特征值为 3 。伴随矩阵的特征值因此为 − 3 / 2 , − 6 , 1 ，对角元素之和为

tr ⁡ ( adj ⁡ ( A ) ) = − 13 2 .

注意 A 2 + 2 ⁢ A 奇异不等于 A 2 + 2 ⁢ A = 0 ；题目给行列式为零时，不能误当矩阵恒等式。

8. A 与 A T 的交叉正交关系

若

A ⁢ α = λ ⁢ α , A T ⁢ β = μ ⁢ β , λ ≠ μ ,

则

λ ⁢ α T ⁢ β = ( A ⁢ α ) T ⁢ β = α T ⁢ A T ⁢ β = μ ⁢ α T ⁢ β ,

所以 α T ⁢ β = 0 。

这是一个比“实对称矩阵不同特征值的特征向量正交”更一般的结论：前一个向量属于 A ，后一个向量属于 A T 。当 A = A T 时，才变成同一个矩阵内部的正交性。

9. 特征向量组合：完整分情况

假设 ξ 1 , ξ 2 是特征向量：

条件 c 1 ⁢ ξ 1 + c 2 ⁢ ξ 2 的结论
同一特征值，且组合不为零 仍是该值的特征向量
同一特征值，但组合为零 不是特征向量
不同特征值，两个系数都非零 不是 A 的特征向量
不同特征值，只有一个系数非零 属于对应的那个特征值
两个系数都为零 不是特征向量

“系数不全为零”并不自动保证组合非零，除非被组合向量本来线性无关。

此外，一个非零向量不能同时属于两个不同特征值： A ⁢ ξ = λ ⁢ ξ = μ ⁢ ξ 推出 ( λ − μ ) ⁢ ξ = 0 ，故 λ = μ 。

10. 同一向量是所有多项式矩阵的特征向量

若 A ⁢ ξ = λ ⁢ ξ ，则对有定义的表达式

L ⁡ ( A ) = a ⁢ f ⁡ ( A ) + b ⁢ A − 1 + c ⁢ adj ⁡ ( A )

（这里先假设 A 可逆），对应特征值为

a ⁢ f ⁡ ( λ ) + b λ + c ⁢ det ⁡ A λ .

原因是这些矩阵都在同一个 ξ 上作数乘。若加入 A T ，通常没有这种共同特征向量保证，不能直接把其特征值加进去。

**补充理解：** f ⁡ ( A ) 可拥有比 A 更多的特征向量，因为不同 λ 可能映射到相同 f ⁡ ( λ ) 。例如 A = diag ⁡ ( 1 , − 1 ) ， A 2 = I ，任意非零向量都是 A 2 的特征向量，但不都是 A 的特征向量。

11. 矩阵方程翻译的几个边界

  • A ⁢ B = 0 只说明 B 的非零列是零特征值特征向量。
  • A ⁢ B = B ⁢ Λ 且 Λ 对角，可逐列读出特征值； B 不可逆时不能直接声称完成对角化。
  • 若每个非零向量都满足同一个固定的 A ⁢ ξ = λ ⁢ ξ ，则 A = λ ⁢ I ；只需将标准基代入即可证明。
  • 若 C ⁢ A T = λ ⁢ C ，转置后为 A ⁢ C T = λ ⁢ C T ，这时可读出 A 的特征向量。这与 C ⁢ A = λ ⁢ C 的转置结果不同。

最后两式中 A 的转置位置尤其容易被 OCR 漏掉。

12. 行和信息的扩展

若 A ⁢ e = s ⁢ e ，则对正整数 m ：

A m ⁢ e = s m ⁢ e .

因此 A m 每行元素之和为 s m ；多项式 f ⁡ ( A ) 每行元素之和为 f ⁡ ( s ) 。若 A 可逆，伴随矩阵每行元素之和为 det ⁡ A / s 。

每列和相同则是 e T ⁢ A = s ⁢ e T ，对应 A T 的特征向量关系，方向要分清。

13. 本讲复习检查

  • 把“行列式为零”与“矩阵等于零”分开。
  • 用迹与行列式时按代数重数统计特征值。
  • 能求出特征子空间维数，不只给出一条特征向量。
  • 非零向量条件在组合、矩阵列与特征定义中都检查。
  • 读矩阵方程时核对转置的位置。
  • 交换关系只保留特征子空间；一维或简单谱条件下才进一步确定共同特征向量。
