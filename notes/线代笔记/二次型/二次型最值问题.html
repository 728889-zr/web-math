两个二次型之比的最值

1. 适用形式

求：

f ⁡ ( x ) g ⁡ ( x ) = x T ⁢ A ⁢ x x T ⁢ B ⁢ x , x ≠ 0

其中 A , B 为实对称矩阵，且 B 正定。

2. 固定做题流程

第一步：把 B 分解

由于 B 正定，可写成：

B = D T ⁢ D

其中 D 可逆。

于是：

x T ⁢ B ⁢ x = x T ⁢ D T ⁢ D ⁢ x = ( D ⁢ x ) T ⁢ ( D ⁢ x )

第二步：令新变量

令：

z = D ⁢ x

则：

x = D − 1 ⁢ z

原商变成：

x T ⁢ A ⁢ x x T ⁢ B ⁢ x = z T ⁢ ( D − 1 ) T ⁢ A ⁢ D − 1 ⁢ z z T ⁢ z

记：

M = ( D − 1 ) T ⁢ A ⁢ D − 1

于是：

f ⁡ ( x ) g ⁡ ( x ) = z T ⁢ M ⁢ z z T ⁢ z

第三步：求 M 的特征值

因为 M 为实对称矩阵：

max z ≠ 0 ⁡ z T ⁢ M ⁢ z z T ⁢ z = λ max ⁡ ( M )
min z ≠ 0 ⁡ z T ⁢ M ⁢ z z T ⁢ z = λ min ⁡ ( M )

因此：

max ⁡ f ⁡ ( x ) g ⁡ ( x ) = λ max ⁡ ( ( D − 1 ) T ⁢ A ⁢ D − 1 )

3. 本题流程

先由：

B = D T ⁢ D

再令：

z = D ⁢ x

得到：

M = ( D − 1 ) T ⁢ A ⁢ D − 1

求出 M 的特征值：

λ 1 = 2 , λ 2 = 0

所以：

max ⁡ f ⁡ ( x ) g ⁡ ( x ) = 2

4. 记忆

x T ⁢ A ⁢ x x T ⁢ B ⁢ x → B = D T ⁢ D → z = D ⁢ x z T ⁢ M ⁢ z z T ⁢ z → 求特征值 λ max ⁡ ( M )

核心：

分母不是 x T ⁢ x 时，先利用 B = D T ⁢ D 把分母化成模长平方，再转化为普通 Rayleigh 商。
