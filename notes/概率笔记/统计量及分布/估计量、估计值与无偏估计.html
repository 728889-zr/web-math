估计量、估计值与无偏估计

设

X ∼ P ⁡ ( λ ) , λ > 0

题目要估计的不是 λ 本身，而是

g ⁡ ( λ ) = e − 2 ⁢ λ .

1. 参数函数本身不是随机变量

在经典参数估计中：

λ

以及

g ⁡ ( λ ) = e − 2 ⁢ λ

都是固定但未知的数，因此它们本身没有概率分布。

真正有分布的是由随机样本构成的估计量，例如

T ⁡ ( X 1 , … , X n ) .
易错点

不是“估计 g ⁡ ( λ ) 的分布”，而是用随机变量

T ⁡ ( X 1 , … , X n )

去估计固定但未知的 g ⁡ ( λ ) 。

2. 估计量与估计值的区别

抽样之前：

T ⁡ ( X 1 , … , X n )

是随机变量，叫估计量。

当样本已经观测为

X i = x i

以后：

T ⁡ ( x 1 , … , x n )

变成一个具体数字，叫估计值。

因此：

估计量：随机变量
估计值：样本代入后得到的具体数字
易错点

样本值确定以后，只是得到参数的一个估计值，并不是知道了真实参数值。

3. 无偏估计量的定义

如果 T 用来估计 g ⁡ ( λ ) ，并满足

E ⁡ [ T ] = g ⁡ ( λ ) ,

则称 T 是 g ⁡ ( λ ) 的无偏估计量。

所以：

  • 若估计 λ ，要求

    E ⁡ ( T ) = λ ;

  • 若估计 e − 2 ⁢ λ ，要求

    E ⁡ ( T ) = e − 2 ⁢ λ .

统一记为：

E ⁡ ( 估计量 ) = 待估参数或参数函数

4. 原题为什么取 ( − 1 ) X 1

泊松分布满足

E ⁡ ( t X ) = e λ ⁢ ( t − 1 ) .

令

t = − 1 ,

则

E ⁡ [ ( − 1 ) X ] = e − 2 ⁢ λ .

所以

( − 1 ) X 1

就是 e − 2 ⁢ λ 的无偏估计量。

若样本值

x 1 = 3 ,

则对应估计值为

( − 1 ) 3 = − 1.

注意：

e − 2 ⁢ λ > 0

但无偏估计值可以是负数，这不矛盾，因为无偏性要求的是

E ⁡ ( T ) = e − 2 ⁢ λ ,

而不是要求每一次估计值都落在参数取值范围内。

5. 如果样本容量变成 2

设

X 1 , X 2 ∼ i . i . d . P ⁡ ( λ ) .

由于

E ⁡ [ ( − 1 ) X 1 ] = E ⁡ [ ( − 1 ) X 2 ] = e − 2 ⁢ λ ,

可以构造

T = ( − 1 ) X 1 + ( − 1 ) X 2 2 .

则

E ⁡ ( T ) = 1 2 ⁢ [ e − 2 ⁢ λ + e − 2 ⁢ λ ] = e − 2 ⁢ λ .

所以

T = ( − 1 ) X 1 + ( − 1 ) X 2 2

也是无偏估计量。

若

x 1 = 3 , x 2 = 2 ,

则估计值为

T ⁡ ( 3 , 2 ) = ( − 1 ) 3 + ( − 1 ) 2 2 = 0.

6. 无偏估计量不唯一

同一个参数或参数函数通常可以有多个无偏估计量。

例如当样本容量为 2 时：

X 1 + X 2 ∼ P ⁡ ( 2 ⁢ λ ) .

因此

P ⁡ ( X 1 + X 2 = 0 ) = e − 2 ⁢ λ .

于是还可以构造

T ∗ = I ⁡ ( X 1 + X 2 = 0 ) ,

其中 I ⁡ ( ⋅ ) 为示性函数。

则

E ⁡ ( T ∗ ) = P ⁡ ( X 1 + X 2 = 0 ) = e − 2 ⁢ λ .

所以 T ∗ 也是无偏估计量。

结论

无偏估计量不要求唯一，只要满足

E ⁡ ( T ) = g ⁡ ( λ )

即可。

7. 估计量是否必须使用全部样本

不必须。

例如样本容量为 2 时，

( − 1 ) X 1

仍然是 e − 2 ⁢ λ 的无偏估计量，即使没有使用 X 2 。

但实际构造估计量时，通常更倾向于充分利用所有样本，因为往往可以减小方差、提高稳定性。

因此：

估计量必须是样本的函数，但不要求一定使用全部样本

8. 矩估计与最大似然估计也是估计量

无论是矩估计还是最大似然估计，最后得到的本质都是

θ ^ = T ⁡ ( X 1 , … , X n ) .

因此它们都是随机变量，都有：

E ⁡ ( θ ^ ) , D ⁡ ( θ ^ ) ,

以及抽样分布。

最大似然估计虽然是从似然函数

L ⁡ ( θ )

出发求最大值，但最终得到的仍然是样本的函数：

θ ^ MLE = T ⁡ ( X 1 , … , X n )

如果无法写成简单显式形式，也可以写成

θ ^ MLE = arg ⁡ max θ ⁡ L ⁡ ( θ ; X 1 , … , X n ) .

一句话总结

参数 λ 或参数函数 g ⁡ ( λ ) 是固定但未知的数；
估计量 T ⁡ ( X 1 , … , X n ) 是随机变量；
样本代入后得到估计值；
若

E ⁡ ( T ) = g ⁡ ( λ ) ,

则 T 是 g ⁡ ( λ ) 的无偏估计量。
