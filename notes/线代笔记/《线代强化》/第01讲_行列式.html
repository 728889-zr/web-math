第1讲 行列式

本页定位
  • 1. 基本性质与操作规则
  • 2. 具体型：化为基本形
  • 3. 具体型：加边法、递推法、归纳法
  • 4. 抽象型行列式
  • 5. 解题入口与易错点
  • 6. 对照原书补全的结构与方法
  • 7. 本讲复习检查
使用说明 单位矩阵统一写 I ，伴随矩阵写 adj ⁡ ( A ) 。

1. 基本性质与操作规则

操作或条件 行列式的变化
交换两行或两列 变号
某一行或列乘 k 整个行列式乘 k
某行的 k 倍加到另一行 不变；列操作同理
两行或两列相同或成比例 等于 0
某行或某列全为 0 等于 0
转置 det ⁡ ( A T ) = det ⁡ A
n 阶矩阵整体乘 k det ⁡ ( k ⁢ A ) = k n ⁢ det ⁡ A

拆分规则：每次沿一行或一列的加法拆分。

若某行是 u + v ，则可以拆成这一行分别为 u 、 v 的两个行列式；其余行保持不变。

不可直接拆矩阵加法

一般情况下， det ⁡ ( A + B ) ≠ det ⁡ A + det ⁡ B 。

2. 具体型：化为基本形

2.1 三角形与副对角线形

上三角、下三角和对角矩阵：

det ⁡ A = ∏ i = 1 n a i ⁢ i .

副对角线一侧全为零的副三角形：

det ⁡ A = ( − 1 ) n ⁢ ( n − 1 ) / 2 ⁢ ∏ i = 1 n a i , n + 1 − i .

符号来自把列顺序完全倒置所需的交换次数。

2.2 分块三角形

若 A , B 是方阵，分块大小相容，则

det ⁡ ( A C 0 B ) = det ⁡ ( A 0 C B ) = det ⁡ A ⁢ det ⁡ B .

若 A 为 m 阶、 B 为 n 阶，则

det ⁡ ( 0 A B C ) = ( − 1 ) m ⁢ n ⁢ det ⁡ A ⁢ det ⁡ B .

这里行块大小为 m , n ，列块大小为 n , m ；不能在分块尺寸不相容时套用。

2.3 范德蒙德行列式

det ⁡ ( 1 1 ⋯ 1 x 1 x 2 ⋯ x n ⋮ ⋮ ⋮ x 1 n − 1 x 2 n − 1 ⋯ x n n − 1 ) = ∏ 1 ≤ i < j ≤ n ( x j − x i ) .

识别重点：列内是同一个数的连续幂。调换幂的排列或变量顺序时，需重新检查符号。

3. 具体型：加边法、递推法、归纳法

3.1 加边法

给原行列式增加一行、一列，使新增行列容易展开，且展开后回到原行列式，再利用新增元素制造消元结构。

典型结构为秩一扰动。对于列向量 u , v ∈ R n ：

det ⁡ ( I + u ⁢ v T ) = 1 + v T ⁢ u .

原书的 I + α ⁢ α T 情形给出：

det ⁡ ( I + α ⁢ α T ) = 1 + α T ⁢ α = 1 + ∑ i = 1 n α i 2 .

**补充理解：**若 A 可逆，可以进一步写成

det ⁡ ( A + u ⁢ v T ) = det ⁡ A ⁢ ( 1 + v T ⁢ A − 1 ⁢ u ) .

3.2 递推法

遇到具有重复排列规律的 n 阶行列式：

  1. 按零元素较多的行或列展开。
  2. 把结果化成同结构的 D n − 1 或 D n − 2 。
  3. 给出初值，解递推或猜测后证明。

常见三对角结构：主对角线为 a ，上对角线为 b ，下对角线为 c ，则

D n = a ⁢ D n − 1 − b ⁢ c ⁢ D n − 2 , D 0 = 1 , D 1 = a .
递推的关键

降阶后的行列式必须保留原来的元素排列规律，不能只因阶数少了就记为 D n − 1 。

3.3 数学归纳法

用于猜出的 n 阶公式的证明：检查起始阶；假设较低阶成立；用展开或递推证明下一阶。若递推涉及两个前项，起始值必须覆盖这两个前项。

4. 抽象型行列式

4.1 利用矩阵乘积

同阶方阵满足

det ⁡ ( A ⁢ B ) = det ⁡ A ⁢ det ⁡ B .

若一组列向量都是另一组列向量的线性组合，把系数写成矩阵： C = A ⁢ B ，再计算 det ⁡ C 。

4.2 利用特征值

若 A 的全部特征值为 λ 1 , … , λ n ，按代数重数计算，则

det ⁡ A = ∏ i = 1 n λ i , det ⁡ f ⁡ ( A ) = ∏ i = 1 n f ⁡ ( λ i ) .

**不要求 A 可对角化。**若 f 含逆矩阵，需另加可逆条件。

4.3 利用相似

B = P − 1 ⁢ A ⁢ P ⟹ det ⁡ B = det ⁡ A .

奇数阶实反对称矩阵 A T = − A 满足

det ⁡ A = det ⁡ A T = det ⁡ ( − A ) = ( − 1 ) n ⁢ det ⁡ A = − det ⁡ A ,

所以 det ⁡ A = 0 。

5. 解题入口与易错点

  • 元素有规律：先消元、找三角形、范德蒙德或递推结构。
  • 列是已知向量的组合：写成矩阵乘积。
  • 给特征值或相似条件：把行列式化成特征值的乘积。
  • 要证明行列式为零：找线性相关、非零齐次解、零特征值或秩不足。
  • 含参数消元：除以参数表达式之前，先讨论其为零的情形。

6. 对照原书补全的结构与方法

6.1 拉普拉斯展开的本质（原书第2页）

上述分块三角公式是拉普拉斯展开的常用结果。**补充理解：**选择固定的 k 行 i 1 < ⋯ < i k ，再枚举 k 列 j 1 < ⋯ < j k ，用选中行列的子式乘其补子式，并附符号

( − 1 ) i 1 + ⋯ + i k + j 1 + ⋯ + j k .

对所有列选择求和，就得到原行列式。分块中大量项因零块消失，剩下主块乘积。

原书还列出

det ⁡ ( C A B 0 ) = det ⁡ ( 0 A B C ) = ( − 1 ) m ⁢ n ⁢ det ⁡ A ⁢ det ⁡ B ,

其中 A 为 m 阶、 B 为 n 阶；两个式子的 C 分别须具有各自相容的尺寸。这里的 C 是泛指对应位置的任意块，不能据此混淆它们的形状。

6.2 三种常用消元观察（原书第2页）

  1. 零多就展开：减少非零展开项，而不是机械从第一行开始。
  2. 元素相近就相减：尤其某两行或两列只差少数位置时，可迅速制造零。
  3. 行和或列和相同就汇总：把各列加到某一列，得到相同的行和，再提公因子、做差消元；列和相同时对行操作。

若元素含参数 x ，得到的是关于 x 的多项式。求根数时先化简这个多项式，不必先求出参数矩阵每个元素的性质。

6.3 加边法的实际构造（原书第3–4页）

对 I + u ⁢ u T ，考虑

K = ( 1 u T − u I ) .

把第一行的 u i 倍加到第 i + 1 行，得

det ⁡ K = det ⁡ ( I + u ⁢ u T ) .

另一方面，把下方各行分别乘 − u i 加到第一行，第一行变成 ( 1 + u T ⁢ u , 0 , … , 0 ) ，故

det ⁡ K = 1 + u T ⁢ u .

方法要点：新增行列既要保证原行列式值不变，又要方便制造零。

6.4 原书递推例的完整结构（例1.4，第5–6页）

矩阵前 n − 1 行的主对角元素为 b 、上对角为 − 1 ，其他位置为零；最后一行为

( a n , a n − 1 , … , a 2 , b + a 1 ) .

其行列式满足

D n = b ⁢ D n − 1 + a n , D 1 = b + a 1 .

反复代入得到

D n = b n + a 1 ⁢ b n − 1 + a 2 ⁢ b n − 2 + ⋯ + a n − 1 ⁢ b + a n .

这里沿第一列展开可以保留结构；改沿不合适的列展开，未必能直接出现同结构的 D n − 1 。

原书例1.5的三对角结构是主对角为 2 ⁢ a 、上对角为 1 、下对角为 a 2 ，所以

D n = 2 ⁢ a ⁢ D n − 1 − a 2 ⁢ D n − 2 , D 1 = 2 ⁢ a , D 2 = 3 ⁢ a 2 .

归纳证明结果为

D n = ( n + 1 ) ⁢ a n .

第一类例题重在“求出递推”；第二类题已给结果，重在“用递推证明结果”。

6.5 正交条件下证明行列式为零

若 A , B 为同阶正交矩阵，令

S = A T ⁢ B − B T ⁢ A .

则 S T = − S 。同时

det ⁡ ( ( A − B ) ⁢ ( A + B ) ) = det ⁡ ( ( A − B ) T ⁢ ( A + B ) ) = det ⁡ S .

第一步只用了 det ⁡ ( A − B ) = det ⁡ ( ( A − B ) T ) ，不是说两个乘积矩阵相同。若阶数为奇数， det ⁡ S = 0 ，于是所求行列式为零。

6.6 从伴随矩阵特征值反推

四阶 A 的伴随矩阵特征值为 1 , − 1 , − 2 , 4 ，因此

det ⁡ ( adj ⁡ ( A ) ) = 8 = ( det ⁡ A ) 3 , det ⁡ A = 2.

由非零伴随特征值推出 A 可逆，进而 A 的特征值为

2 , − 2 , − 1 , 1 2 .

对 f ⁡ ( t ) = t 3 + 2 ⁢ t 2 − t − 3 ，有

f ⁡ ( 2 ) = 11 , f ⁡ ( − 2 ) = − 1 , f ⁡ ( − 1 ) = − 1 , f ⁡ ( 1 / 2 ) = − 23 / 8.

所以

det ⁡ ( A 3 + 2 ⁢ A 2 − A − 3 ⁢ I ) = − 253 8 .

这类题分三步：伴随行列式求 det ⁡ A → 反推 A 特征值 → 代入多项式并相乘。

6.7 常对角、常非对角矩阵

对角元素为 a ，其他元素为 b 的 n 阶矩阵，行列式为

[ a + ( n − 1 ) ⁢ b ] ⁢ ( a − b ) n − 1 .

也可写成 M = ( a − b ) ⁢ I + b ⁢ e ⁢ e T ， e = ( 1 , … , 1 ) T ，因此特征值为 a + ( n − 1 ) ⁢ b 和 a − b （后者 n − 1 重）。

原书矩阵为对角 k 、非对角 k ⁢ a ，且 0 < a < 1 、 k > 0 ，故最大特征值为

λ max = k ⁢ [ 1 + ( n − 1 ) ⁢ a ] .

  • 会识别行和相同、对应位置相近和零较多三类消元入口。
  • 能建立保留元素规律的递推式，并写明初值。
  • 能从伴随矩阵的特征值反推原矩阵行列式与特征值。
  • 能根据题目数域和参数条件检查每一次除法。
