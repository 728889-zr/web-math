考研积分中的空间几何

本笔记整合原有的旋转曲面、空间圆、法向量和积分方向笔记。只讨论考研高数中建立积分区域、计算线面积分所需的空间几何；曲线积分、曲面积分部分按所报数学类别的考试范围使用。

学习顺序：认出线和面 → 算夹角、距离 → 写旋转方程 → 写区域与上下限 → 判断积分方向。

1. 用点和向量表示直线、平面

1.1 向量只需掌握这几项

对 a = ( a 1 , a 2 , a 3 ) 、 b = ( b 1 , b 2 , b 3 ) ：

| a | = a 1 2 + a 2 2 + a 3 2 , a ⋅ b = a 1 ⁢ b 1 + a 2 ⁢ b 2 + a 3 ⁢ b 3 .

点积用来算夹角和投影。 a ⋅ b = 0 表示两个非零向量垂直。

a × b = ( a 2 ⁢ b 3 − a 3 ⁢ b 2 ,   a 3 ⁢ b 1 − a 1 ⁢ b 3 ,   a 1 ⁢ b 2 − a 2 ⁢ b 1 ) .

叉积垂直于两个原向量，其长度是它们张成的平行四边形面积。两个非零向量叉积为零，表示它们平行。

1.2 直线：一个点，加一个方向

过 A = ( a , b , c ) ，方向向量为 v = ( l , m , n ) ≠ 0 ：

( x , y , z ) = ( a , b , c ) + t ⁡ ( l , m , n ) , t ∈ R .

若 l , m , n 都不为零，也可写成

x − a l = y − b m = z − c n .

方向分量为零时，用参数式，不能写分母为零的分式。

  • 过两点 A , B ：方向取 B − A 。
  • x = 0 ,   y = 1 ： z 自由，是平行于 z 轴的直线。
  • 两个不平行平面相交：联立两个方程表示交线，方向可取两个法向量的叉积。
  • 线段 A ⁢ B ： A + t ⁢ ( B − A ) ，额外限制 0 ≤ t ≤ 1 。

例如过 ( 1 , 0 , 0 ) 、 ( 0 , 1 , 1 ) 的直线为

( x , y , z ) = ( 1 − t , t , t ) .

1.3 平面：一个点，加一个法向量

过 A = ( a , b , c ) ，法向量为 n = ( A 1 , B 1 , C 1 ) ≠ 0 ：

A 1 ⁢ ( x − a ) + B 1 ⁢ ( y − b ) + C 1 ⁢ ( z − c ) = 0.

一般式 A ⁢ x + B ⁢ y + C ⁢ z + D = 0 的法向量就是 ( A , B , C ) 。

例如“过 ( 1 , 0 , 0 ) 且垂直于直线 x = y = z 的平面”，法向量取直线方向 ( 1 , 1 , 1 ) ，所以平面为 x + y + z = 1 。

判断维数时看自由度：空间中的一个普通平面方程通常留下两个自由度；两个独立平面方程留下一个自由度。但不能机械地数方程，例如 x 2 + y 2 + z 2 = 0 实际只有一个点。

2. 空间中两直线的夹角

2.1 先找方向向量，再用点积

若两直线方向为 v 1 , v 2 ，两直线夹角按较小角取 θ ∈ [ 0 , π / 2 ] ：

cos ⁡ θ = | v 1 ⋅ v 2 | | v 1 | ⁢ | v 2 | .

绝对值的作用：把钝角转换成与之互补的锐角。直线没有固定箭头，反向选取方向向量不应改变两直线夹角。

异面直线也用这个公式。 可以把其中一条平移到与另一条相交，方向不变，夹角不变。

例如 z 轴方向为 ( 0 , 0 , 1 ) ，直线 x = y = z 的方向为 ( 1 , 1 , 1 ) ，所以

cos ⁡ θ = 1 3 , sin ⁡ θ = 2 3 , tan ⁡ θ = 2 .

这也是 z 轴绕 x = y = z 旋转形成的圆锥的半顶角。

2.2 顺带区分另外两种夹角

对象 使用的向量 较小夹角公式
两直线 两个方向向量 cos ⁡ θ = | v 1 ⋅ v 2 | ‖ v 1 ‖ ⁢ ‖ v 2 ‖
两平面 两个法向量 cos ⁡ θ = | n 1 ⋅ n 2 | ‖ n 1 ‖ ⁢ ‖ n 2 ‖
直线与平面 直线方向、平面法向量 sin ⁡ θ = | v ⋅ n | ‖ v ‖ ⁢ ‖ n ‖

线面夹角用正弦，是因为线与面的夹角，与线和法向量的较小夹角互余。

3. 点到直线、平面的距离

距离都指最短距离，即垂线段的长度。 不要随便选线上或面上一个点来算两点距离。

3.1 点到直线：去掉沿直线的分量

直线经过 A ，方向为 v ≠ 0 。点 H 是从 P 向直线作垂线得到的垂足，满足 H 在直线上、 H ⁡ P → ⋅ v = 0 。对直线上任一点 Q ，勾股定理给出 P ⁢ Q 2 = P ⁢ H 2 + H ⁡ Q 2 ，所以最短距离在 Q = H 时取得。

令 q = P − A 、 u = v / | v | 。 q ⋅ u 是从 A 到 H 沿直线的有向位移，是一个数。乘上单位方向 u 才得到位移向量 A ⁢ H → ：

q = ( q ⋅ u ) ⁢ u ⏟ A ⁢ H → + [ q − ( q ⋅ u ) ⁢ u ] ⏟ H ⁡ P → .

把位移向量加到 A 上就得到 H 。在直角三角形 A ⁢ H ⁡ P 中用勾股定理得到距离公式：

H = A + ( q ⋅ u ) ⁢ u , d = | q | 2 − ( q ⋅ u ) 2 .

也可使用叉积形式：

d = | q × v | | v | .

理解：分子是平行四边形面积，除以底边 | v | ，就是高。

例：求 P = ( 0 , 0 , a ) 到 x = y = z 的垂足和距离。

先用垂直条件求 H 。 轴上的点三个坐标相等，所以设 H = ( t , t , t ) 。轴方向取 v = ( 1 , 1 , 1 ) ，而 H ⁡ P → = P − H = ( − t , − t , a − t ) ，于是

H ⁡ P → ⋅ v = − t − t + ( a − t ) = a − 3 ⁢ t = 0.

解得 t = a / 3 ，所以 H = ( a / 3 , a / 3 , a / 3 ) 。直接算线段 P ⁢ H 的长度：

d = P ⁢ H = ( − a / 3 ) 2 + ( − a / 3 ) 2 + ( 2 ⁢ a / 3 ) 2 = 2 3 ⁢ | a | .

对照之前答疑里的投影法。 当时选轴上的坐标原点 O 作起点，所以 q = O ⁢ P → = ( 0 , 0 , a ) ， u = ( 1 , 1 , 1 ) / 3 。投影先给出沿轴位移 h = a / 3 ，再给出垂足：

h = q ⋅ u = a 3 , H = O + h ⁡ u = ( a / 3 , a / 3 , a / 3 ) .

这里 h 是沿单位方向量出的有向长度， t = a / 3 是 H 的每个坐标，两者满足 t = h ⁡ / 3 。答疑和整合稿都可用 P ⁢ H 2 = O ⁢ P 2 − O ⁢ H 2 = a 2 − ( a / 3 ) 2 计算距离。

同一例再用叉积核对。 用未单位化的方向向量 v = ( 1 , 1 , 1 ) ，有 q × v = ( − a , a , 0 ) ，因此

d = | ( − a , a , 0 ) | | ( 1 , 1 , 1 ) | = 2 ⁢ | a | 3 = 2 3 ⁢ | a | .

投影法把 P ⁢ H 作为直角三角形的直角边来求，叉积法把同一段 P ⁢ H 作为平行四边形的高来求。只求距离时两种都可以。还要求垂足或旋转轨道圆心时，可先用投影或垂直条件求 H 。当 | a | = 1 时，距离为 6 / 3 。

3.2 点到平面：取沿法向量的分量

记忆

点 P = ( x 0 , y 0 , z 0 ) 到平面 A ⁢ x + B ⁢ y + C ⁢ z + D = 0 的距离为

d = | A ⁢ x 0 + B ⁢ y 0 + C ⁢ z 0 + D | A 2 + B 2 + C 2 .

原因：取平面上任意点 Q ， P − Q 在单位法向量上的投影长度，就是垂直距离。

若还要求垂足，记 L = A ⁢ x 0 + B ⁢ y 0 + C ⁢ z 0 + D ，则

H = P − L A 2 + B 2 + C 2 ⁢ ( A , B , C ) .

例如原点到 x + y + z = 1 的距离为 1 / 3 ，垂足为 ( 1 / 3 , 1 / 3 , 1 / 3 ) 。

平行平面 A ⁢ x + B ⁢ y + C ⁢ z = d 1 与 A ⁢ x + B ⁢ y + C ⁢ z = d 2 的距离为

| d 2 − d 1 | A 2 + B 2 + C 2 .

使用前应先把两平面的法向系数调整为相同的一组。

最容易混的地方： 点到线，要去掉“沿线”的部分；点到面，要保留“沿法线”的部分。

4. 把文字中的线、面、区域写成方程

4.1 先确定要描述什么

文字 代数表达 描述的对象
到原点距离等于 R > 0 x 2 + y 2 + z 2 = R 2 球面
到原点距离不超过 R x 2 + y 2 + z 2 ≤ R 2 球体
到 z 轴距离等于 R x 2 + y 2 = R 2 圆柱面， z 自由
高度 z = c 、到 z 轴距离等于 R z = c ,   x 2 + y 2 = R 2 圆周
高度 z = c 、到 z 轴距离不超过 R z = c ,   x 2 + y 2 ≤ R 2 圆盘
位于两平面 z = a , z = b 之间， a < b a ≤ z ≤ b 一个位置限制
第一卦限 x , y , z ≥ 0 三个位置限制

“面”“面内的区域”“面围成的立体”必须区分。等式通常描述边界，不等式用来选取内部或一侧。

4.2 考研积分中常见曲面

下面 a , b , c , R > 0 ：

方程 几何形状 看截面的办法
x 2 + y 2 + z 2 = R 2 球面 固定 z ，圆半径为 R 2 − z 2
x 2 / a 2 + y 2 / b 2 + z 2 / c 2 = 1 椭球面 固定一个坐标，得到椭圆
x 2 + y 2 = R 2 圆柱面 每个高度都是同样的圆

z = x 2 + y 2 旋转抛物面 截面半径为 z ，且 z ≥ 0

双叶双曲面可改写为 x 2 + y 2 = z 2 − 1 。固定 z 后，右边是截面圆的半径平方。 | z | > 1 时截面是半径 z 2 − 1 的圆。 z = ± 1 时截面各缩成一个点。 − 1 < z < 1 时右边为负，截面为空，因此上下两叶分开。

没有某个坐标，意味着沿该坐标方向不受限制，不是该坐标等于零。

4.3 翻译文字的固定步骤

  1. 设待求点为 ( x , y , z ) 。若涉及旋转，用参数单独表示旋转前的点。
  2. 把“距离、垂直、平行、旋转”分别换成距离式、点积、方向向量和旋转不变量。
  3. 把“之间、上方、内部、第一卦限”补成不等式。
  4. 联立边界求交线，检查是否要分段。
  5. 选一个明显满足题意的点，代入检查不等号方向。

平方会丢失符号限制。 例如 z = x 2 + y 2 平方后，要写成 z 2 = x 2 + y 2 ,   z ≥ 0 ，否则多出下半锥面。

5. 绕轴旋转：同时保留轴向位置和半径

5.1 一个点旋转成什么？

轴外一点绕轴旋转一周，形成一个圆：圆心是点到轴的垂足，圆所在平面垂直于轴，半径是点到轴的距离。轴上的点保持不动。

两个不变量：沿轴的位置不变，到轴的距离不变。

图中轴为 x = 0 , y = 1 ，旋转前的点为 P = ( 1 , 2 , 2 ) 。轴上的点具有形式 ( 0 , 1 , s ) ，垂足须与 P 等高，所以 H = ( 0 , 1 , 2 ) 。 P ⁢ H = 2 ，旋转后的轨道满足

z = 2 , x 2 + ( y − 1 ) 2 = 2.

5.2 绕坐标轴或与其平行的轴

若原曲线在每个高度处可写为 P ⁡ ( z ) = ( x 0 ⁡ ( z ) , y 0 ⁡ ( z ) , z ) ，绕轴 x = a , y = b ：

( x − a ) 2 + ( y − b ) 2 = [ x 0 ⁡ ( z ) − a ] 2 + [ y 0 ⁡ ( z ) − b ] 2 .

左边是旋转后点到轴的距离平方；右边是原曲线在同一高度处的半径平方。原曲线的 z 范围必须保留；同一高度若有多个半径，要保留全部分支。

常用轴的距离平方：

轴 轴向坐标 距离平方
x 轴 x y 2 + z 2
y 轴 y x 2 + z 2
z 轴 z x 2 + y 2
x = a , y = b z ( x − a ) 2 + ( y − b ) 2
y = b , z = c x ( y − b ) 2 + ( z − c ) 2

例：同一条直线绕 z 轴和偏移轴。

原直线过 A = ( 1 , 0 , 0 ) 与 B = ( 0 , 1 , 1 ) ，参数式为 ( 1 − t , t , t ) 。两个旋转轴都平行于 z 轴，所以 z = t 。固定高度 z ，原直线上对应的点是 P ⁡ ( z ) = ( 1 − z , z , z ) 。

  1. 绕 z 轴。 圆心为 H 0 = ( 0 , 0 , z ) 。向量 H 0 ⁡ P → = ( 1 − z , z , 0 ) ，所以半径平方为 ( 1 − z ) 2 + z 2 。旋转后的方程为

    x 2 + y 2 = ( 1 − z ) 2 + z 2 = 2 ⁢ ( z − 1 2 ) 2 + 1 2 .

    最小半径为 1 / 2 ，每个高度都有非退化圆周，形成单叶双曲面。

  2. 绕偏移轴 x = 0 , y = 1 。 圆心改为 H 1 = ( 0 , 1 , z ) ，向量 H 1 ⁡ P → = ( 1 − z , z − 1 , 0 ) 。重新计算半径平方，得到

    x 2 + ( y − 1 ) 2 = ( 1 − z ) 2 + ( z − 1 ) 2 = 2 ⁢ ( z − 1 ) 2 .

    当 z = 1 时， P ⁡ ( 1 ) = B 正好在新轴上，半径降到零， B 成为锥顶。其余高度的半径为 2 ⁢ | z − 1 | ，因此形成双圆锥面。

左图的截面圆始终有正半径，右图的截面圆在 z = 1 缩为一点。图示截取 0 ≤ z ≤ 2 。若题目说的是整条直线，则 z 可取任意实数。若只转动线段 A ⁢ B ，则取 0 ≤ z ≤ 1 ，右图对应锥顶以下的一支。

y 2 + z 2 = f ⁡ ( x ) 2 .

5.3 绕斜轴：把“高度”改成沿轴投影

轴经过 A ，单位方向为 u 。旋转前的点为 P ⁡ ( t ) ，旋转后的点为 Q = ( x , y , z ) 。先计算

消去 t ，再保留题目的范围。第一式固定沿轴位置，第二式固定半径。

例： z 轴绕 x = y = z 。

取 P ⁡ ( t ) = ( 0 , 0 , t ) 、 u = ( 1 , 1 , 1 ) / 3 ：

5.4 曲线旋转与区域旋转要区分

固定轴向位置后：

  • 半径只有一个值 R ：圆周，方程 ρ 2 = R 2 。
  • 半径覆盖 0 ≤ ρ ≤ R ：圆盘，面积 π ⁢ R 2 。
  • 半径覆盖 r ≤ ρ ≤ R ：圆环，面积 π ⁢ ( R 2 − r 2 ) 。

求旋转体体积时，若轴向坐标 h 是实际长度：

V = ∫ h 1 h 2 π ⁢ [ R ⁢ ( h ) 2 − r ⁢ ( h ) 2 ] d h .

半径是距离，不一定等于原区域端点的坐标。例如 0 ≤ y ≤ 3 绕 y = 1 旋转，距离 | y − 1 | 覆盖 [ 0 , 2 ] ，截面是半径 2 的圆盘，不能用 π ⁢ ( 2 2 − 1 2 ) 。

斜轴题若使用 s = x + y + z ，实际轴向长度是 h = s / 3 ，因此 d ⁢ h = d ⁢ s / 3 ，不能漏掉系数。

6. 从方程写出积分区域

6.1 先投影，再写上下界

若立体在两个曲面之间：

Ω = { ( x , y ) ∈ D ,   z − ⁡ ( x , y ) ≤ z ≤ z + ⁡ ( x , y ) } ,

则

∭ Ω f ⁡ d ⁢ V = ∬ D ∫ z − z + f ⁡ ( x , y , z ) d z d x ⁢ d ⁢ y .

投影 D 是所有能找到合法 z 的 ( x , y ) ，因此必须满足 z − ≤ z + ，还要满足其余边界条件。

例 1：柱面 x 2 + y 2 = 1 与平面 z = 0 , x + z = 1 围成的立体。

x 2 + y 2 ≤ 1 , 0 ≤ z ≤ 1 − x .

圆盘内 x ≤ 1 ，所以上界不低于下界。可以写成

− 1 ≤ x ≤ 1 , − 1 − x 2 ≤ y ≤ 1 − x 2 , 0 ≤ z ≤ 1 − x .

例 2：抛物面 z = x 2 + y 2 与平面 z = 1 围成的立体。

先由上下界有序得 x 2 + y 2 ≤ 1 ，因此

0 ≤ r ≤ 1 , 0 ≤ θ ≤ 2 ⁢ π , r 2 ≤ z ≤ 1.

柱坐标下 x = r ⁢ cos ⁡ θ , y = r ⁢ sin ⁡ θ ，体积元为 d ⁢ V = r d ⁢ z d ⁢ r d ⁢ θ 。

6.2 两种常用换元的空间含义

换元 定义与体积元 适合的区域
柱坐标 x = r ⁢ cos ⁡ θ , y = r ⁢ sin ⁡ θ , z = z ； d ⁢ V = r d ⁢ r d ⁢ θ d ⁢ z 圆柱、绕 z 轴的锥面和抛物面
球坐标 x = ρ ⁢ sin ⁡ φ ⁢ cos ⁡ θ , y = ρ ⁢ sin ⁡ φ ⁢ sin ⁡ θ , z = ρ ⁢ cos ⁡ φ ； d ⁢ V = ρ 2 ⁢ sin ⁡ φ d ⁢ ρ d ⁢ φ d ⁢ θ 球、球与圆锥相交的区域

这里球坐标的 φ 从 + z 轴向下量，通常 0 ≤ φ ≤ π ； θ 是绕 z 轴的方位角。符号约定必须先看清。

例如单位球内、上锥面 z = x 2 + y 2 上方：

0 ≤ ρ ≤ 1 , 0 ≤ φ ≤ π 4 , 0 ≤ θ ≤ 2 ⁢ π .

依据是 ρ ⁢ cos ⁡ φ ≥ ρ ⁢ sin ⁡ φ 。原点处角度不唯一，不影响积分。

先从不等式确定范围，再写积分；不要只凭“像个圆”就给所有角度都写满一周。

7. 球面与平面的交线：优先识别圆

球心 C 、球半径 R ，球心到平面距离为 d ：

  • d < R ：交线是圆，圆心是 C 到平面的垂足，半径 r = R 2 − d 2 。
  • d = R ：只有一个切点。
  • d > R ：没有交点。

公式来自球心、截面圆心、圆上点组成的直角三角形：

r 2 + d 2 = R 2 , ∮ Γ d s = 2 ⁢ π ⁢ r .

原笔记中的“球面加平面就是圆”，应补上 d < R 这个条件。

原题整合：

Γ : x 2 + y 2 + z 2 = 1 , x + y + z = 1 , I = ∮ Γ ( y 2 + 2 ⁢ x − z ) d s .

交线在坐标轮换下不变，且轮换保持弧长，所以三个轮换后的积分相等。取平均：

I = 1 3 ⁢ ∮ Γ ( x 2 + y 2 + z 2 + x + y + z ) d s = 2 3 ⁢ ∮ Γ d s .

这里 d = 1 / 3 、 r = 2 / 3 ，所以

I = 4 ⁢ 6 ⁢ π 9 .

这类题先看曲线上是否有恒等关系和对称性，积分若只剩常数乘 d ⁢ s ，直接求周长。

8. 法向量、方向与线面积分

8.1 法向量与单位法向量不同

对光滑曲面 G ⁡ ( x , y , z ) = 0 ，在 ∇ G ≠ 0 处：

n = ∇ G = ( G x , G y , G z ) , n ^ = ± ∇ G | ∇ G | .

曲面方向余弦就是单位法向量的三个分量，不需要先求三个角。 ∇ G = 0 时，不能直接用此式得到法向量。

上侧看 n z > 0 ，下侧看 n z < 0 ；朝 + x 看 n x > 0 ，朝 + y 看 n y > 0 。“前后左右”必须结合题目的坐标约定，不能脱离图示固定背诵。

外侧指向立体外部。例如区域 G ≤ 0 的光滑边界， ∇ G 指向 G 增大的外侧。

8.4 斯托克斯公式：边界与法向必须匹配

方向用右手规则：大拇指指向法向，四指弯曲方向是边界正向。从法向箭头尖端朝曲面看，正向边界为逆时针。

平面区域取 + z 法向时，从上方看外边界逆时针、孔洞边界顺时针。更换曲面简化计算时，边界及其方向必须一致，且新曲面上向量场仍须满足公式条件。

9. 做空间积分题时的检查表

  1. 对象： 是直线、圆周、曲面、圆盘，还是立体？
  2. 位置： 轴经过哪里，方向是什么？是否有平移？
  3. 条件： 等式、不等式和参数范围是否写全？平方是否多出分支？
  4. 距离： 用的是垂直距离还是误用了两点距离？参数和绝对值有没有漏？
  5. 旋转： 轴向位置与到轴距离是否同时保留？截面是圆周、圆盘还是圆环？
  6. 积分区域： 上界是否始终不低于下界？要不要分段？换元因子是否写上？
  7. 方向： 第一类还是第二类？外侧、上侧和边界方向是否匹配？
