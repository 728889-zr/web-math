第18讲 多元函数积分学

1. 定义与直接结论

三重积分

直角坐标：

∭ Ω f ⁡ ( x , y , z ) d V .

柱坐标：

x = r ⁢ cos ⁡ θ , y = r ⁢ sin ⁡ θ , d ⁢ V = r d ⁢ r d ⁢ θ d ⁢ z .

球坐标：

x = ρ ⁢ sin ⁡ φ ⁢ cos ⁡ θ , y = ρ ⁢ sin ⁡ φ ⁢ sin ⁡ θ , z = ρ ⁢ cos ⁡ φ ,
d ⁢ V = ρ 2 ⁢ sin ⁡ φ d ⁢ ρ d ⁢ φ d ⁢ θ .
形心先看对称性

求形心时先看区域是否对称，能直接确定的坐标不要积分。

二维平面区域：

x ¯ = 1 A ⁢ ∬ D x d A , y ¯ = 1 A ⁢ ∬ D y d A .

若关于 y 轴对称，则 x ¯ = 0 ；关于 x 轴对称，则 y ¯ = 0 。

三维区域：

x ¯ = 1 V ⁢ ∭ Ω x d V , y ¯ = 1 V ⁢ ∭ Ω y d V , z ¯ = 1 V ⁢ ∭ Ω z d V .

若关于 y ⁢ z , x ⁢ z , x ⁢ y 平面对称，则对应有

x ¯ = 0 , y ¯ = 0 , z ¯ = 0.

若关于 z 轴旋转对称，则

x ¯ = y ¯ = 0 .

考试反射：先用对称性定坐标，再只积分剩下的坐标。

第一型曲线积分

∫ L f ⁡ ( x , y , z ) d s .

参数化 r ⁡ ( t ) ：

d ⁢ s = | r ′ ⁡ ( t ) | ⁢ d ⁢ t .

第一型曲面积分

∬ Σ f ⁡ ( x , y , z ) d S .

若 z = z ⁡ ( x , y ) ：

d ⁢ S = 1 + z x 2 + z y 2 d ⁢ x ⁢ d ⁢ y .

第二型曲线积分

∫ L P d x + Q ⁢ d ⁢ y + R ⁢ d ⁢ z .

参数化后：

∫ a b ( P ⁢ x ′ ⁡ ( t ) + Q ⁢ y ′ ⁡ ( t ) + R ⁢ z ′ ⁡ ( t ) ) d t .

方向反向，积分变号。

∮ L P ⁡ ( x , y ) d x + Q ⁡ ( x , y ) ⁢ d ⁢ y = ∬ D ( ∂ Q ∂ x − ∂ P ∂ y ) d σ .

如图所示, 所谓 L 取正向, 是指当一个人沿着 L 的这个方向前进时, 左手始终在 L 所围成的 D 内. ①曲线封闭且无奇点在其内部, 直接用格林公式. 若给的是封闭曲线的曲线积分 ∮ L P d x + Q ⁢ d ⁢ y ，可以验算 P 和 Q 是否满足“在该封闭曲线所包围的区域D内，P和Q具有一阶连续偏导数”.若满足，则可用格林公式

∮ L P d x + Q d ⁢ y = ∬ D ( ∂ Q ∂ x − ∂ P ∂ y ) d σ

计算之.这里要求L为D的边界,且正向.

正向闭曲线内部有奇点：

∮ L P d x + Q ⁢ d ⁢ y = ( ∗ ) ∮ L 1 P d x + Q ⁢ d ⁢ y .

这里要求 L 1 与L的方向相同.如果后者容易计算,即可达到目的. 【注】（*）处是这样来的：如图所示，若 L 所围区域 D 内有奇点 q ，则用 L 1 “挖去”它，并记挖去奇点后的阴影区域为 D ′ ，于是

∮ L P d x + Q ⁢ d ⁢ y = ∮ L + L 1 − P d x + Q ⁢ d ⁢ y − ∮ L 1 − P d x + Q ⁢ d ⁢ y = ∬ D ′ ( ∂ Q ∂ x − ∂ P ∂ y ) d σ + ∮ L 1 P d x + Q ⁢ d ⁢ y = ∮ L 1 P d x + Q ⁢ d ⁢ y .

Stokes 后如何选曲面积分与投影

Stokes：

∮ L P d x + Q ⁢ d ⁢ y + R ⁢ d ⁢ z = ∬ Σ ( ∇ × F ) ⋅ n d S = ∬ Σ A d y ⁢ d ⁢ z + B d ⁢ z ⁢ d ⁢ x + C d ⁢ x ⁢ d ⁢ y .

两种写法等价：

  • ( ∇ × F ) ⋅ n d ⁢ S ：按第一类曲面积分处理；
  • A d ⁢ y ⁢ d ⁢ z + B d ⁢ z ⁢ d ⁢ x + C d ⁢ x ⁢ d ⁢ y ：按第二类曲面积分处理，通常投影更快。

若曲面写成 z = z ⁡ ( x , y ) ，投到 x ⁢ O ⁢ y ，上侧有

n d ⁢ S = ( − z x , − z y , 1 ) ⁢ d ⁢ x ⁢ d ⁢ y

因而

d ⁢ y ⁢ d ⁢ z = − z x ⁢ d ⁢ x ⁢ d ⁢ y , d ⁢ z ⁢ d ⁢ x = − z y ⁢ d ⁢ x ⁢ d ⁢ y , d ⁢ x ⁢ d ⁢ y = d ⁢ x ⁢ d ⁢ y .

也可由

d ⁢ z = z x ⁢ d ⁢ x + z y ⁢ d ⁢ y

理解。

第一类投影：

d ⁢ S = 1 + z x 2 + z y 2 d ⁢ x ⁢ d ⁢ y .

第二类投影：

A d ⁢ y ⁢ d ⁢ z + B d ⁢ z ⁢ d ⁢ x + C d ⁢ x ⁢ d ⁢ y → ( − A ⁢ z x − B ⁢ z y + C ) ⁢ d ⁢ x ⁢ d ⁢ y .

选投影面：“上/下侧”优先投 x ⁢ O ⁢ y ；“前/后侧”优先投 x ⁢ O ⁢ z ；“左/右侧”优先投 y ⁢ O ⁢ z 。

**易错：**第一类方法本身没错，但若选错投影面，容易引入根号和分母；Stokes 后通常优先保留第二类形式直接投影。

第二型曲面积分

∬ Σ P d y ⁢ d ⁢ z + Q d ⁢ z d ⁢ x + R d ⁢ x d ⁢ y = ∬ Σ F ⋅ n d S .
第二类曲面积分的方向

第二类曲面积分本质为

∬ Σ ( P , Q , R ) ⋅ n d S ,

所以方向就是确定法向量 n 的正负。

若 z = z ⁡ ( x , y ) ：

上侧 :   n ⁢ d ⁢ S = ( − z x , − z y , 1 ) ⁢ d ⁢ x ⁢ d ⁢ y

下侧整体取负。

同理：

x = x ⁡ ( y , z ) ,   n x > 0 : ( 1 , − x y , − x z ) ⁢ d ⁢ y ⁢ d ⁢ z
y = y ⁡ ( x , z ) ,   n y > 0 : ( − y x , 1 , − y z ) ⁢ d ⁢ x ⁢ d ⁢ z

判断方向最稳的方法：看题目要求的法向量对应分量应为正还是负；方向相反就整体乘 − 1 。 闭曲面“外侧”取指向区域外部的法向；Stokes 中边界方向与法向用右手法则对应。 Stokes 中由曲线方向反推法向： “顺/逆时针”必须先看题目是从哪个方向观察。 若从某正坐标轴方向看：

逆时针 ⇒ n  指向该正轴
顺时针 ⇒ n  背向该正轴

例如从 + z 方向看：逆时针 ⇒ n z > 0 ，顺时针 ⇒ n z < 0 。 因此可据此确定投影公式中 n x , n y , n z 应取正向还是负向。

转换投影 ②转换投影定理. 设曲面 Σ : z = z ⁡ ( x , y ) , z 有一阶连续偏导数, 且 P ⁡ ( x , y , z ) , Q ⁡ ( x , y , z ) , R ⁡ ( x , y , z ) 在 Σ 上连续, 则

∬ Σ P ⁡ ( x , y , z ) d y ⁢ d ⁢ z + Q ⁡ ( x , y , z ) ⁢ d ⁢ z ⁢ d ⁢ x + R ⁡ ( x , y , z ) ⁢ d ⁢ x ⁢ d ⁢ y = “ ± ” ∬ D ( − P ⁡ ∂ z ∂ x − Q ⁡ ∂ z ∂ y + R ) d x ⁢ d ⁢ y ,

式中 P = P ⁡ [ x , y , z ⁡ ( x , y ) ] , Q = Q ⁡ [ x , y , z ⁡ ( x , y ) ] , R = R ⁡ [ x , y , z ⁡ ( x , y ) ] . 【注】证 因为

n = “ ± ” 1 1 + ( ∂ z ∂ x ) 2 + ( ∂ z ∂ y ) 2 ⁢ ( − ∂ z ∂ x , − ∂ z ∂ y , 1 ) , = ( cos ⁡ α , cos ⁡ β , cos ⁡ γ ) d ⁢ S = 1 + ( ∂ z ∂ x ) 2 + ( ∂ z ∂ y ) 2 ⁢ d ⁢ x ⁢ d ⁢ y ,

并记 F = ( P , Q , R ) , dS = (dydz, dzdx, dxdy)，则

d ⁢ S ⋅ cos ⁡ α = d ⁢ y ⁢ d ⁢ z d ⁢ S ⋅ cos ⁡ β = d ⁢ z ⁢ d ⁢ x d ⁢ S ⋅ cos ⁡ γ = d ⁢ x ⁢ d ⁢ y d ⁢ S = ( cos ⁡ α ⁢ d ⁢ S , cos ⁡ β ⁢ d ⁢ S , cos ⁡ γ ⁢ d ⁢ S ) = ( cos ⁡ α , cos ⁡ β , cos ⁡ γ ) ⁢ d ⁢ S
∬ Σ P d y ⁢ d ⁢ z + Q ⁢ d ⁢ z ⁢ d ⁢ x + R ⁢ d ⁢ x ⁢ d ⁢ y = ∬ Σ F ⁡ ( x , y , z ) ⋅ d S = ∬ Σ [ F ⁡ ( x , y , z ) ⋅ n ] d S = ∬ Σ ( P , Q , R ) ⋅ “ ± ” 1 1 + ( ∂ z ∂ x ) 2 + ( ∂ z ∂ y ) 2 ⁢ ( − ∂ z ∂ x , − ∂ z ∂ y , 1 ) ⁢ d ⁢ S = “ ± ” ∬ D ( − P ⁢ ∂ z ∂ x − Q ⁢ ∂ z ∂ y + R ) d x ⁢ d ⁢ y ,

式中“±”的选取显然就是前述①的情形.

高斯公式

闭曲面取外侧：

∬ Σ F ⋅ n d S = ∭ Ω ∇ ⋅ F ⁡ d ⁢ V ,

即

∬ Σ P d y ⁢ d ⁢ z + Q d ⁢ z d ⁢ x + R d ⁢ x d ⁢ y = ∭ Ω ( P x + Q y + R z ) d V .

2. 考研做题固定流程

三重积分

  1. 先画/识别空间区域；
  2. 选投影面；
  3. 写“下 ≤ 变量 ≤ 上”；
  4. 圆柱/球面对称优先柱坐标、球坐标；
  5. 先用对称性消奇项。

第一型线面积分

  1. 代入曲线/曲面方程；
  2. 算 d ⁢ s 或 d ⁢ S ；
  3. 利用对称性；
  4. 几何意义题可把积分看成质量、面积等。

第二型曲线积分

  1. 开曲线、参数简单 → 直接参数化；
  2. 平面闭曲线 → 优先格林；
  3. 空间闭曲线 → 考虑斯托克斯，曲面可自由选择但方向必须匹配；
  4. 路径无关 → 查 P y = Q x （并注意区域条件），再找势函数。

第二型曲面积分

  1. 先确定方向：上/下、内/外、前/后；
  2. 能投影直接算 → 用投影公式；
  3. 闭曲面 → 优先高斯；
  4. 非闭曲面想用高斯 → 补面，算完再减补面；
  5. 投影一对多时必须分片，不能把两个表面压成一个区域直接算。

3. 补充

  • 第一型积分无方向；第二型积分有方向，反向即变号。
  • 格林、斯托克斯、高斯分别把“边界 ↔ 内部”联系起来：
格林：平面曲线→二重积分
斯托克斯：空间曲线→曲面积分
高斯：闭曲面→三重积分
  • 投影问题先用代数消去被投影变量，再画图检查；不要只凭空间想象。
