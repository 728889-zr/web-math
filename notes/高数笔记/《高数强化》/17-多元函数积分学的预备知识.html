第17讲 多元函数积分学的预备知识

1. 定义与直接结论

方向导数与梯度

设 f ⁡ ( x , y ) 给平面上每个点赋一个数，例如该处的海拔。从某个点出发，向东走、向北走或斜着走，海拔的变化率可能不同。方向导数回答“选定一个方向，每走一单位距离，函数值在起点附近变化多少”。梯度是在函数可微时用来统一计算这些变化率的向量。

1. 先确定起点、方向和走过的距离

  • P 0 = ( x 0 , y 0 ) 是起点。下标 0 表示起点处的坐标。
  • v = ( a , b ) ≠ 0 是题目给的方向向量。例如“从 P 0 指向 A ”时，取 v = A − P 0 ，也就是终点坐标减起点坐标。
  • u = ( u x , u y ) = v / a 2 + b 2 是同方向的单位向量。 u x , u y 是它的两个坐标分量，满足 u x 2 + u y 2 = 1 。 u x , u y 也常写成 cos ⁡ α , cos ⁡ β ，其中 α , β 分别是 u 与 x 轴正向、 y 轴正向的夹角。

沿 u 走距离 t > 0 ，到达

P ⁡ ( t ) = P 0 + t ⁢ u = ( x 0 + t ⁢ u x ,   y 0 + t ⁢ u y ) .

因为 u 的长度为 1，所以位移 t ⁢ u 的长度就是 t 。例如若直接用 v = ( 3 , − 1 ) 作参数，参数每增加 1，实际要走 10 ，这时对参数求导得到的是每单位参数的变化率。单位化后，参数才直接量度行走距离。

2. 用差商定义方向导数

记 Δ ⁢ x = t ⁢ u x 、 Δ ⁢ y = t ⁢ u y 为两个坐标的改变量。 Δ 读作 delta，在这里表示“改变量”。这次移动引起的函数值改变量是

Δ ⁢ f = f ⁡ ( x 0 + Δ ⁢ x , y 0 + Δ ⁢ y ) − f ⁡ ( x 0 , y 0 ) = f ⁡ ( P ⁡ ( t ) ) − f ⁡ ( P 0 ) .

其中 f ⁡ ( P 0 ) 是 f ⁡ ( x 0 , y 0 ) 的简写， f ⁡ ( P ⁡ ( t ) ) 是把走到的点 P ⁡ ( t ) 的两个坐标代入 f 。 Δ ⁢ f 是两个函数值的差。除以距离 t ，得到这一小段路上的平均变化率。令距离趋于零，就得到起点处沿指定方向的瞬时变化率。

D u ⁢ f ⁡ ( P 0 ) = lim t → 0 + ⁡ f ⁡ ( P 0 + t ⁢ u ) − f ⁡ ( P 0 ) t .

D u ⁢ f ⁡ ( P 0 ) 也常写成 ∂ f ∂ l | P 0 ，其中 l 标记所选方向。结果是一个带正负号的数，单位是“函数值的单位 / 距离的单位”。正值表示前进时函数值在一阶上增加，负值表示在一阶上减少，零表示一阶变化为零。

这里用 t → 0 + 来描述“从 P 0 朝 u 的箭头方向靠近”。有些教材把沿整条直线的双侧差商极限写成 t → 0 。当 f 在 P 0 可微时，两种写法对同一 u 给出相同结果。遇到不可微的定义题，按题目采用的约定检查单侧或双侧极限。

3. 可微时，为什么用梯度点乘单位方向

f x ⁡ ( P 0 ) 是在 P 0 保持 y = y 0 、只改变 x 所得的偏导数。 f y ⁡ ( P 0 ) 同理，只改变 y 。把这两个数按坐标顺序放在一起，得到 P 0 处的梯度：

∇ f ⁡ ( P 0 ) = ( f x ⁡ ( P 0 ) , f y ⁡ ( P 0 ) ) .

∇ 读作 nabla。 ∇ f ⁡ ( P 0 ) 是一个向量， Δ ⁢ f 是一次实际移动得到的函数值之差。它们通过可微的线性近似联系起来。

若 f 在 P 0 可微，对足够小的位移 ( Δ ⁢ x , Δ ⁢ y ) ，有

Δ ⁢ f = f x ⁡ ( P 0 ) ⁢ Δ ⁢ x + f y ⁡ ( P 0 ) ⁢ Δ ⁢ y + o ⁡ ( r ) , r = ( Δ ⁢ x ) 2 + ( Δ ⁢ y ) 2 .

r 是这次位移的长度。 o ⁡ ( r ) 是误差项，意思是把误差除以 r ，当位移趋于零时，所得比值趋于零。前两项合起来就是梯度与位移的点积，表示 Δ ⁢ f 的线性部分。

沿单位方向移动时， Δ ⁢ x = t ⁢ u x 、 Δ ⁢ y = t ⁢ u y ，而 r = t 。代入上式并除以 t ：

Δ ⁢ f t = f x ⁡ ( P 0 ) ⁢ u x + f y ⁡ ( P 0 ) ⁢ u y + o ⁡ ( t ) t .

令 t → 0 + ，误差与步长的比值趋于零，于是

D u ⁢ f ⁡ ( P 0 ) = f x ⁡ ( P 0 ) ⁢ u x + f y ⁡ ( P 0 ) ⁢ u y = ∇ f ⁡ ( P 0 ) ⋅ u .

取 u = ( 1 , 0 ) 或 ( 0 , 1 ) ，就分别得到 f x ⁡ ( P 0 ) 或 f y ⁡ ( P 0 ) 。用方向余弦表示 u 时，上式也可写成 f x ⁡ ( P 0 ) ⁢ cos ⁡ α + f y ⁡ ( P 0 ) ⁢ cos ⁡ β 。

公式的前提

一条可直接用于考试的推理链是 一阶偏导在起点的邻域内存在并连续 ⇒ 函数在起点可微 ⇒ 方向导数可用梯度点乘单位方向。题目只给出偏导数或各方向导数存在时，仍需要确认可微性，或者用差商定义计算。

4. 反方向、最快上升和最快下降

沿 u 的反方向走，单位向量换成 − u ，距离 t 仍取正，终点是 P 0 − t ⁢ u 。用 P ⁡ ( − t ) 可以表示同一个终点，但在反方向导数的差商中，分母仍是实际走过的距离 t 。若固定方向 u ，改用负参数 − t 求沿整条直线的左侧差商，分母则是 − t 。

若 f 在起点可微，由点积的线性性可得

D − u ⁢ f ⁡ ( P 0 ) = ∇ f ⁡ ( P 0 ) ⋅ ( − u ) = − D u ⁢ f ⁡ ( P 0 ) .

即使 u 和 − u 的单侧方向导数都存在，缺少可微条件时也要分别检查。例如 f ⁡ ( x , y ) = | x | 在原点，沿 ( 1 , 0 ) 和 ( − 1 , 0 ) 各走距离 t > 0 ，两边的函数值都由 0 变成 t ，所以两个单侧方向导数都是 1。

接下来问“所有方向里哪个上升最快”。假设 f 在 P 0 可微，且梯度长度 g = ‖ ∇ f ⁡ ( P 0 ) ‖ > 0 。令 θ 为梯度与所选单位方向 u 的夹角。它与第 1 步中相对于坐标轴的 α , β 各有不同含义。由点积公式和 ‖ u ‖ = 1 ，

D u ⁢ f ⁡ ( P 0 ) = g ⁡ cos ⁡ θ .
选取的单位方向 夹角 方向导数
与梯度同向， u = ∇ f ⁡ ( P 0 ) / g θ = 0 最大值 g
与梯度反向， u = − ∇ f ⁡ ( P 0 ) / g θ = π 最小值 − g
与梯度垂直 θ = π / 2 0

题目问“最快上升的方向”时，可用梯度向量表示方向。题目要求单位方向时，再除以梯度长度。问“最快下降的方向”时取负梯度的方向，问该方向上的导数取 − g 。若梯度为零，由点积公式可知每个方向的一阶变化率都是零，此时夹角公式没有定义，也没有唯一的最快方向。

5. 从等高线看懂梯度为什么指向上升

等高线 f ⁡ ( x , y ) = C 上的函数值都是同一个常数 C 。设曲线用参数 s 表示为 r ⁡ ( s ) = ( x ⁡ ( s ) , y ⁡ ( s ) ) ， r ′ ⁡ ( s ) = ( x ′ ⁡ ( s ) , y ′ ⁡ ( s ) ) 是沿曲线前进的切向量，撇号表示对参数 s 求导。沿曲线的函数值恒等于 C ，所以链式法则给出

0 = d d ⁢ s ⁢ f ⁡ ( x ⁡ ( s ) , y ⁡ ( s ) ) = f x ⁡ ( x ⁡ ( s ) , y ⁡ ( s ) ) ⁢ x ′ ⁡ ( s ) + f y ⁡ ( x ⁡ ( s ) , y ⁡ ( s ) ) ⁢ y ′ ⁡ ( s ) = ∇ f ⁡ ( r ⁡ ( s ) ) ⋅ r ′ ⁡ ( s ) .

在梯度和切向量都非零的点，点积为零就表示梯度垂直于等高线的切线。配合上一步可知，梯度指向附近函数值升高的一侧。

如果题目用 y = y ⁡ ( x ) 描述曲线，切向量可取 ( 1 , y ′ ) ，其中 y ′ = d ⁢ y / d ⁢ x 是切线斜率。沿等高线时 f x + f y ⁡ y ′ = 0 ，当 f y ≠ 0 时得 y ′ = − f x ⁡ / f y 。若题目改问“切线与梯度平行的曲线”，则匹配 ( 1 , y ′ ) 与 ( f x , f y ) 的分量比例，当 f x ≠ 0 时得 y ′ = f y ⁡ / f x 。斜率公式描述切线的直线方向。要沿曲线向函数值增大的方向走，还要选取与梯度同向的箭头。所除的分量为零时，回到切向量判断是否为竖直切线。

6. 例题贯通，沿指定方向走一小步

设 f ⁡ ( x , y ) = x 2 + 2 ⁢ y ，求 P 0 = ( 1 , 1 ) 沿 v = ( 3 , − 1 ) 的方向导数，并求最快上升的单位方向。这里两个偏导连续，可以使用梯度公式。

  1. 单位化得 u = ( 3 , − 1 ) / 10 。沿这个方向走 t 后，到达 P ⁡ ( t ) = ( 1 + 3 ⁢ t / 10 , 1 − t / 10 ) 。

  2. f x = 2 ⁢ x ， f y = 2 ，所以 ∇ f ⁡ ( P 0 ) = ( 2 , 2 ) 。点乘 u 得 D u ⁢ f ⁡ ( P 0 ) = ( 6 − 2 ) / 10 = 4 / 10 。沿反方向的方向导数为 − 4 / 10 。

  3. 直接把 P ⁡ ( t ) 代入原函数。起点函数值 f ⁡ ( P 0 ) = 3 ，实际改变量为

    Δ ⁢ f = ( 1 + 3 ⁢ t 10 ) 2 + 2 ⁢ ( 1 − t 10 ) − 3 = 4 10 ⁢ t + 9 10 ⁢ t 2 .

    于是 Δ ⁢ f ⁡ / t = 4 / 10 + 9 ⁢ t / 10 。 t → 0 + 时得到相同的方向导数。这里 9 ⁢ t 2 / 10 是被差商极限消掉的误差项。

  4. 梯度长度是 2 ⁢ 2 ，所以最快上升的单位方向是 ( 1 , 1 ) / 2 ，最大方向导数是 2 ⁢ 2 。过起点的等高线为 x 2 + 2 ⁢ y = 3 ，在起点的切线方向可取 ( 1 , − 1 ) ，和 ( 2 , 2 ) 点积为零。

图左的 P ⁡ ( t ) 和 P ⁡ ( − t ) 位于同一条直线上，分居起点两侧。图右标出了过起点的等高线、切线，以及梯度和负梯度。过起点的等高线是曲线，与它相切的直线只描述起点处的方向。

7. 做题时如何选公式

题目问法 做法
沿给定向量或由一点指向另一点 找方向，单位化，在起点算梯度。可微时用点积
题目只给函数定义，起点处可微性不明 把 P 0 + t ⁢ u 直接代入函数，按方向导数定义取极限
最快上升或下降 先求梯度，分别取梯度或负梯度方向，变化率分别为梯度长度或其负值
等高线切向量或法向量 在梯度非零处，梯度给法向，和它垂直的非零向量给切向

对三元函数 F ⁡ ( x , y , z ) ，方向向量和梯度都多一个 z 分量，梯度为 ( F x , F y , F z ) 。把二维的等高线 f ⁡ ( x , y ) = C 换成三维的等值面 F ⁡ ( x , y , z ) = C ，在梯度非零的光滑点，梯度垂直于该面的切平面。后面求隐式曲面 F = 0 的切平面就用这个关系。

2. 考研做题固定流程

  1. 方向导数先把方向向量单位化。
  2. 曲面切平面先写隐式方程 F = 0 ，直接找梯度。
  3. 空间交线切线：两个法向量叉乘。
  4. 法线/法平面与切线/切平面互相垂直，注意题目问的是“方向”还是“方程”。
