使用说明单位矩阵统一写 I ，伴随矩阵写 adj ⁡ ( A ) 。

1. 二次型的矩阵表示

f ⁡ ( x ) = x T ⁢ A ⁢ x , A = A T .

平方项系数直接放在对角线上；交叉项系数平均分给两个对称位置。

例如

f = 2 ⁢ x 1 2 + 3 ⁢ x 2 2 − 4 ⁢ x 1 ⁢ x 2 ⟹ A = ( 2 − 2 − 2 3 ) .

若原式给非对称矩阵 B ，其二次型矩阵为

A = B + B T 2 , x T ⁢ B ⁢ x = x T ⁢ A ⁢ x .

实反对称部分对二次型贡献为零。

2. 标准形、规范形与惯性

标准形只含平方项：

d 1 ⁢ y 1 2 + ⋯ + d r ⁢ y r 2 .

规范形把非零系数化为 ± 1 ：

z 1 2 + ⋯ + z p 2 − z p + 1 2 − ⋯ − z p + q 2 .

p 为正惯性指数， q 为负惯性指数；秩为 p + q ，零项数为 n − p − q 。

可逆线性变换保持 p , q 不变，即惯性定律。规范形通常需要缩放变量，这种缩放一般不是正交变换。

3. 配方法与正交变换法

3.1 配方法

作可逆换元 x = C ⁢ y ：

f = y T ⁢ C T ⁢ A ⁢ C ⁢ y .

配方后的对角系数一般不是 A 的特征值。

若配方得到的是 y = D ⁢ x ，则题目要求的 x = C ⁢ y 中， C = D − 1 。这是变换矩阵方向的常见错误。

没有平方项但有交叉项时，可先制造平方项，例如

x 1 = u 1 + u 2 , x 2 = u 1 − u 2 ⟹ x 1 ⁢ x 2 = u 1 2 − u 2 2 .

3.2 正交变换

作 x = Q ⁢ y ，其中 Q 正交，则

Q T ⁢ A ⁢ Q = diag ⁡ ( λ 1 , … , λ n ) , f = ∑ i λ i ⁢ y i 2 .
比较项 配方法 正交变换法
变换矩阵 可逆 正交
矩阵关系 合同 同时合同与相似
对角系数 不一定是特征值 是特征值
保持的性质 惯性与秩 惯性、秩、特征值、长度
适合目标 标准形、规范形、惯性 特征值标准形、正交矩阵、最值

4. 伪配方法：平方和不保证正定

若

f ⁡ ( x ) = ∑ i = 1 s ℓ i ⁢ ( x ) 2 ,

只能直接推出半正定。令各线性式组成 D ⁢ x ，则

f ⁡ ( x ) = ‖ D ⁢ x ‖ 2 , f ⁡  正定 ⟺ ker ⁡ D = { 0 } ⟺ r ⁡ ( D ) = n .

当平方项数恰为 n 时，等价于 D 可逆。

原书典型结构：

f = ( x 1 + x 2 ) 2 + ( x 2 + x 3 ) 2 + ( a ⁢ x 3 + x 1 ) 2 .
D = ( 1 1 0 0 1 1 1 0 a ) , det ⁡ D = a + 1.

所以 a ≠ − 1 时正定； a = − 1 时非零向量 ( 1 , − 1 , 1 ) T 使 f = 0 ，仅半正定。

OCR 校核重点

原页第三项为 ( a ⁢ x 3 + x 1 ) 2 ，故临界参数为 a = − 1 。参数所乘变量的位置和正负号都要核对。

5. 正交变换的传递与合同矩阵的构造

若

Q A T ⁢ A ⁢ Q A = Λ , Q B T ⁢ B ⁢ Q B = Λ ,

则取 Q = Q A ⁢ Q B T ，有 Q T ⁢ A ⁢ Q = B 。

同阶实对称矩阵 A , B 合同，当且仅当正、负惯性指数分别相同。

若分别化到同一规范形 J ：

S A T ⁢ A ⁢ S A = J , S B T ⁢ B ⁢ S B = J ,

则取 C = S A ⁢ S B − 1 ，满足 C T ⁢ A ⁢ C = B 。

补充：合同题的固定反射

若

A = D T ⁢ B ⁢ D , D  可逆 ,

则 A , B 合同。

1. 合同保持对称性

若 A = A T ，则

B = D − T ⁢ A ⁢ D − 1 ,

从而

B T = B .

所以

合同矩阵中，一个对称，则另一个也对称

2. 实对称矩阵判断合同

同阶实对称矩阵：

A ≅ B ⟺ A , B  的正、负惯性指数分别相同

二阶矩阵常可快速用行列式判断：

det ⁡ A < 0 ⇒ 一正一负 .

3. 要具体求合同矩阵

若分别化到同一规范形

S A T ⁢ A ⁢ S A = J , S B T ⁢ B ⁢ S B = J ,

则要满足

A = D T ⁢ B ⁢ D ,

可取

D = S B ⁢ S A − 1 .

记忆：

判断合同看惯性；求  D  就把两边化到同一个  J

4. 正定、合同于 I 、顺序主子式

以下均以 A 为实对称矩阵为前提：

A ⁢  正定 ⟺ λ i > 0 ⟺ p ⁡ ( A ) = n ⟺ Δ 1 , … , Δ n > 0 ⟺ A ≅ I

其中 Δ k 为前 k 阶顺序主子式。

因此 Sylvester 判别法是充要条件：

Δ k > 0   ( ∀ k ) ⟺ A  正定

而

A ≅ I

之所以等价于正定，是因为合同保持惯性， I 的惯性指数为

( p , q ) = ( n , 0 ) .
易错点

合同本身不保持顺序主子式的数值。 正确逻辑是

A ≅ I ⇒ A ⁢  正定 ⇒ Δ k > 0 ,

不能直接说“因为 I 的顺序主子式为正，所以 A 的也为正”。

6. 合同与相似的区别

关系 定义 主要不变量
等价 B = P ⁢ A ⁢ Q ， P , Q 可逆 秩
相似 B = P − 1 ⁢ A ⁢ P 特征值、特征多项式、迹、行列式、秩
合同 B = C T ⁢ A ⁢ C ， C 可逆 对实对称矩阵保持惯性与秩

**对于同阶实对称矩阵，相似必合同；合同不一定相似。**例如 I 与 2 ⁢ I 合同，但特征值不同，不相似。

合同不保持行列式数值，但

det ⁡ B = ( det ⁡ C ) 2 ⁢ det ⁡ A ,

所以实合同变换保持行列式的正负性及是否为零。

7. 正定判定

以下以 A 为实对称矩阵为前提。

A ⁢  正定 ⟺ ∀ x ≠ 0 ,   x T ⁢ A ⁢ x > 0.

等价条件：

  • 全部特征值严格大于 0 。
  • 正惯性指数为 n 。
  • 所有顺序主子式严格大于 0 。
  • 与 I 合同。
  • 存在可逆 D ，使 A = D T ⁢ D 。

顺序主子式取左上角：

Δ k = det ⁡ A 1 : k , 1 : k , k = 1 , … , n .

二阶实对称矩阵特别方便：

( a b b c ) ⁢  正定 ⟺ a > 0 , a ⁢ c − b 2 > 0.

必要条件 a i ⁢ i > 0 、 det ⁡ A > 0 单独使用不充分。

**补充理解：**半正定等价于所有特征值非负，也等价于所有主子式非负；不能只把正定的“顺序主子式大于零”改成“大于等于零”。负定的顺序主子式判据为 ( − 1 ) k ⁢ Δ k > 0 。

8. 正定矩阵的重要性质

若 A 正定，则 A − 1 、 adj ⁡ ( A ) 、正整数次幂 A m 、 k ⁢ A （ k > 0 ）以及 C T ⁢ A ⁢ C （ C 可逆）都正定。

若 A , B 正定，则 A + B 与分块对角矩阵 diag ⁡ ( A , B ) 正定。

在本书要求正定矩阵实对称的口径下：

A ⁢ B ⁢  正定 ⟺ A ⁢ B = B ⁢ A .

一般正定矩阵的乘积虽然具有正实特征值，但未必对称，不能直接称作本书意义上的正定矩阵。

若要解正定矩阵平方根 C 2 = M ，先正交对角化正定 M ：

M = Q ⁢ diag ⁡ ( μ 1 , … , μ n ) ⁢ Q T , C = Q ⁢ diag ⁡ ( μ 1 , … , μ n ) ⁢ Q T .

得到唯一的对称正定平方根。

9. 二次型最值

9.1 单位球约束与瑞利商

实对称矩阵 A 满足

λ min ≤ x T ⁢ A ⁢ x x T ⁢ x ≤ λ max , x ≠ 0.

所以在 x T ⁢ x = 1 上，最小值、最大值分别为最小、最大特征值；取等号的向量位于对应特征子空间。

在 x T ⁢ x = R 2 上，两端为 R 2 ⁢ λ min 、 R 2 ⁢ λ max 。

9.2 两个二次型之比

若 A = A T 、 B 正定，要求

x T ⁢ A ⁢ x x T ⁢ B ⁢ x , x ≠ 0 ,

先分解 B = D T ⁢ D ，令 z = D ⁢ x ，则

x T ⁢ A ⁢ x x T ⁢ B ⁢ x = z T ⁡ ( D − T ⁢ A ⁢ D − 1 ) ⁢ z z T ⁡ z .

因此最值是实对称矩阵 D − T ⁢ A ⁢ D − 1 的最小、最大特征值。

补充理解：也可解广义特征值问题 A ⁢ x = λ ⁢ B ⁢ x ，即 det ⁡ ( A − λ ⁢ B ) = 0 。分母正定是上述结论的关键条件。

10. 配方后如何写出变换矩阵

原书例题中的二次型

f = 3 ⁢ x 1 2 + 2 ⁢ x 2 2 + x 3 2 + 4 ⁢ x 1 ⁢ x 2 + 2 ⁢ x 1 ⁢ x 3 + 2 ⁢ x 2 ⁢ x 3 = x 1 2 + ( x 1 + x 2 ) 2 + ( x 1 + x 2 + x 3 ) 2 .

若题目要求化成 2 ⁢ y 1 2 + 3 ⁢ y 2 2 + y 3 2 ，应令

y 1 = x 1 2 , y 2 = x 1 + x 2 3 , y 3 = x 1 + x 2 + x 3 .

此时 y = D ⁢ x ，而题目所需的 x = C ⁢ y 为

D = ( 1 / 2 0 0 1 / 3 1 / 3 0 1 1 1 ) , C = D − 1 = ( 2 0 0 − 2 3 0 0 − 3 1 ) .

最后核验 C T ⁢ A ⁢ C = diag ⁡ ( 2 , 3 , 1 ) 。不能把 D 直接当成 C ，也不能仅凭配方就称该变换为正交变换。

从一般标准形 ∑ d i ⁢ y i 2 化到规范形时，对每个 d i ≠ 0 令 z i = | d i | y i ，得到系数 sgn ⁡ ( d i ) ；零系数对应的变量保留。

11. 正定判据的具体用法与反例

11.1 原书的含参数行列式例题

设

A = ( 1 2 − 2 − a ) , B = ( 1 0 1 a ) , f ⁡ ( x , y ) = det ⁡ ( x ⁢ A + y ⁢ B ) .

先展开，得到

f ⁡ ( x , y ) = ( 4 − a ) ⁢ x 2 − 2 ⁢ x ⁢ y + a ⁢ y 2 .

这里要判断正定的是二次型对应的对称矩阵

H = ( 4 − a − 1 − 1 a ) ,

而不是题目给出的非对称矩阵 A 或 B 。因此

f ⁡  正定 ⟺ 4 − a > 0 , a ⁢ ( 4 − a ) − 1 > 0 ⟺ 2 − 3 < a < 2 + 3 .

11.2 必要条件为什么不够（补充反例）

取

H = ( 1 2 2 2 1 2 2 2 1 ) .

它的对角元全为正，行列式为 5 > 0 ，但特征值为 5 , − 1 , − 1 ，所以不是正定矩阵。

“顺序主子式全部非负”也不足以判断半正定。例如

K = ( 0 0 0 − 1 )

的两个顺序主子式均为零，但 ( 0 , 1 ) ⁢ K ⁢ ( 0 , 1 ) T = − 1 。半正定要检查所有主子式，或直接检查全部特征值。

11.3 从平方和读出 A = D T ⁢ D

原书中的矩阵

A = ( 1 − 1 1 − 1 2 − 3 1 − 3 6 )

对应

x T ⁢ A ⁢ x = ( x 1 − x 2 + x 3 ) 2 + ( x 2 − 2 ⁢ x 3 ) 2 + x 3 2 .

所以可取

D = ( 1 − 1 1 0 1 − 2 0 0 1 ) , A = D T ⁢ D .

D 可逆，故 A 正定。此分解若不附加三角形和正对角元等限制，一般不唯一：对任意正交矩阵 Q ， ( Q ⁢ D ) T ⁢ ( Q ⁢ D ) = A 。

12. 最值的取等条件与原书例题

瑞利商取最大值的充要条件是 x 为非零向量且位于最大特征值的特征子空间；取最小值同理。若极值特征值重数大于一，取等向量不止一条方向。

在广义瑞利商中，若 z = D ⁢ x ，则应先求 z 的取等方向，再由 x = D − 1 ⁢ z 还原。等价的直接条件为

A ⁢ x = λ max ⁢ B ⁢ x 或 A ⁢ x = λ min ⁢ B ⁢ x .

原书例题：

A = ( 1 − 2 − 2 4 ) , B = ( 1 − 1 − 1 2 ) .

由于

x T ⁢ B ⁢ x = ( x 1 − x 2 ) 2 + x 2 2 , D = ( 1 − 1 0 1 ) ,

有

D − T ⁢ A ⁢ D − 1 = ( 1 − 1 − 1 1 ) .

它的特征值为 0 , 2 ，故

0 ≤ x T ⁢ A ⁢ x x T ⁢ B ⁢ x ≤ 2.
  • 最小值 0 ： z 与 ( 1 , 1 ) T 同方向，故 x 与 ( 2 , 1 ) T 同方向。
  • 最大值 2 ： z 与 ( 1 , − 1 ) T 同方向，故 x 与 ( 0 , 1 ) T 同方向。

若额外要求 x T ⁢ B ⁢ x = 1 ，最大值在 x = ( 0 , ± 1 / 2 ) T 处取得，最小值在 x = ± ( 2 , 1 ) T / 2 处取得。若无归一化约束，任意非零倍数均可。

曲面判断中的惯性

三维齐次二次型经可逆换元变成 u 2 + v 2 − w 2 时，等值面 f = 1 是单叶双曲面；变成 u 2 − v 2 − w 2 时， f = 1 是双叶双曲面。可逆变换保持惯性，正交变换还保持长度和角度。含一次项的二次曲面还需先处理平移，不能只看二次部分就完成分类。

13. 本讲解题检查清单

  1. 矩阵表示：交叉项系数除以二；非对称矩阵先取对称部分。
  2. 变换方向：区分 y = D ⁢ x 与 x = C ⁢ y ；最终用 C T ⁢ A ⁢ C 核验。
  3. 目标形式：标准形只需可逆变换；要求正交变换时必须用单位正交特征向量。
  4. 合同判断：比较正、负惯性指数；仅比较秩一般不够。
  5. 平方和：先证明各线性式同时为零只有零解，再宣布正定。
  6. 参数正定：严格不等式逐一求交集，端点不能包含。
  7. 矩阵乘积：实对称正定矩阵的乘积需检查交换性，才保持实对称正定。
  8. 最值：确认分母正定或约束有效，同时给出取等方向；换元后还原原变量。
