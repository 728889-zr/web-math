1. 事件与概率

详见 01-第1讲-随机事件和概率。

P ⁡ ( A ¯ ) = 1 − P ⁡ ( A )

P ⁡ ( A ∣ B ) = P ⁡ ( A ⁢ B ) P ⁡ ( B ) , P ⁡ ( A ⁢ B ) = P ⁡ ( B ) ⁢ P ⁡ ( A ∣ B )

全概率：

P ⁡ ( A ) = ∑ i P ⁡ ( B i ) ⁢ P ⁡ ( A ∣ B i )

P ⁡ ( B j ∣ A ) = P ⁡ ( B j ) ⁢ P ⁡ ( A ∣ B j ) ∑ i P ⁡ ( B i ) ⁢ P ⁡ ( A ∣ B i )

10. 置信区间与假设检验

单正态总体均值置信区间：

σ  已知 : X ¯ ± z α / 2 ⁢ σ n
σ  未知 : X ¯ ± t α / 2 ⁢ ( n − 1 ) ⁢ S n

拒绝域：

H 1 双侧/单侧 拒绝条件
μ ≠ μ 0 双侧 | Z | ≥ z α / 2 或 | T | ≥ t α / 2
