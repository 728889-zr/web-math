第 9 讲　参数估计与假设检验

1. 定义与直接结论

1.1 估计量与估计值【基础补充】

  • 用样本构造的统计量 θ ^ ⁡ ( X 1 , … , X n ) 称为参数 θ 的估计量。
  • 将一组具体观测值代入后得到的数称为估计值。
  • 估计量是随机变量；估计值是具体数字。

1.2 矩估计法

总体 k 阶原点矩

μ k ′ = E ⁡ ( X k )

用样本 k 阶原点矩

A k = 1 n ⁢ ∑ i = 1 n X i k

替代。

  • 一个未知参数：通常列一个有效矩方程。
  • 两个未知参数：列两个独立矩方程。
  • 若一阶矩不含待估参数，就改用二阶或更高阶矩。

1.3 最大似然估计

给定样本观测 x 1 , … , x n ：

离散型：

L ⁡ ( θ ) = ∏ i = 1 n P θ ⁡ ( X = x i ) .

连续型：

L ⁡ ( θ ) = ∏ i = 1 n f ⁡ ( x i ; θ ) .

选择使 L ⁡ ( θ ) 最大的参数值作为 θ ^ 。常用对数似然：

ℓ ⁡ ( θ ) = ln ⁡ L ⁡ ( θ ) , ℓ ′ ⁡ ( θ ) = 0.

最大似然估计具有不变性：若 θ ^ 是 θ 的 MLE，则 g ⁡ ( θ ^ ) 是 g ⁡ ( θ ) 的 MLE。

1.4 常见分布的 MLE

总体分布 参数的最大似然估计
B ⁡ ( 1 , p ) p ^ = X ¯
B ⁡ ( m , p ) ， m 已知 p ^ = X ¯ / m
P ⁡ ( λ ) λ ^ = X ¯
G ⁡ ( p ) p ^ = 1 / X ¯
E ⁡ ( λ ) λ ^ = 1 / X ¯
U ⁡ ( 0 , θ ) θ ^ = X ( n )
U ⁡ ( a , b ) 两端未知 a ^ = X ( 1 ) ,   b ^ = X ( n )
N ⁡ ( μ , σ 2 ) 两参数均未知 μ ^ = X ¯ ,   σ ^ 2 = 1 n ⁢ ∑ ( X i − X ¯ ) 2
N ⁡ ( μ , σ 2 ) ， μ 已知 σ ^ 2 = 1 n ⁢ ∑ ( X i − μ ) 2

注意：正态方差的 MLE 分母是 n ；无偏样本方差 S 2 的分母是 n − 1 ，二者不是同一概念。

1.5 估计量的评价

  • 无偏性： E ⁢ θ ^ = θ 。
  • 有效性：在同一类无偏估计量中，方差越小越有效。
  • 一致性/相合性： θ ^ n → P θ 。
  • 均方误差： $$\operatorname{MSE}(\hat\theta)=E(\hat\theta-\theta)^2 =D\hat\theta+[E\hat\theta-\theta]^2.$$

无偏只表示平均意义不偏，不保证单次估计接近真值；一致性描述样本量增大时的行为。

1.6 置信区间的概念

若随机区间 ( θ ^ L , θ ^ U ) 满足

P ⁡ ( θ ^ L < θ < θ ^ U ) = 1 − α ,

则称其为置信度 1 − α 的置信区间。

频率学派表述中，参数是固定的、区间是随机的；不能说“参数以 1 − α 的概率落在已经算出的这个固定区间内”。

1.7 单个正态总体的常用置信区间

设 X 1 , … , X n ∼ N ⁡ ( μ , σ 2 ) 。 σ 2 已知，估计 μ ：

( X ¯ − z α / 2 ⁢ σ n ,   X ¯ + z α / 2 ⁢ σ n ) .

σ 2 未知，估计 μ ：

( X ¯ − t α / 2 ⁢ ( n − 1 ) ⁢ S n ,   X ¯ + t α / 2 ⁢ ( n − 1 ) ⁢ S n ) .

μ 已知，估计 σ 2 ：

( ∑ ( X i − μ ) 2 χ α / 2 2 ⁡ ( n ) , ∑ ( X i − μ ) 2 χ 1 − α / 2 2 ⁡ ( n ) ) .

μ 未知，估计 σ 2 ：

( ( n − 1 ) ⁢ S 2 χ α / 2 2 ⁢ ( n − 1 ) , ( n − 1 ) ⁢ S 2 χ 1 − α / 2 2 ⁢ ( n − 1 ) ) .

补充： z α / 2 、 t α / 2 、 χ α / 2 2 从哪里来

1. 上侧分位数的含义

若 Z ∼ N ⁡ ( 0 , 1 ) ，定义 z β 满足：

P ⁡ ( Z > z β ) = β .

若 T ∼ t ⁡ ( ν ) ，定义 t β ⁡ ( ν ) 满足：

P ⁡ ( T > t β ⁡ ( ν ) ) = β .

若 Q ∼ χ 2 ⁡ ( ν ) ，定义 χ β 2 ⁡ ( ν ) 满足：

P ⁡ ( Q > χ β 2 ⁡ ( ν ) ) = β .

下标表示的是临界值右侧的概率。因此，下标越小，对应临界值越大。 例如 α = 0.05 时：

z α / 2 = z 0.025 ≈ 1.96 , P ⁡ ( Z > 1.96 ) ≈ 0.025 .
2. 中央概率怎样取？

Z 分布和 t 分布关于 0 对称，所以两端各留出 α / 2 后：

P ⁡ ( − z α / 2 ≤ Z ≤ z α / 2 ) = 1 − α ,
P ⁡ ( − t α / 2 ⁡ ( ν ) ≤ T ≤ t α / 2 ⁡ ( ν ) ) = 1 − α .

卡方分布不对称，需要分别确定两个端点：

q L = χ 1 − α / 2 2 ⁡ ( ν ) , q R = χ α / 2 2 ⁡ ( ν ) .

它们满足 0 < q L < q R ，并且：

P ⁡ ( Q < q L ) = α 2 , P ⁡ ( Q > q R ) = α 2 ,

因此：

P ⁡ ( χ 1 − α / 2 2 ⁡ ( ν ) ≤ Q ≤ χ α / 2 2 ⁡ ( ν ) ) = 1 − α .
注意

Z 、 t 分布关于 0 对称，因此双侧用 ± z α / 2 、 ± t α / 2 ；

1.8 假设检验与两类错误

  • 原假设 H 0 ：通常放“等号”和保守立场。
  • 备择假设 H 1 ：研究者希望用样本支持的方向。
  • 显著性水平 α ：当 H 0 为真时误拒 H 0 的概率上限。

第一类错误（弃真）： H 0 为真却拒绝，概率为 α 。

第二类错误（取伪）： H 0 为假却未拒绝，概率为 β 。

检验功效为 1 − β 。

2. 考研做题固定流程

流程 A：矩估计

  1. 数未知参数个数。
  2. 从最低阶开始写理论矩；无参数信息的方程跳过。
  3. 用样本矩替换理论矩。
  4. 解方程，并检查解是否落在参数空间内。

流程 B：最大似然估计

  1. 写单个样本的分布或密度，并把支撑条件一并写出。
  2. 利用 iid 写乘积似然。
  3. 能去掉的与参数无关因子只可在“对参数求最大”时去掉。
  4. 取对数、求导、解驻点。
  5. 检查参数范围、二阶导数、端点和不可导点。
  6. 若支撑依赖参数（如均匀分布），先从样本最大/最小值确定可行域，再判断单调性。

流程 C：构造置信区间

  1. 找只含待估参数且分布已知的枢轴量。
  2. 截取概率为 1 − α 的区间。
  3. 解不等式，把参数单独留在中间。
  4. 卡方分布不对称，不能照搬“左右相同临界值”。

流程 D：假设检验

  1. 先写 H 0 , H 1 ，由 H 1 决定单侧或双侧。
  2. 由“方差已知/未知”选择 Z 或 T 统计量。
  3. 在 H 0 下写统计量分布。
  4. 根据 α 写拒绝域。
  5. 代入样本值：落入拒绝域就拒绝 H 0 ，否则只能说“不能拒绝”，不能说“证明 H 0 正确”。

流程 E：求第二类错误概率

  1. 先由 H 0 与 α 确定接受域。
  2. 把真实参数换成题目给出的备择值。
  3. 在该真实分布下计算“统计量落入接受域”的概率，即 β 。

3. 补充 / 易错点

高频错误
  • 写似然时不能丢掉含参数的指示条件或支撑范围。
  • 似然方程无根不代表无 MLE；最大值可能在边界、最大次序统计量或最小次序统计量处。
  • 正态总体 σ 2 的 MLE 一般有偏；不要和无偏样本方差混淆。
  • 置信度提高时，其他条件不变，置信区间通常变宽。
  • “不拒绝 H 0 ”不等于“接受并证明 H 0 ”。
  • H 1 的方向决定拒绝域方向；不要背图而忘记题意。
  • 固定样本量下，单纯减小 α 往往会增大 β ；两类错误不能同时任意减小。

区间估计与双侧检验具有对应关系：若 μ 0 不在置信度 1 − α 的双侧置信区间内，则在显著性水平 α 下拒绝 H 0 : μ = μ 0 。
